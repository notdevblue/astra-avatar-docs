2026-09-15 사용자 요청으로 정리했다. **새 압축본 용량을 제외한 순 회수량은 16.20GiB**다. 모델 작업의 중간 점검 대기 상태는 유지한다.

합계 24,068개 파일, 17.03GiB를 제거했다. 마지막 항목의 새 압축본 81개는 0.83GiB이며 이 크기를 차감한 순 회수량을 표시했다. 실험의 고유 기록을 폐기한 것이 아니라 동일 내용의 압축본으로 보존한 것이다.

## 보존 및 확인

- 원본 모델·텍스처·고유 사본·현재 v354 후보·원본 검수 사진과 영상은 보존했다. Git 추적 파일 삭제 0.
- v352 전달 파일 34개 SHA256 일치, v354 현재 검수 파일 4개가 커밋과 동일했다. 중간 보고서의 문서·매체 링크 12개 모두 유효하다.
- 중복 내보내기는 작업 원본 또는 독립 문서 체크아웃에 동일 경로/크기/SHA256 사본이 남는 경우만 제거했다. 게시 문서 저장소 자체는 보존했다.
- 기존 ZIP 53개는 압축 파일 SHA·전체 CRC·제거 대상 구성원 SHA·현재 원문 SHA를 검증했다. Git에 보존된 ZIP 또는 동일한 분할 압축 조각이 남는다.
- 새 gzip 81개는 압축을 다시 풀어 원문 SHA를 확인한 뒤에만 원문을 제거했다. ZIP/gzip 각 1개 실제 복원·재해시 검사를 추가 수행하고 다시 압축 보존 상태로 되돌렸다.
- 실행 중 Unity의 Library/Temp, Python 환경, Git pack·커밋 이력은 건드리지 않았다. 동시에 돌아가던 Git 자동 정리의 용량 변화는 위 삭제 합계에 포함하지 않았다.

## 필요할 때 원시 자료 복원

현재 보고서·사진·영상·모델 검수에는 복원이 필요 없다. 과거 동작의 원시 JSON/bin을 다시 분석하는 도구는 해당 파일을 먼저 복원한다. 작업 저장소 루트에서:

```sh
python3 tools/restore_v354_cleanup.py
python3 tools/restore_v354_cleanup.py --restore --prefix avatar_modeling/v353_npr_rebuild/physics_trials/원하는_실험폴더/
```

첫 명령은 복원 가능한 수와 용량만 표시한다. 두 번째 명령은 지정한 과거 실험의 자료만 복원한다. 폴더 대신 정확한 파일 경로를 지정해도 된다. 기존 파일의 내용이 다르면 덮어쓰지 않고 중단한다. 전체를 복원하면 원시 자료만 약 15.36GiB가 다시 필요하므로 필요한 실험만 선택한다.

옛 `share_exports/v...` 임시 폴더에는 중복 매체가 빠져 있을 수 있다. 보고서는 작업 원본 또는 `share_exports/astra-avatar-docs`의 게시 체크아웃에서 연다. 필요하면 고정 커밋을 다시 내보내거나 삭제 목록의 `retained_source`에서 복사한다.

파일별 경로·크기·SHA·남긴 압축본·구성원·검증 결과는 작업 저장소 `docs/maintenance/v354_WORKSPACE_CLEANUP.json`에 기록했다. 복원 도구는 `tools/restore_v354_cleanup.py`, 새 압축본은 `avatar_modeling/v353_npr_rebuild/reviews/maintenance_archives/v354_large_raw/`에 보관한다. 문서 저장소에는 이 설명만 공유하고 원시 검증 데이터는 게시하지 않는다.
