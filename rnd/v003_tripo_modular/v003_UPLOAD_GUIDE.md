# v003 · Tripo 입력 안내

기본 몸과 각 의상은 별도 생성 작업이다. ZIP을 풀면 `images/body`, `jacket`, `shirt`, `tie`, `trousers`, `shoes` 폴더가 있으며, 각각 같은 파츠의 `front.png`, `right.png`, `left.png`, `back.png`가 들어 있다.

| 파일 | 이 자료의 방향 기준 |
|---|---|
| `front.png` | 캐릭터 또는 의상을 정면에서 봄 |
| `right.png` | 착용자 자신의 오른쪽 측면. 코·가슴 앞·구두 앞코가 화면 오른쪽을 향함 |
| `left.png` | 착용자 자신의 왼쪽 측면. 코·가슴 앞·구두 앞코가 화면 왼쪽을 향함 |
| `back.png` | 캐릭터 또는 의상을 뒤에서 봄 |

기본 몸·자켓·셔츠는 T 포즈다. 측면에서 팔이나 소매가 어깨 근처로 짧게 겹쳐 보이는 것은 수평 팔이 카메라 쪽을 향한 모습이다. A 포즈 시험 파일을 끼워 넣지 않는다. 몸의 노출된 눈이 있는 쪽은 `left.png`, 앞머리가 더 가리는 쪽은 `right.png`다.

사용 중인 Tripo 화면의 방향 슬롯 이름과 미리보기를 확인해 각 이미지를 넣는다. **이 문서의 표시 순서인 정면→오른쪽→왼쪽→뒤를 API 배열 순서로 그대로 사용하지 않는다.** Tripo v2 공식 문서는 위치 배열을 `[front, left, back, right]`로 설명한다. 이름 키를 받는 API에서는 이름을 명시하는 편이 혼동이 적다. [Tripo 공식 generation 문서](https://platform.tripo3d.ai/docs/generation), [Tripo H 시리즈 문서](https://developers.tripo3d.ai/en/docs/generation-multiview-to-model/standard). 확인일: 2026-09-15. 이번에는 사용자 계정의 실제 UI/생성 실행을 확인하지 않았다.

한 작업에는 한 폴더의 네 장만 넣는다. 전체 기본 몸 정면에 자켓 측면이나 바지 뒷면을 섞지 않는다. 사진 여러 장을 합친 보고서 화면 대신 개별 PNG를 업로드한다.

몸은 속옷과 헤어가 포함된 기본형이다. 의상은 몸·마네킹 없는 파츠별 이미지다. 각 파츠의 화면상 배율은 독립적이므로 생성 후 기본 몸에 크기와 착용 위치를 맞추고, 빈 내부·옷 두께·본/웨이트·관통을 확인한다. 기본 몸과 의상에 같은 T 포즈를 사용한다고 자동 피팅이나 같은 정점 구조가 보장되지는 않는다.
