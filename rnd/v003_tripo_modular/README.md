# v003 · Tripo용 T 포즈 기본 몸과 독립 의상 4방향

2026-09-15 · 생성 이미지 입력 후보 · 기존 비앙카 모델 수정 없음

사용자 요청에 따라 정면·오른쪽·왼쪽·뒤를 방향별 PNG로 만들었다. 기본 몸은 원화의 얼굴·헤어를 유지한 속옷형(불투명 스포츠 브라와 짧은 피트 쇼츠, 맨발)이며, 자켓·셔츠·넥타이·바지·구두 한 쌍은 몸이 없는 독립 의상 이미지다. **기본 몸과 자켓·셔츠의 최종 입력은 T 포즈**다. A 포즈 시험은 작업 저장소의 trials에만 보존하고 입력 ZIP에서 제외했다.

**[24장 입력 ZIP 다운로드](v003_TRIPO_INPUTS.zip)** · [방향과 입력 방법](v003_UPLOAD_GUIDE.md)

각 폴더의 네 이미지를 같은 생성 작업에 사용한다. 서로 다른 파츠의 이미지를 하나의 4방향 입력으로 섞지 않는다. 이 문서의 4열 표는 보기용이며, 업로드할 파일은 각 셀의 개별 PNG다.

## 확인과 제작 경계

- 내장 ImageGen으로 방향별 이미지를 생성했다. 원화와 앞 단계 생성본을 참조했고, 셋마다 정면 기준을 만든 뒤 다른 방향을 생성했다. 좌우 이미지를 파일 반전으로 만들지 않았다.
- 첫 A 포즈는 후속 사용자 지시로 입력 후보에서 제외했다. 자켓 정면의 빈 뒤판 표현을 보완했고, 구두의 높은 시점을 낮추는 수정을 시도했다. 최종 각 이미지를 직접 확인했다.
- 원화에 가려졌던 몸의 두께, 속옷, 의상 안쪽·뒤쪽과 세부 봉제는 추정 디자인이다. 참고 모델의 메시나 텍스처를 이식하지 않았다.
- 생성 그림은 정확한 직교 렌더가 아니다. 미세한 시점·배율·주름 차이가 남으며, 같은 좌표의 정합·의상 여유분·두께·관통·토폴로지를 검증한 3D 데이터가 아니다. 특히 얇은 넥타이 측면, 열린 자켓 내부, 구두의 시점/양쪽 가림은 생성 결과를 확인해야 한다.
- 기본 몸에는 속옷과 머리가 포함된다. Tripo가 이를 몸과 붙여 만들 수 있으므로 완전한 피부 전용 메시나 헤어 분리가 보장되지 않는다. 의상은 파츠별 화면을 크게 채워 제작했으므로, 생성된 파츠를 합칠 때 스케일·착용 위치·웨이트를 맞춰야 한다.
- 이번 전달은 **24개 이미지와 입력 묶음**이다. Tripo 업로드·모델 생성·자동 리깅·Blender/Unity 통합은 실행하지 않았다. 기존 비앙카 제작본의 T 바인드 포즈를 변경한 것도 아니다.

프롬프트 요약: “원화의 성인 캐릭터 인상·긴 곱슬 헤어·정장 디테일을 유지하고, 속옷형 기본 몸과 몸 없는 독립 의상을 각각 같은 포즈의 정면·양측면·뒤로 생성한다. 몸/상의는 수평 T 포즈, 흰 배경, 글자·가이드·다른 파츠 없이 한 이미지에 한 방향만.” 전체 생성·수정 프롬프트와 원본 경로 기록은 작업 저장소에 보존한다.
