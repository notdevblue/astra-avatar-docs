# v001 · 확인 결과 요약

2026-09-15 · 읽기 전용 조사

| 확인 항목 | 결과 | 판단 범위 |
|---|---|---|
| 비앙카 기준 파일 | 저장된 전달 기록과 일치 | 기준 파일 확인이며 현재 장면이나 최종 품질 판정은 아님 |
| 비앙카 구성 | 몸 관련 부위와 의상 일부를 포함한 메시, 별도 코트 메시 확인 | 완전한 기본 몸의 존재를 뜻하지 않음 |
| 참고 모델 | 과거 조사에 사용한 프리팹·메시 원본과 현재 파일 일치 | 새 런타임 검수나 모든 의존 자산 검사 아님 |
| 설명용 사진 | 기존 비교 사진을 변경 없이 복사하고 직접 재확인 | 최신 비앙카 외형 또는 분리 전후 결과 사진 아님 |
| 의상 없는 몸의 완전성 | 미확인 | 실제 의상 숨김·표면 검사 필요 |
| 모델 전환·제작 시간 비교 | 미실행 | 보고서의 권장안은 자료를 종합한 설계 판단 |

상세 자산 경로·해시·파일 크기를 포함한 재현용 기록과 검사 스크립트는 작업 저장소에만 보존한다. 이 공유 문서는 결과와 한계를 설명하는 요약이며 원시 검증 기록을 대체하지 않는다.
