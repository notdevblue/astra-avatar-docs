# v001 · 사용자 피드백 — SiuSiu의 질감 표현이 목표

사용자 정정: “테두리를 원한 건 아니고, SiuSiu의 질감 표현이 마음에 들어서 그랬어.”

이 정정을 기존 시험의 후속 제안보다 우선한다. 앞선 답변은 테두리·하이라이트 띠에 초점을 좁혀 사용자의 의도를 잘못 해석했다. **목표는 SiuSiu에서 느껴지는 표면 질감과 재질 표현**이다. 단순히 테두리를 없애거나 더 약한 띠를 만드는 것으로 목표를 대체하지 않는다.

추가 사용자 지시: SiuSiu와 비앙카의 옷 소재가 다르므로 이를 고려한다. [소재별 대응 조사](../v002_material_mapping/v002_MATERIAL_REVIEW.md)를 후속 방향으로 읽는다.

## 기존 시험의 위치

- B/C/D/E와 비교 사진은 실제 실험 기록으로 보존한다. 재질 수정이나 새 렌더는 이번 정정에서 하지 않았다.
- E를 자동 후속 출발점으로 삼는 판단은 보류한다. 기존 A와 SiuSiu를 다시 나란히 보는 것부터 시작한다.
- 사용자 발언은 특정 MatCap, 무광 정도, 하이라이트 폭, 색면 평탄화 방식의 선택이나 승인으로 해석하지 않는다.

## 다음 조사에서 볼 것

1. 얼굴·머리·천·가죽·장식의 대응 부위를 확대해 색 변화, 음영의 부드러움과 대비, 광택의 넓이와 강도, 작은 표면 디테일을 구분한다. 이는 조사 항목이며 사용자가 각 특성을 선호한다고 확정한 내용은 아니다.
2. 고정 카메라에서 조명을 바꾸고, 고정 조명에서 시점을 바꿔 어떤 표현이 기본색에 고정되어 있고 어떤 표현이 재질 효과에 반응하는지 분리한다. 기존 비교를 활용하되 추가 실험을 완료했다고 쓰지 않는다.
3. 관찰 결과를 바탕으로 비앙카의 한 부위에서 한 요소씩 비교한다. 광택 강화나 텍스처 평탄화를 해법으로 미리 정하지 않는다. 기존 신발·옷·머리 디테일을 유지한 기준본과 함께 검수한다.

이후 작업 위치는 계속 `avatar_shader`다. 모델링 관절 후보의 채택 상태는 바꾸지 않는다. 이번 변경은 **요청 의도와 후속 방향을 정정한 문서 기록**이며 질감 구현 완료가 아니다.
