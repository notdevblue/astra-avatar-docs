# v002 · 소재 차이를 고려한 SiuSiu 질감 조사

**[사진 포함 소재별 분석과 적용 순서](v002_MATERIAL_REVIEW.md)**

사용자는 테두리가 아니라 SiuSiu의 질감 표현을 원하며, 비앙카와 의상 소재가 다르다는 점을 고려하도록 요청했다. 기존 렌더와 비앙카 디자인 레퍼런스를 직접 다시 검토하고 소재별 대응과 다음 시험 조건을 정리했다. 새 셰이더·마스크·기본색·모델 편집은 아직 없다. E를 후속 기준으로 채택하지 않는다.

`images/`는 이전 실제 Unity 렌더를 픽셀 변경 없이 복사한 비교 자료다. `VISUAL_REVIEW.json`은 출처와 해시를 기록한다. 원본 디자인 이미지·구매 원본·검증 JSON은 문서 공유 대상에서 제외한다.
