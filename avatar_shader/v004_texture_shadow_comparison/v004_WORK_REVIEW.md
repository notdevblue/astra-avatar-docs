# v004 2D 셰이더·고정 그림자 대안 비교

2026-09-13. [v343 텍스처 작업](../../avatar_modeling/v343_texture_resolution/v343_WORK_REVIEW.md)을 마친 뒤 별도 사본으로 비교했다. 원래 검수본을 덮어쓰지 않았다. **추천 검토 순서는 B → A → C**다. B는 세부 채색을 유지하면서 조명 변화를 완화하고, C는 더 평평하지만 코트 주름 깊이가 약해져 실험 사본으로 남겼다.

## 일반 모델도 그림자를 그리는가

스타일에 따라 다르다. PBR base color는 조명/AO를 분리하는 쪽이고, 애니메이션풍은 밝은 색·어두운 색·그림자 마스크를 작가가 설계한다. 모든 그림자를 지울 필요는 없다. 이번 캐릭터에서는 **고정된 큰 명암과 불규칙한 얼룩을 구분하고, 작은 접촉 명암·봉제선은 유지하는 방향**이 적합하다고 판단했다. [조사 근거와 설정 상세](v004_RESEARCH.md)

## 직접 비교한 차이

SiuSiu는 얼굴의 단순한 색면, 강한 눈·외곽선, 넓고 명확한 헤어 하이라이트 띠가 2D 인상에 크게 기여한다. Bianca는 기본 텍스처의 가는 머릿결과 넓은 옷 명암이 더 많다. **셰이더 값만 복사해 같은 인상이 되지는 않는다.** 이번 B는 캐릭터의 기존 채색 디테일을 유지하는 범위라 기본 조명에서는 A와 차이가 작고, 주광이 없거나 색 조명이 강할 때 차이가 더 잘 보인다.

C는 코트 앞의 불규칙하고 넓은 명암을 덜 그려 더 평평하게 보인다. 주머니·단추·봉제선은 남았지만 주름의 깊이도 일부 약해졌다. 따라서 현재 전신에 확대 적용하지 않았다. SiuSiu처럼 더 강한 색면 설계를 원한다면 헤어 하이라이트와 옷 그림자를 디자인 차원에서 바꾸는 다음 선택이 필요하다. 이번 검수의 자동 채택 사항은 아니다.

### 색 레이어 진단

다음은 동적 그림자·MatCap·추가 색 레이어를 끈 진단이다. A에도 옷 주름 명암이 남아 있어 기본 텍스처에 그려져 있음을 확인할 수 있다. SiuSiu의 색 레이어를 끄면 헤어 색도 달라지므로 이 사진을 SiuSiu 원래 완성 외형으로 읽으면 안 된다.

## 검증·전달

7개 모드 × 9시점/광원 조건으로 **63장**을 렌더했다. 앞·옆·뒤, 광원 방향 변경, 따뜻한/차가운 조명, 주광 없음, 색 레이어 진단을 포함한다. A/B/C는 같은 메시·본·변형 구조를 사용하며 별도 재질만 연결했다. 실행 전후 사용자의 Unity 씬 경로·dirty 상태를 보존했다.
