# v090 — 기존 코트 색의 국소 UV 재베이크

사용자는 미해결 개선을 계속하고, 모델 원형을 유지하는 범위에서 텍스처 수정도 시도하도록 승인했다. 이 단계는 v086에서 텍스처가 깨졌던 기존 겨드랑이 면 정리에 새 UV를 부여해 기존 색을 옮기는 실험이다. **텍스처 줄무늬는 제거했지만 변형 품질이 나빠 이 형상은 선별하지 않는다.**

원본 디자인은 `avator_references/ref_char.png`를 실제 열어 비교했다. v089 검수본에서 기존 주름 꼭짓점 24365·28802·6708만 dissolve하고, 주변 기존 9면을 국소적으로 다시 연결했다. 캐릭터 메시를 새로 생성하거나 교체·리메시하지 않았다. 베이크용 원본/수정 표면 사본은 임시로만 쓰고 저장 전에 제거했다. 저장 파일에는 아바타 메시 오브젝트가 하나다.

## 실제 수행

기존 네 UV 묶음을 가로지르던 경계를 별도의 12꼭짓점 UV 섬으로 바꿨다. 기존 재질에서 실제 Principled Base Color에 연결된 `Bianca_reference_basecolor_v005`의 색을 임시 Emission으로 읽어 Cycles Selected to Active 방식으로 구웠다. 새로운 색 디자인이나 AI 이미지 생성은 하지 않았다.

512×512 sRGB 이미지, margin 16px, extrusion 8mm, 최대 ray 거리 40mm다. 이 크기들은 현재 모델 좌표계에서의 값이며 모든 아바타에 적용할 권장값이 아니다. 새 이미지와 재질 슬롯은 이 국소 패치에만 사용한다. PC에서도 재질 슬롯 증가 비용은 있으며 최종 아틀라스 통합은 아직 하지 않았다.

Blender 공식 문서는 Selected to Active, Emit, cage/extrusion 및 UV 섬 주변 margin을 제공한다. 이번 웹 확인은 검색 색인까지이며 본문 직접 열기는 402로 실패했다. 실제 동작은 설치된 Blender 5.2.1에서 MCP로 베이크·저장·재로드하여 확인했다. [Blender Render Baking](https://docs.blender.org/manual/en/latest/render/cycles/baking.html)

면적 경고는 같은 자세의 평가 삼각형 면적이 중립의 0.2배 미만 또는 3배 초과인 사건이다. 기준 패치는 16삼각형, 수정 패치는 10삼각형이므로 동일 분모의 비율이나 성공률이 아니다. 두 검사에서 수정 부위 밖의 원래 면 경고 집합은 비교 단계에서 따로 확인한다. 접촉쌍 수 감소를 관통 깊이 개선으로 해석하지 않는다.

남은 정점을 이동하지 않아도 면을 다시 연결하면 표면 자체는 바뀐다. 국소 삼각형마다 231개의 바리센트릭 표본을 사용한 거리 검사에서 원래 표면→수정 표면 최대 6.296mm, 반대 방향 최대 2.272mm였다. 정확한 Hausdorff 거리나 전체 원형 동일성 증명이 아니다. **텍스처가 정상이어도 이 변형 구조를 채택할 수는 없다.**

초기 실행의 MCP context 선택 오류는 명시적 context override로 수정했다. 베이크 대상 이미지를 자신의 셰이더가 읽는 순환 경고는 베이크 동안만 연결을 해제한 뒤 다시 구워 해결했다. 위 SHA는 수정 후 결과다.

후속 [v091](../v091_patch_flow/REVIEW.md)은 같은 경계 안에서 자세별 늘어남을 고려해 면 연결을 다시 고른다. v090에서 누락 없이 구운 색은 동일 UV 경계의 후속 비교용으로도 보존한다.
