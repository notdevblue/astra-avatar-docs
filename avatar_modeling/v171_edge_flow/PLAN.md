# 기존 어깨 면의 연결 방향 실험

v166 다자세 좌표 보정, v168 사각면 내부 대각선, v169 원래 홈 채우기는 큰 어깨 문제를 해결하지 못했다. 이번에는 **기존 이웃면 사이의 공통 edge를 회전**해 변형 방향과 면 흐름을 바꾼다. 정점을 생성하거나 원래 좌표를 바꾸지 않는다. 국소 삼각화 및 면 연결 수정은 사용자 허용 범위의 별도 파일에서 수행한다.

[Blender Rotate Edge 공식 설명](https://docs.blender.org/manual/en/4.1/modeling/meshes/editing/edge/rotate_edge.html)은 이웃면 사이 공통변을 회전하여 토폴로지를 재구성하는 기능을 설명한다. 실제 실행은 Blender BMesh 편집으로 한다. v168은 같은 사각면 안의 두 대각선만 비교했지만, 이번 후보는 서로 다른 원래 면을 가로지르는 연결도 평가한다.

계획: 136기존자세로 불안정한 면의 이웃을 찾고, 후보 대각선이 정지 표면에서 크게 벗어나거나 UV seam을 가로지르면 제외한다. rest 비평면성은 최대2mm 이내인 별도 후보부터 시작한다. 다자세 면적/면방향 점수가 나아지고 새 연결이 기존 edge와 중복되지 않는 비중첩 후보를 고른다. 적용 후 원형 좌표/키/웨이트 보존과 UV 이음, 새 자기교차를 검사하고 독립자세와 정면·뒤·아래 사진으로 판단한다. 수치 개선만으로 채택하지 않는다.
