# v044 — 원래 옷의 자세 목표를 만드는 시험

팔을 든 상태에서 기존 코트 면을 국소 정리하고 원래 주름의 세부를 다시 더한 뒤, 역스키닝으로 기존 메시의 보정키를 만들었다. 정점·면 추가나 새 메시 생성은 없다. 원형 세부 유지량 100/35/25/0%와 범위를 비교했다.

단독 목표에서는 일부 어깨 접힘이 줄었지만 옷의 분리 정점과 노멀이 남아 각진 음영이 이어졌다. 넓은 정리는 주름 자체를 잃거나 작은 면을 압축할 수 있었다. 이 파일들의 키는 수동 비교 목표이며 자동 구동 완성본이 아니다. 후속은 [v045 연결 검토](../v045_coat_connections/REVIEW.md)와 [v052 제한한 자세 보정](../v052_pose_clothing/REVIEW.md)이다.
