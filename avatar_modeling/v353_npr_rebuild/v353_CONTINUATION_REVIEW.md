# v353 후속 검수 — 헤어 새 원화 전사와 Unity 표면·의복 물리

**전체 작업은 진행 중이다.** 이 문서는 새로 끝난 시험과 실제 확인한 결함을 기록한다. 앞·뒤 머리의 선 표현은 개선됐지만 측면에 전사 경계가 남아 현재 헤어 사본은 미채택이다. 자켓 Cloth도 아직 정상적인 자세 추종을 확인하지 못했다. 이를 완료로 표시하거나 최종 통합본에 합치지 않는다.

## 1. 레퍼런스 스타일과 헤어 전사

일본 애니메이션·게임·일러스트의 절제된 갈색 팔레트, 가닥을 따라가는 가는 선, 형태를 읽게 하는 간결한 하이라이트를 기준으로 했다. 기존 아바타의 초기 텍스처 픽셀은 새 원화의 입력으로 사용하지 않았다. 실제 원래 메시를 회색으로 촬영한 가이드와 사용자 2D 레퍼런스, 이번에 새로 만든 원화의 스타일을 사용했다. 얼굴·헤어 길이·비례·기존 UV는 이 채색 시험에서 변경하지 않았다.

먼저 35도에서 보이는 원래 헤어 전체에 새 원화를 적용했다. 이어 반대쪽 −35도와 뒤 180도의 회색 가이드를 실제 Blender에서 촬영하고, 각각 새 원화를 제작해 전사했다. 그림만 생성해 결과로 공유한 것이 아니라 아래 사진처럼 실제 모델에 적용한 뒤 8방향 전후 16장을 촬영했다.

### 전사 과정에서 찾은 오류와 수정

| 시도 | 실제 결과 | 판정·대응 |
|---|---|---|
| 한 가닥 249삼각형만 전사 | 부분 색조가 주변과 달라 패치처럼 보임 | 미채택. 실제 보이는 헤어 전체로 비교 범위 확대 |
| 8비트 가림 마스크 사용 | 마스크의 저장 잡음 때문에 점무늬 발생 | FLOAT 깊이·원래 면 ID·가시 표면 종류를 직접 검증하도록 수정 |
| 기존 새 아틀라스까지 EMIT 베이크로 다시 샘플링 | 처음 1/255, 여러 시점 누적 때 최대 7/255의 비채색 영역 변화 발견 | 최종 보존 검사 실패. 저장 디더를 끄는 것만으로 해결되지 않음 |
| **새 원화만 베이크하고 네이티브 합성기에서 합성** | 비채색 영역은 UV를 다시 샘플링하지 않고 원래 텍셀 사용 | 최종 비채색 영역 오차 0. Blender 실제 합성·저장 후 다시 읽어 검사 |

35/−35/180도에서 실제 가시 원래 면 중심의 일치 표본은 각각 3210/3162/3684개였다. 중앙 깊이 오차는 약 0.030/0.035/0.031mm다. 전체 개별 깊이 오차가 모두 이 값이라는 뜻은 아니다. 베이크 시 각 삼각형의 화면 기울기와 정확한 면 ID, 깊이, 앞면 방향, 경계 마스크를 다시 검사한다. 가려진 뒷면에 원화를 무조건 투사하지 않는다.

−35도 합성에서 비채색 15,339,889텍셀, 뒤 합성에서 15,251,731텍셀의 디코드 값 차이 **0**을 확인했다. 모든 원래 메시 좌표·런타임 UV·이미지 바인딩은 촬영 후 복원했다. 이 수치 통과는 측면 미관의 합격과 별개다.

네이티브 합성기 구현은 [Blender 5.0 Python API 변경 안내](https://developer.blender.org/docs/release_notes/5.0/python_api/)의 합성 노드 그룹 변경을 참고하고 실제 Blender 5.2.1에서 실행했다. 구형 노드 이름 실패도 기록·수정했다.

## 2. 얼굴의 환경 조명 반응

같은 NEW4 눈 기하·face7·얼굴 로컬 그림자 OFF를 두고 AsUnlit 0/0.25/0.45를 비교했다. 밝음·어두움·차가운 색광·따뜻한 색광, 근접·상반신의 실제 Unity 사진 24장을 생성했다. 아래 어두운 환경과 따뜻한 환경의 세 후보, 차가운 근접 사진을 직접 확인했다. 24장 생성 자체를 전부 독립 검수 완료로 세지 않는다.

| 어두운 환경 0 | 어두운 환경 0.25 | 어두운 환경 0.45 |
|---|---|---|
| ![0](reviews/shader/native_face_environment_v1/FACE_AU000_PORTRAIT_DIM.png) | ![0.25](reviews/shader/native_face_environment_v1/FACE_AU025_PORTRAIT_DIM.png) | ![0.45](reviews/shader/native_face_environment_v1/FACE_AU045_PORTRAIT_DIM.png) |

0은 피부에 환경색이 강하게 묻고, 0.45는 어두운 옷에 비해 얼굴이 더 밝다. 0.25는 후속 통합 비교의 우선 후보로 두되, 전신 손·피부와의 일치 및 실제 Unity 사용 환경까지 확인한 최종값은 아니다. 눈·입의 선명도는 유지되고 이전의 흰 눈꺼풀 아크가 다시 생기지 않는지 함께 확인했다.

## 3. 카라와 셔츠 노멀

카라의 details/shirt 그림자를 00/01/10/11로 분리해 좌우 조명 8장을 실제 촬영했다. **둘 다 그림자를 꺼도 매듭 양옆의 판과 색 경계가 남는다.** 그림자만 끄는 처리는 근본 해결이 아니다. details의 기존 두 부품 C10/C11에 새로 지정한 색 `#DED4CD`와 셔츠 새 원화 기본 `#E0D9D3` 차이가 있으며, 같은 천의 색 정리와 실제 부품 겹침 대응을 이어간다. 이전 rest-ray의 잘못된 면 대응은 판단 근거로 사용하지 않는다.

| 두 재질 그림자 OFF | 두 재질 그림자 ON |
|---|---|
| ![OFF](reviews/shader/native_collar_shadow_v1/DETAILS0_SHIRT0_NECKLINE_LEFT.png) | ![ON](reviews/shader/native_collar_shadow_v1/DETAILS1_SHIRT1_NECKLINE_LEFT.png) |

별도로 뒤카라의 9개 Blender 코너를 실제 Unity 8개 UV 분리 정점의 노멀·탄젠트로 전송하고, 24장 조명 비교를 촬영했다. 기존 좌표·UV·인덱스·웨이트·바인드포즈·보정 키와 범위 밖 N/T는 그대로다. 실제 해당 삼각형의 최소 N·Ng는 +0.0099217이다. 직접 확인한 뒤카라 전후와 정면 사진에서 큰 차이는 없었으며, 남는 판 경계를 이 수정으로 해결했다고 하지 않는다.

## 4. 자켓 Cloth의 자세 추종 진단

전체 고정 Cloth는 원래 스킨과 같은 위치를 따라야 하는 대조 시험이다. 그러나 1736개 실제 Cloth 입자가 기울임·유지·복귀 66표본 내내 중립 위치에 고정됐다. 그러므로 이전의 겉보기 변화는 자연스러운 드레이프 검증으로 사용할 수 없다.

Animator가 매프레임 중립을 덮어쓰는지 분리하기 위해, 각 자세를 만든 뒤 91~299프레임에는 Animator만 잠시 끄고 SDK 계산을 유지했다. 실제 기록된 본은 기울어진 상태지만 Cloth는 여전히 움직이지 않았다. 세 방향 모두 같은 결과다. **Animator 반복 덮어쓰기 하나만으로 설명되지 않는다.** 최종 모델의 Animator를 끄는 수정은 채택하지 않는다.

다음으로 기존 코트 사본의 렌더러 스케일100을1로 정규화했다. 원래 정점·위치 보정량은100배, 바인드포즈는 대응 역변환을 적용하고 UV·노멀·탄젠트·인덱스·웨이트는 유지했다. 중립 세계 좌표 차이 최대0.000299mm, 32개 개별 보정 키의 최대 차이0.001829mm로 원래 외형을 보존했다. 실제 3×1800프레임 시험은 완료했지만 Cloth 입자는 여전히 움직이지 않아 **스케일 정리만으로 해결됐다고 할 수 없다**.

두 시험 모두 완료 후 원래 사용자 장면 일치를 확인했다. 다음은 항상 활성인 실제 카메라로 렌더러가 계속 보이는 조건의 대조다. 기존 감사의 카메라는 필요할 때만 직접 렌더했으므로, Cloth와 화면 가시성의 관계를 확인한다. 이는 원인 분리를 위한 실행 중 시험이며 결과 합격으로 기록하지 않는다.

## 5. 헤어 물리

RESTCLEAR는 중립 외형이 밀려나던 문제를 거의 제거했지만, 움직일 때 코트·이웃 헤어와 새 접촉이 생겨 미채택이다. 반경을 다시 크게 만드는 방식 대신 실제 코트 쪽 표면을 따라가는 별도 물리 경로 사본 두 개를 만들었다. 기존 129본의 부모·세계 행렬, 기존 메시·UV·모든 보정 키·웨이트·바인드포즈는 보존했다. 원래 추가된 5개 스킨 본은 물리 경로의 제외된 자식으로 연결하고, 중립 세계 스킨 최대 차이0.000418mm와 재로드 검사를 통과했다. 중립의 모든 9콜라이더 여유 최소0.683mm다.

이 두 후보는 **구축·재로드 검수만 끝났고 연속 SDK 동작은 아직 대기**다. 중립 보존 수치로 접촉·흔들림·복귀 품질을 합격 처리하지 않는다. 넥타이 지지 후보와 어깨 후보도 기존 대기 목록에서 빠지지 않는다.

## 검수 범위와 계속할 작업

이 후속의 사진은 제작자가 직접 확인했다. 검토용 에이전트 세 개는 사용량 한도로 후속 검토가 중단되어, 이번 새 사진 전체의 독립 검수 완료라고 표시하지 않는다. 앞선 눈·얼굴63장과 단추32장에 대한 완료된 독립 보고서는 별도로 유지한다.

계속할 순서는 측면·안쪽 헤어 전사 경계, 카라 동일 천의 색·실제 겹침 대응, 자켓의 정상 Cloth 평가 또는 지원되는 본 물리 대안, 헤어·넥타이·어깨 실제 동작, 검증한 표면과 물리의 통합, 전체 관절·연속 동작·영상 및 최종 Unity 검수다. PC VRChat 클라이언트 실행은 아직 검증하지 않았다. 전체 작업 완료나 최종 사용자 채택을 뜻하지 않는다.
