# v353 넥타이 역순 시험 독립 검토

**머리 0.130075mm / 머리 본 0.344140mm 차이는 후보가 아니라 실행 순서를 정확히 따른다.** 이전 반복 검토에서 남긴 “PAD1 조건 또는 두 번째 실행 효과” 중 이번 증거는 두 번째 실행 효과를 지지한다. 이 차이를 PAD1의 비대상 헤어 수정 회귀로 분류하지 않는다. 무작위 흔들림도 아니다.

## 실제 비교

최초·반복은 BASE→PAD1, 역순은 PAD1→BASE다. 아래 수치는 같은 프레임끼리 비교했다.

| 비교 | 비대상 BodyHair 정점 최대 | 머리 본 최대 | Coat 정점 최대 |
|---|---:|---:|---:|
| 기존 첫 번째 BASE ↔ 역순 첫 번째 PAD1 | **0mm** | **0mm** | **0mm** |
| 기존 두 번째 PAD1 ↔ 역순 두 번째 BASE | **0mm** | **0mm** | **0mm** |
| 같은 BASE: 첫 번째 ↔ 두 번째 | 0.1300752057mm | 0.3441397456mm | 0.0000614391mm |
| 같은 PAD1: 두 번째 ↔ 첫 번째 | 0.1300752057mm | 0.3441397456mm | 0.0000614391mm |

같은 후보라도 순서가 바뀌면 이전 머리 차이가 재현되고, 다른 후보라도 순서가 같으면 비대상 실제 표면과 머리 본 위치가 같았다. 정점 최대는 Bend frame120의 Unity16238, 본 최대는 frame62의 hair_tip_00다. PAD1의 순서를 앞으로 바꾼 차이 벡터는 기존 BASE→PAD1 벡터와 정확히 반대다.

## 확인한 관문과 범위

- 역순 DONE success, 두 조건 각600프레임 완료, source/scene 복원 equal 확인 후 분석했다.
- 여섯 조건의 실제 **630본기록 × 6**과 **21시점 × 2메시 × 6 = 252개 표면 binary**를 새로 읽어 전체15쌍을 비교했다.
- 같은 후보의 최초/반복/역순 SOURCE JSON은 prefab 경로·dependency hash·정점·삼각형·웨이트·본 배열까지 정확히 동일하다.
- phase/phase_frame/active_input/root_position/deltaTime, 공통 충돌체 위치·회전, hair_anchor/hair_wind 위치·회전, 정규 중립 검사 결과도 동일하다.
- 역순 실행 시 고정한 harness SHA와 canonical 입력 SHA는 현재 실제 파일과 일치한다. 순서 기록은 PAD1Repeat→BASERepeat다.
- 표면은 각21시점이며 600프레임 전체 표면/접촉 검사가 아니다. 0.344mm는 넥타이의 의도된 변화를 제외한 머리 본 수치다.

현재 결론은 해당 실행기의 **결정적 순서 의존성**까지다. SDK 내부 등록 순서, 첫 초기화 상태, 누적 시뮬레이션 시각 중 어떤 구현 요소가 이를 만들었는지는 아직 분리하지 않았다. 늦은 프레임이나 부정확한 입력이라는 추측으로 원인을 특정하지 않는다.

## 보고서와 다음 검증에 반영할 점

1. “PAD1의 헤어가 0.130075mm 변했다”는 수치를 그대로 후보 회귀 근거로 사용하지 않는다. 같은 실행 순서의 교차 배치 비교에서는 비대상 표면 차이가 0이다.
2. 넥타이 정점 자체도 같은 후보의 실행 순서 변경으로 BASE 최대 **0.0688713mm**, PAD1 최대 **0.0822215mm** 차이가 있다. 따라서 관통 여부의 최종 주장은 역순의 실제 표면에서도 확인해야 한다. 이번 분석은 접촉 쌍을 새로 계산하지 않았다.
3. 후보 효과를 비교할 때 같은 순서인 `기존 BASE ↔ 역순 PAD1` 및 `역순 BASE ↔ 기존 PAD1`을 함께 사용하면 이 확인된 비대상 순서 효과를 분리할 수 있다. 다른 시험 입력·후속 사본까지 자동으로 무회귀 판정을 확대하지 않는다.
