# v353 Cloth 단일 가슴 본 입력 독립 검토

코트의 Cloth 오차는 이번 시험에서도 남았습니다. 가슴 본에만 작은 이동·회전을 주었는데, 같은 가슴 본 100% 정점끼리도 서로 다른 방향과 비율로 반응했습니다. 중립 초기 상태와 복귀는 일치했습니다. 따라서 현 결과를 코트 물리 완성으로 채택하지 않습니다. 그렇다고 Cloth 사용 자체가 불가능하다고 확정한 결과도 아닙니다.

## 이번에 실제 확인한 범위

기존 코트 형상과 면 연결을 보존한 진단 사본에서, 본 단위만 동치 표현한 수동 계층을 사용했습니다. 각 조건은 새 Cloth를 중립 자세에서 시작했습니다. 무입력·가슴 회전 ±1도·월드 X 이동 ±2 mm의 5조건, 조건당 360프레임으로 총 1,800프레임을 실제 실행했습니다. 초기 90프레임 중립 → 150프레임 입력 유지 → 120프레임 중립 복귀입니다.

원래 스킨과 진단용 스킨의 최대 차이는 0.000122 mm, 지정 목표와 실제 스킨 차이는 0.000181 mm였습니다. 모두 기존 0.002 mm 관문을 통과했습니다. 관찰 직전에 본을 억지로 동기화하지 않았으며, 진단 계층에 Animator·PhysBone 등 별도 구동기가 없음을 확인했습니다. 원본 의존 데이터와 작업 장면 보존도 통과했습니다.

## 이동 결과

아래는 입력을 충분히 유지한 239프레임입니다. 세 정점 모두 가슴 본 영향이 정확히 100%여서, +2 mm 입력의 스킨 목표는 모두 `(2, 0, 0)` mm입니다.

| 감시 정점 | Cloth 실제 이동 X / Y / Z (mm) | 목표와 거리 (mm) |
|---|---:|---:|
| 1623 | 1.84937 / 0.03576 / −0.03237 | 0.15817 |
| 1153 | 1.74795 / 0.15666 / 0.01891 | 0.29737 |
| 1150 | 1.77231 / −0.01120 / 0.04780 | 0.23292 |

−2 mm 입력에도 방향이 반전되는 유사한 감쇠가 남았고, 오차는 각각 0.16367 / 0.30654 / 0.23812 mm였습니다. +1도 회전의 관찰점 오차는 0.132~0.188 mm였습니다. 이동 조건의 코트 전체 최대 변위 오차는 약 0.466 mm입니다. 이 수치는 이번 작은 입력 시험의 결과이며, 이전 큰 몸 기울임에서 남은 약 9~11 mm 오차와 구분합니다.

120프레임과 239프레임의 세 관찰점 결과가 정확히 같아서, 단순히 더 기다리면 수렴한다는 근거가 없습니다. 중립 복귀 후에는 세 점의 잔여 이동이 정확히 0이고, 전체 코트는 약 0.0001 mm 수치 오차 수준으로 복귀했습니다.

## 겹친 정점과 웨이트 가설 확인

실제 렌더 정점 3,894개는 Cloth 입자 1,736개에 대응합니다. 같은 위치에 겹친 정점끼리 서로 다른 본 웨이트를 가지면, Cloth 내부의 결합 방식 때문에 반응이 달라질 가능성을 따로 검사했습니다.

- 1,736개 그룹 모두 그룹 안의 원래 위치와 전체 본 웨이트가 정확히 같습니다.
- 관찰점 1623은 다른 정점과 합쳐지지 않은 단독 입자입니다.
- 1153/3832와 1150/2738은 각각 같은 위치·같은 노멀·가슴 본 100%입니다.
- 따라서 첫 정점을 선택하거나 평균을 내는 방식 모두 관찰점 목표를 똑같이 예측합니다. 현재 감쇠를 설명하지 못합니다.
- 두 메시 모두 전체 영향 본은 최대 4개입니다. 4개 초과 웨이트를 잘라 읽어서 생긴 오차도 아닙니다.
- 전체 코트에서 전체 웨이트 API와 기존 4개 API 값이 소수 단위까지 완전히 같은 것은 아닙니다. 532점에서 최대 0.000000148 차이가 있으나 본 종류는 일치하고, 세 관찰점은 가슴 본 1.0으로 정확히 같습니다. 이 차이를 전체 일치로 잘못 보고하지 않았습니다.

## 현재 결론과 다음 구분 시험

같은 단일 본 입력에 위치별 반응이 다르므로, 전체에 하나의 행렬이나 스케일 보정값을 곱하는 수정은 근거가 없습니다. 타이밍·외부 충돌체·본 단위·겹친 정점의 서로 다른 웨이트만으로 설명되는 문제도 이번 자료에서 확인되지 않았습니다. Cloth 내부의 목표 구성·결합 제약·실제 렌더 표면 대응 중 어느 부분인지 더 좁혀야 합니다.

다음에는 동일한 코트 형상 전체를 한 개 기존 가슴 본 100%로 묶은 **진단용 사본**에서 +2 mm 입력을 한 번 비교할 수 있습니다. 중립 형상을 정확히 맞추고, 나머지 조건과 초기화를 유지합니다. 전체가 정확히 2 mm 이동하면 여러 본이 섞인 Cloth 초기 구성과 관련된 문제로 범위를 좁힐 수 있고, 동일한 감쇠가 남으면 그 설명도 제외됩니다. 이 웨이트는 아바타 수정안이 아니며 실사용 후보로 채택하지 않습니다.

코트의 기존 PhysBone 지지·중력·충돌체 개선은 별도로 유효한 비교 경로입니다. 다만 위쪽 몸판에는 원래 물리 웨이트가 거의 없으므로, 중력값 변경만으로 위쪽 접힘까지 해결했다고 판단해서는 안 됩니다.
