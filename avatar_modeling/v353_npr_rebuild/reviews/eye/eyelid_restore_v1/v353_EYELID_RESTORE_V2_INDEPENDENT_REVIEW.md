# v353 눈꺼풀 복원 face9 독립 검수

**face9는 눈꺼풀 복원 검수 후보로 선택할 수 있다.** 주접힘선·짧은 안쪽 보조선의 읽힘을 유지하면서 face8의 외측 계단과 주속눈썹 바로 위 분리 잔선이 사라졌다. 이 판정은 실제 0°/35°/55°의 근접·중간 크기 12장 범위이며 사용자 최종 채택과 구분한다.

실제 사진 12개를 모두 직접 열어 비교했다. 사진 SHA 재검산 불일치 0, 6쌍의 실제 기하·카메라·광원·자세 일치, 원본·후보·장면 보존을 확인했다. 실행 PAIR_REVIEW는 수정하지 않았고 판정은 별도 `FACE9_INDEPENDENT_REVIEW_V2.json`에 남겼다. [face8 실패 기록](v353_EYELID_RESTORE_INDEPENDENT_REVIEW.md)은 그대로 보존한다.

## 해석 범위

v352에서 보였던 주접힘·안쪽 보조 접힘의 **역할과 가시성**이 복원됐다. v352의 기존 픽셀이나 넓고 흐린 음영을 동일하게 되돌린 것이 아니며, 이번 더 깨끗한 선 표현은 유지할 가치가 있다. 원래 눈꺼풀의 모든 깊이감을 완전히 같은 수준으로 재현했다고 주장하지 않는다.

현재 55°에서 짧은 보조선이 주접힘에 가까워지는 것은 사진상 투영 압축으로 보이지만, 모든 표면 광선 대응을 계측한 인과 확정은 아니다. 해당 표본에서는 더 수정해야 할 명확한 새로운 꺾임이나 떠 있는 조각이 발견되지 않았다. 수치만으로 다시 선을 지우거나 넓은 기하를 바꿀 근거는 없다.

이번 자료에는 숨은 반대눈을 드러낸 양측 검사, 음수 사선/연속 회전, 다른 광원, face9 원본 대 BC7 압축만의 비교, 최종 물리 병합·PC 클라이언트 검수가 포함되지 않았다. 이전 face7 압축 무회귀 결과를 face9 디테일에 그대로 적용하지 않는다. 다음 단계는 이 복원 후보를 사용자에게 보여주고 최종 통합의 남은 검수 범위에서 확인하는 것이다.
