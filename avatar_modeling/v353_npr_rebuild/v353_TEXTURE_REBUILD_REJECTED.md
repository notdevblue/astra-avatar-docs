# v353 텍스처 전면 재작업 폐기 결정

**사용자 결정에 따라 이번 v353 텍스처 전면 재작업은 전부 미채택·사용 중단한다.** 얼굴·눈꺼풀 후속 복원 face9, Hair29, 옷·신발 새 채색, 그 표면을 사용한 BC7 압축 후보도 후속 기준으로 사용하지 않는다. 기존 문서의 ‘검수 후보 선택’·‘통합 시험용 선택’은 이 결정으로 철회됐다.

품질 문제가 핵심이다. 기존 눈매와 옷·신발의 세부를 보존하지 못했고, 번짐을 줄이는 과정에서 필요한 선과 작은 명암 면까지 단순화했다. 형상 보존·압축·재로드 검사가 통과한 사실은 레퍼런스에 맞는 시각 품질을 뜻하지 않았다. 후속 국소 복원만으로 전체 방향의 품질 부족을 해결했다고 판단하지 않는다.

## 중단 범위와 보존

- 이번 재작업 텍스처와 이를 전제로 한 UV·재질·셰이더 선택을 후속 모델에 자동 이식하지 않는다. 추가 눈 복원이나 옷·신발 재채색도 중단한다.
- 파일과 전후 사진·실패 기록은 이력으로 보존한다. ‘폐기’는 결과의 미채택이며 물리적 파일 삭제나 Git 이력 삭제를 수행하지 않았다.
- 기존 관절·본 작업을 함께 삭제하거나 되돌리지는 않는다. 재작업 표면과 섞인 시험본을 최종본으로 채택하지 않는다.
