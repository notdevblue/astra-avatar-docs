# v353 NPR 전면 재작업 — 실제 실행 중간 검수

**전체 작업은 진행 중이며 최종 채택본이 아니다.** 기존 텍스처의 픽셀을 채색 원본으로 사용하지 않고 새 기본색·세부 그림을 제작했다. 실제 모델 적용에서 발견한 투영·UV·기하·셰이더·물리 문제를 분리하고 수정 중이다. 아래 사진은 제작자가 직접 열어 확인한 결과이며, 보기 좋지 않은 시험도 원인과 함께 남긴다.

최종 목표는 **Unity 게임/PC VRChat에서 조명·자세·움직임이 달라져도 정상적으로 동작하는 일본 애니메이션·게임·일러스트 계열 NPR 캐릭터**다. 레퍼런스의 차분한 색과 인상, 머리 컬과 가는 선, 눈매, 봉제선·단추·신발 디테일을 존중한다. 그림자를 없앤다는 이유로 디테일을 지우지 않는다. [아트 방향과 공식 조사](v353_ART_DIRECTION.md)

Blender 편집과 베이크·렌더는 Computer Use로 실행한다. 기존 메시·사본을 보존하며 대체 메시를 만들지 않는다. 베이크용으로 동일 삼각형을 임시 복사한 경우 작업 후 폐기한다. Unity Editor SDK 시험은 실제 PC VRChat 클라이언트 검증과 구분한다.

헤어는 실제 SDK 7단계 동작에서 167개 스킨 표본과 중립·복귀를 확인한다. 단순 인접 콜라이더 추가는 Wind 접촉을 해결하지 못했다. 기존 Wind 본 영향이 충돌 제어를 우회하는 원인을 찾아 가이드 추종 후보를 별도 실행하고 있다. [인접 콜라이더 실패와 원인](reviews/physics/v353_HAIR_NEIGHBOR_REVIEW.md)

넥타이 깊이별 분담 후보는 기울임의 하방 정렬을 개선했지만 큰 숙임에서 숨은 셔츠 교차가 남았다. 코트·헤어·넥타이 후보의 파일 존재나 각각의 제한적 개선을 전체 통합 완료로 계산하지 않는다. 최종 후보가 정해진 뒤 같은 입력의 비교 GIF/영상과 실제 통합 결과를 추가한다.

## 추가 확인: 바지 외곽 혼입과 눈의 중복 면

### 바지의 톱니선: UV 경계가 아닌 원화 배경 혼입

| 기존 새 채색의 측면 | 배경 혼입 차단 후 같은 측면 |
|---|---|
| ![](images/v353_PANTS_BEFORE_V7_90.png) | ![](images/v353_PANTS_EDGEGUARD_90.png) |

흰 배경과 섞인 원화 가장자리의 회색 픽셀이 전사 마스크를 통과했다. 조사한 문제 표본 55개 모두 원화의 흰 배경에서 2픽셀 이내였고, 실제 아틀라스에서는 UV섬 경계에서 최대 202.65텍셀 안쪽이었다. 바지의 1,724삼각형 중 정확 중복면은 0이었다. 따라서 UV 패딩이나 셰이더 강도로 가리는 방식으로 해결하지 않았다.

새 원화의 2.5픽셀 주변 배경 근접도를 검사해 외곽 혼입을 줄이고 16샘플로 다시 베이크했다. 기존 형상과 UV, 원화 안쪽의 주름선은 그대로 사용했다. 제작자가 위 두 사진을 직접 확인했고 측면 톱니선 감소를 확인했다. 반대쪽·뒤·정면 및 Unity 재질 비교도 별도 검사하며, 신발 측면의 디테일 부족을 바지 개선으로 완료 처리하지 않는다.

| 기존 35° | 깊이·중복 면·새 눈 경계 수정 후 35° | 현재 남은 바깥 끝 55° |
|---|---|---|
| ![](reviews/eye/images/v353_V5_EYE_NEUTRAL_35.png) | ![](reviews/eye/images/v353_V6_CLEAN_EYE_NEUTRAL_35.png) | ![](reviews/eye/images/v353_V6_CLEAN_EYE_NEUTRAL_55.png) |

앞뒤 부품의 각 점을 따로 납작하게 투영하면 원래 두께를 잃으므로, 동일 위치의 층들이 공통 깊이 이동을 받는 방식으로 바꿨다. 이어 원판 위에 겹친 기존 세부 면 100개를 정리했다. 모든 기존 정점·키·웨이트와 남는 면의 UV를 유지했으며, 새 눈 메시로 대체하지 않았다. 별도 세부 면의 원래 역할을 ‘반사 조각’으로 단정했던 표현은 정정한다.

삭제 비교 14장과 새 채색 사진을 제작자와 독립 검토자가 확인했다. 이후 V6 장면에 임시 얼굴 베이크 프록시가 남아 겹친 것을 발견해 제거하고, 실제 아바타 메시 2개만 있는 상태로 5장을 다시 촬영했다. 위 후속 사진은 프록시 제거 후 결과다. 앞선 프록시 포함 V6/벽 이동 사진만으로 내린 세부 판정은 보류했으며 재촬영으로 대체한다. Unity native 검수에는 이 임시 프록시가 포함되지 않았다. 흰 사각 조각·홍채 경계 차단은 줄었지만 바깥 눈꼬리에는 단차가 남고, 현재 세로타원 동공도 레퍼런스 인상과 다르다. 이 상태는 최종 미합격이다. 실제 광선·UV 대응에서 바깥 단차가 눈 주변 안쪽 면과 앞벽의 깊이 차이와 연관되는 것을 확인해 기존 벽의 연결을 검토 중이다. [독립 눈 검토](reviews/eye/v353_EYE_V6_REVIEW.md)
