# v353 다른 모델과 비교한 공통 한계·수용 기록

사용자 추가 기준(2026-09-14): 계속 해결되지 않는 문제가 다른 모델에서도 허용되는 종류라면, 별도 문서에 정리한 뒤 다음 작업으로 넘어가도 됩니다. 이번 검수에 바로 적용합니다.

비교 대상은 실제 보유한 SiuSiu·Lapwing입니다. 비슷한 자세, 카메라 거리, 물리 활성 상태와 조명에서 보이는 정도를 확인합니다. 다른 제작자의 의도를 추정해 “원래 의도한 문제”라고 단정하지 않으며, 비교에서 관찰한 공통 한계와 사용자가 승인한 수용 범위를 구분합니다.

## 판정 기준

- 비슷한 원인과 정도의 현상이 비교 모델에서도 실제 확인되는가.
- 일반 거리의 움직임에서도 드러나는가, 확대/면 교차 계산에서만 확인되는가.
- 원래 겹쳐 배치한 헤어 뿌리인지, 가닥 끝이나 옷 가장자리가 눈에 띄게 뚫리는 것인지.
- 기능·실루엣·부피·표정·복귀에 영향을 주는가.
- 수정하면 다른 부분을 더 크게 악화시키는가.

검사에서 삼각형이 교차했다는 이유만으로 모든 겹침을 결함으로 세지 않습니다. 반대로 다른 모델에도 작은 겹침이 있다는 이유로 우리 모델의 큰 빈 공간·함몰·고정된 검정 얼룩까지 수용하지 않습니다.

검은 팔–몸 사이 공간은 정상 연결 구조로 확인했으므로 구멍을 메우는 수정 대상에서 제외합니다. 이는 다른 모델의 결함을 근거로 수용한 것이 아니라 우리 모델의 기하를 다시 확인한 분류 정정입니다. 실제 세 모델의 허리 기울임 약±17.23° 정적 비교에서도 팔–몸 음각 공간과 의복 층의 가려짐이 보입니다. 다만 SiuSiu는 재킷이 없는 맨허리이고 Lapwing은 넓은 드레스·소매이므로 Bianca의 포켓 위 몸판 접힘을 동일 수준으로 허용할 근거가 되지 않습니다.

이번에 처리 범위를 확정한 것은 **가려진 헤어 층의 겹쳐 보임과 네 입력에서의 현재 헤어 반응 유지**입니다. 실제 비교 사진·영상과 시각 검토 범위는 [헤어 참조 동작 보고](v353_REFERENCE_MOTION_REVIEW.md)에 정리했습니다. 이것은 정확히 같은 삼각형 교차를 다른 제작자가 허용했다는 주장도, 모든 바람·옷 접촉의 완료 판정도 아닙니다. 사용자에게 재승인을 반복 요청하지 않고 승인한 기준 안에서 판정합니다.
