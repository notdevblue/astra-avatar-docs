# v108 — 검증된 소매 보정 검수 묶음

v106의 모든 실제 검사가 끝나면 같은 형상·웨이트·키·애니메이션을 유지한 검수 사본으로 묶는다. v089 보호 기준에 더한 변화는 양쪽 기존 소매 정점의 옆 들기 보정 두 개다. 앞 들기 실험 v107은 별도 결과를 명시하며 자동 포함하지 않는다.
