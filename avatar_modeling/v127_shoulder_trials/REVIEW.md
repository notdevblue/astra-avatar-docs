# v127 — 관절 깊이와 코트 웨이트 결합 시험

v126 진단 뒤 기존 메시의 별도 사본8개를 만들었다. 기준 v121과 함께 앞/뒤/옆8각도×비틀림3개,각24자세를 실제 MCP로 평가했다. 상완 head를뒤3/6/9mm 옮기는 시험에서 쇄골 끝·어깨 보조·CTRL 본도 함께 맞추고 quaternion 전달식을 갱신했다. 중립 원형 오차는8e-7m 미만, 정점/면/UV/텍스처 변경0이다. 기존 pose key의 좌표를 바꾸지 않은 초기 선별이며, rest 변경 후보의 키 저작 기준까지 완료한 최종 리그가 아니다.

앞들기는 v126의 앞으로 도는 쇄골 성분만 제거한 경로다. 팔을 실제 내미는 별도 동작까지 고정한 의미는 아니다. 웨이트 시험은 코트 몸판 가장자리의 상완/쇄골 영향 일부를 기존 가슴 슬롯으로, 어깨 캡의 상완 영향 일부를 기존 쇄골 슬롯으로 옮겼다. 새 영향 슬롯을 추가하지 않았다. 기존 미사용 보조 본을 일괄 켜지 않았다.

각 누적은24자세의 합이다. 낮아진 합계를 품질 통과로 사용하지 않는다. 예를 들어 D3의 앞90도2배초과늘어남은6.103→5.105%지만 새 면적 경고15건이 생겼다. 서로 다른 경로에서 접촉 쌍이 교체되는 것과 관통 깊이가 악화되는 것은 동일하지 않으며, 코트 외형 렌더와 지역별 검사를 추가해야 한다.

**8개 모두 최종 통합 보류.** 다음 v128은 뒤3mm 구조에서 좋아진 기존 옆/뒤 표면을 높은 가중치의 목표로 삼아 웨이트를 제한 범위에서 적합한다. 단순히 같은 이동량을 반복하는 대신 양립 가능한 표면 변형을 찾는다. 코드 (공유본 미포함: `work.py`), 사본 정보 (공유본 미포함: `BUILD.json`), 각 CHECK/POSES 파일로 재현할 수 있다.
