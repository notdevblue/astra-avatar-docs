# v343 텍스처 작업 중 시도와 판단

검수 종료 기록. 최종 후보와 잔여 한계는 [작업 보고서](v343_WORK_REVIEW.md)를 따른다.

| 시도 | 확인한 문제 | 처리 |
|---|---|---|
| Head 전체 아틀라스 생성 | 일부 UV 섬 위치/윤곽과 머릿결이 바뀌어 원래 메시와 정확히 맞지 않음 | 미채택. 원본 유지 |
| 머리 UV 240개 큰 차트 전개 | 일부 차트 늘어짐과 해석 실패 1건 | 28개 차트는 원래 경계로 복귀. 최종 1,473개 차트, 4K 유지 |
| UV만 전사 | 얼굴/헤어 실제 6방향 렌더에서 거의 동일. 렌더 마스크 내 평균 RGB 차이 약 0.07/0.08 | 전사 후보 보존. 위치·본·웨이트 변경 없음 |
| 의상/신발 UV 패널별 정리 | 큰 패널의 선은 회복되지만 작은 패널 경계와 앞코의 넓은 얼룩이 남음 | 모델 표면 투영 정리 추가 |
| 얼굴 UV 패널별 생성 | 독립 생성 이미지의 피부 색조가 달라 새 조각 경계가 드러남 | 얼굴 후보 미채택. `trials/*PANELS.png` 및 실제 실패 렌더 보존 |
| 실제 모델 정면/측면 기반 색 차이 투영 | 얼굴 색 연결 개선. 색 유사도를 가시성 판정에 쓰면 보정 일부 누락 | 색 유사도 방식 미채택 |
| 기존 삼각형 깊이로 가시성 계산 | 앞코의 큰 얼룩 개선, 적용 누락 감소. 측면/바닥과 UV 경계의 얇은 흔적 추가 확인 | 헤어·신발 6방향, 얼굴 아래, 양 소매 뒤 투영으로 보완 완료 |
| 생성 이미지와 모델 대응 검산 | 기존 삼각형·UV로 CPU 재구성한 신발 이미지가 Blender 입력과 일치 | 좌표 등록 자체가 원인이 아님 확인. 이 이미지는 보조 검산이며 최종 검수는 Blender/Unity 실제 렌더 |
| 코트 고정 명암 감소 | 단추·주머니 선을 남기고 넓은 명암만 줄인 별도 텍스처 생성 | v004 셰이더 비교 사본에서 검토. v343 주 후보에 자동 합치지 않음 |

생성 이미지는 채색 재료일 뿐 모델 적용 성공 증거가 아니다. 변경 후 실제 Blender/Unity 렌더를 열어 검수한다. 섬 수 감소·픽셀 수·검증 통과를 시각 품질 완성으로 해석하지 않는다.

## 후반 시도와 선택

| 시도 | 결과 | 판단 |
|---|---|---|
| 얼굴 패널별 피부 톤 보정 | 각 패널의 색조가 독립적으로 변해 조각 경계가 더 보임 | 미채택. 원래 Head 전사본 위에 정면·측면·아래 투영으로 다시 구성 |
| 투영 마스크의 빈 픽셀을 일괄 이웃 채우기 | 얼굴 귀 주변에 가는 선이 생김 | Head에는 미채택. Paint의 1.5px 이내 래스터 틈만 제한적으로 적용 |
| 얼굴 뒷면까지 양면 투영 | 반대쪽 귀/면에 다른 시점의 색이 섞임 | 정면·측면은 법선 방향으로 제한, 턱 아래만 높이 제한을 둔 별도 투영 |
| 턱 아래 약한 투영 | 원래 다각형 색 띠가 일부 남음 | 목 아래 영역에만 아래 방향 기여도를 높여 실제 렌더에서 색 띠 감소 확인 |
| 소매 끝 패널 약한 혼합 | 단추 아래 천의 사각 잔상이 남음 | 끝단 4개 패널에 한해 혼합 강도를 높임. 단추 표면은 보호 |
| 런타임 속성 단순 직렬화 비교 | 1,372개 차이가 보고됨 | 모두 객체 참조의 세션별 FileID. 객체 참조는 계층 경로로 비교하고 중복 내부 ID는 제외하니 24,155개 속성 차이 0 |
| 원본 도구 실행 문제 | NumPy float32 메타데이터 JSON 직렬화 실패, 중복 bridge 요청 ID | float 변환 및 고유 요청 ID로 복구. 출력·응답을 확인한 뒤 후속 실행 |
| 고정 명암을 크게 덜 그린 코트 | 밝고 평평하지만 주름 깊이도 약해짐 | v004 C 별도 사본만 보존. 전체 의상에 자동 적용하지 않음 |

Head 전체 아틀라스 생성은 UV 위치를 바꾸기 쉬워 미채택했다. 초기에 생성 도구가 한 요청을 거부한 경우도 있었으며 결과 파일이 없는 실행은 사용하지 않았다. 채택한 생성 재료와 정확한 프롬프트는 작업 저장소의 `GENERATIONS.json`과 `generated/`에 남겼다. 문서 공유 저장소에는 원본 아틀라스·생성 채색 재료를 게시하지 않는다.
