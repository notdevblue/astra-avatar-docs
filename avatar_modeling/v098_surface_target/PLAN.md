# v098 — 함몰 전체의 포즈 곡면

v094 조사와 v097 실패를 이어간다. 최근 사본은 주름 끝의 단면 웨이트에서 목표를 얻었고, 그 목표의 큰 이동은 주로 주름 끝을 바꿨다. 이번에는 팔을 올린 실제 표면을 다시 ray 검사하여 위쪽 소매 뿌리까지 포함한다.

기존 연결을 유지한 제한 영역에서 포즈 표면의 급격한 굴곡을 완화하는 목표를 만든다. 바깥 정점은 고정하고 원래 포즈에서 멀어지는 양에 벌점을 준다. 정점별 이동은 최대8mm로 제한하며 기존 표면 법선의 안쪽으로 움직이는 성분을 제거해 과도한 수축을 막는다. 중립 기하·웨이트·UV를 바꾸지 않는 Shape Key 사본에서 비교한다. 이 목표는 포즈 조각의 계산 보조이며 실물 옷 시뮬레이션/튜토리얼 정답이 아니다.

기본 자세와 혼합 회전의 실제 평가, 같은 카메라의 넓은 어깨/앞/옆 컬러, 기존 면의 면적·접촉을 함께 확인한다. 수치 경고는 발생 위치와 실제 외관을 살펴 판단하며 총합 하나로 결론내리지 않는다. 목표 곡면이 유망하면 여러 자세의 면 제약을 반영해 후속 보정한다. 새 메시/면/정점/본 생성 없음. 기존 v089와 v038 무릎 보호.
