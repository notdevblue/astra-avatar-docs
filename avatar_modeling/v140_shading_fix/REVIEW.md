# v140 — 어깨의 각진 음영 정리

v138의 실제 면은 이어져 있는데 어깨에서 빛이 갑자기 끊기는 문제를 수정한 별도 사본이다. 사용자 채택 완료를 의미하지 않는다.

코트의 Sharp 102개 중 어깨와 겨드랑이 위쪽 67개만 해제했다. 나머지 35개는 유지했다. 모든 Custom normals를 초기화하거나 코트 전체를 평탄하게 처리하지 않았다. v139에서 Custom normals 초기화만으로는 거의 차이가 없었고, Sharp 해제가 각진 음영에 영향을 준 것을 먼저 확인했다.

- 정적 검수 파일 (공유본 미포함: `bianca_LOCAL_SHADING_REVIEW.blend`)
- [앞 90도 비교](COMPARE_F90.jpg)
- [뒤 35도 비교](COMPARE_B35.jpg)
- [뒤 60도 비교](COMPARE_B60.jpg)
- 변경 edge 목록과 저장 검증 (공유본 미포함: `BUILD.json`)
- 39자세 좌표 비교 (공유본 미포함: `CHECK.json`)

실제 MCP 저장·재로드에서 정점, 웨이트, 기존 16개 보정 키 좌표는 보존됐다. 앞뒤 회전 24조건과 옆 회전 15조건의 평가 정점 좌표가 v138과 완전히 같았다. 10개 컬러 렌더를 만들었다. 음영이 변경되는 작업이므로 렌더 픽셀이 원본과 같아야 하는 검사는 적용하지 않았다.

각진 음영은 완화됐지만, 텍스처에 그려진 어두운 곡선과 겨드랑이의 실제 깊은 접힘은 남는다. 후속 텍스처 작업은 [v141](../v141_texture_fix/REVIEW.md), 최종 통합 확인은 [v143](../v143_seam_review/START_HERE.md)에서 확인한다.

근거: [Blender Shading](https://docs.blender.org/manual/en/latest/scene_layout/object/editing/shading.html). Sharp 경계와 Smooth 표면의 역할을 구분해 적용했다.
