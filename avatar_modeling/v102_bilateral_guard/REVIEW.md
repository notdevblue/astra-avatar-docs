# v102 — 국소 삼각형 사이 분리 축 검사

기존 좌우54정점 목표를 각각 조정했다. 후보에서 겹치거나 가까워진 비연결 삼각형 쌍을 찾고, 기준 포즈에서 분리되던 축의 간격을 보존하는 조건을 추가했다. 고정 삼각 조합 기반 계산이며 실제 Blender의 동적 분할과 구분한다.

| 쪽 | 최종 간격 조건 | 캐시 새 / 해소 삼각 경고 | 최대 변위 |
|---|---:|---:|---:|
| 왼쪽 | 10,692 | 0 / 338 | 5.111mm |
| 오른쪽 | 7,749 | 0 / 440 | 7.532mm |

각각 두 적합 단계 후 추가할 새 국소 쌍이0이었다. 각 단계는1200회 상한 종료, 간격 조건 최대 잔차는 왼쪽0.000139mm/오른쪽0.000963mm다. 이는 전역 교차0이나 수렴 증명이 아니다. 검사 영역 바깥 고정 면은 모든 쌍에 포함되지 않았으며, 후속 v103의 오른쪽 원래면8684 접촉이 이 범위 한계를 보여줬다.

이 버전은 기존 정점 변위 데이터 LEFT.npz/RIGHT.npz와 계산·검사 기록이다. 새 메시 파일을 생성한 단계가 아니다. 실제 Blender 통합은 [v103](../v103_bilateral_review/PLAN.md)에서 두 키로 만들었고 사각면 경계 보호를 추가했다. 원래 v089 파일과 무릎 파일은 보존한다.
