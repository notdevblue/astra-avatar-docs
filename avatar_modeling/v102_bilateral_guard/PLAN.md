# v102 — 양쪽 보정의 국소 면 간격 검사

왼쪽 v100은 기존530에서 새 접촉0, 면적 새1/해소132까지 줄었지만 기존200의 다른 두 자세에서 [15403,15404] 접촉이 새로 생겼다. 이미 발견한 쌍만 제한하면 이웃에서 새 접촉이 나타날 수 있어, 보정 후보의 인접하지 않은 국소 삼각형 쌍을 자동 검사해 분리 축 제약을 추가한다. 오른쪽은 v101의 독립 면 제약 목표에서 시작한다.

2107개의 선별 자세 중 활성434개에 대해 기존54정점의 같은 포즈 키 목표만 수정한다. 원래 교차하지 않던 삼각형의 간격을 유지하고 필요한 쌍을 반복 추가한다. 기존 교차의 해소와 새 교차 방지를 구분한다. 실제 Blender의 자세 후 삼각분할·컬러·동작 검증은 별도다. 새로운 난수는 아직 최종 학습에 포함하지 않았다. 새 메시/정점/면/본 생성 없음.
