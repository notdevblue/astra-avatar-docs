# 기존 손 면의 대각선과 선택적 마디 보조

ISOLATE50 손 사본에서 개별 마디300표본을 사용해 문제 사각형의 두 대각선을 각각 평가했다. 기존에 경고가 없던 자세에 새 경고를 만들지 않고 경고 표본을 줄이는 대각선만 선택했다.8사각형 내부 대각선 고정으로 정점 추가/이동0, UV 코너·웨이트 동일, 총 삼각형 수 유지다. 전체 평가 면 경고는72→48,교차 면쌍3133→3144로 접촉은 같은 집합이 아니다. 자세·원래면 번호로 다시 대응한 비교가 필요하다.

모든 손가락에 보조본을 넣는 v043 실험은 부작용이 있었다. 이번은 남은 두 번째 마디의 부피 붕괴를 겨냥해 중지 PIP만/네 손가락 PIP/중간·끝마디로 범위를 나눈다. 원래 Humanoid 본은 유지하고 local회전 절반의 보조본에 원래 두 본의 공통 웨이트만 옮긴다. 아직 검증·통합 전이다.
