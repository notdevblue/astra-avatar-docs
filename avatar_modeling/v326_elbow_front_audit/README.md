# v326 팔꿈치 정면 각짐 검토

[사진 포함 결과](v326_ELBOW_REVIEW.md). v324 원본과 v325 실제 스냅숏0/180을 읽은 국소 재검토이며 모델 수정 없음.

`analyze_elbow.py`는 v325의 원래 위치·삼각형·웨이트와 실제 두 자세를 비교한다. `MacElbowFrontViews.cs`는 Unity PreviewScene에만 표시해 원래 재질·회색·실루엣으로 촬영한다. 양쪽 본 위치 기준75mm 영역으로 실제 기하 면각을 비교하며 패널 L/R 글자를 리그 좌우로 가정하지 않는다. 수치 (공유본 미포함: `ELBOW_CHECK.json`), 촬영 계획 (공유본 미포함: `RENDER_PLAN.json`), 장면 보존 (공유본 미포함: `RENDER_COMPLETE.json`), 원본 보존 (공유본 미포함: `SOURCE_PRESERVATION.json`).

v325의 `REVIEW_SNAPSHOTS.npz`에 실제 위치/노멀과 원본 자료가 보존되어 있다. 전체0/180 캐시는 `.venv/v325_full_rig/`를 사용한다. 입력 의존성은 v325 안내 (공유본 미포함: `README.md`)를 따른다. 새 동작 재생이나 후보 수정 비교는 이번에 수행하지 않았다.
