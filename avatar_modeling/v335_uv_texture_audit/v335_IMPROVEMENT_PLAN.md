# v335 · UV·텍스처 개선 실행 계획

이번 단계는 비교 조사까지 완료했습니다. 아래는 다음 사본에서 진행할 순서이며 새 UV나 채색을 이미 적용했다는 뜻이 아닙니다. 관절은 v334 상태로 보존합니다.

## 1. 코트 한 패널 또는 소매에서 시작

기존 메시 사본에 새 UV 레이어를 만들고 원래 UV를 남깁니다. 기존 면을 옷의 재봉 경계에 맞춰 연속된 패널로 펼칩니다. 정점 위치·토폴로지·웨이트·본·보정키는 유지합니다. 먼저 v324 기본색을 새 UV로 전사하고, 원래 주름·단추·라펠이 그대로인지 같은 카메라에서 비교합니다. 재배치만으로 명암·얼굴·옷 형태가 달라 보이면 채색을 진행하기 전에 전사 문제를 해결합니다.

국소 시험이므로 아틀라스 전체를 다시 배치할 필요가 있는지부터 확인합니다. 패널에 원래보다 적은 픽셀을 배정하지 않고, 경계 여백·베이크 확장·축소 표시를 확인합니다. 여러 조각을 단순히 꽉 채우는 것보다 수정할 면이 연결되고 경계가 유지되는 것이 목표입니다.

## 2. 원래 디테일 보존 후 선택적으로 채색

원래 방향별 캐릭터 레퍼런스, v324, 새 UV 전사본을 비교합니다. 레퍼런스의 주름·재봉선·신발 띠·머리 결을 보존하고 그 구조와 무관한 번짐만 수정합니다. 전체 흐림 제거 필터나 평활화는 적용하지 않습니다. 넓은 밝기 변화와 재질 광택을 혼동하지 않도록 원래 재질 / 주요 효과 해제 양쪽으로 확인합니다.

SiuSiu에서는 무늬·테두리의 분리와 용도별 마스크를, Lapwing에서는 큰 색면과 선택한 디테일의 대비를 참고합니다. 비앙카의 정장을 광택이 강한 다른 의상으로 바꾸는 것을 목표로 삼지 않습니다. 텍스처 장수·재질 수를 늘리기 전에 기존 두 아틀라스 안에서 부위별 배치를 개선할 수 있는지 먼저 시험합니다.

## 3. 국소 성공 후 부위 확장

코트·소매 → 바지·신발 → 얼굴·손 → 머리 순서로 원본 비교를 남깁니다. 코트 안감과 가려진 다리·피부, 옆·뒤 면은 가림을 푼 사본에서도 확인합니다. 얼굴과 머리는 작은 UV 변경도 표현을 바꿀 수 있으므로 별도 비교본으로 유지합니다. 새 메시 생성·부분 대체·자동 리메시는 하지 않습니다.

## 4. 품질이 정리된 뒤 압축·해상도 비교

원본 4K 무압축과 사본의 4K 압축 / 2K 압축을 가까운 거리와 전신 거리에서 비교합니다. 해상도·압축·재질 효과를 한꺼번에 바꾸지 않습니다. 얼굴·얇은 선·신발 띠·밉 경계의 손실이 보이면 해당 설정을 채택하지 않습니다.

Unity의 Max Size는 실제 가져오기 크기를 제한하고 압축 설정은 런타임 형식에 영향을 줍니다. 3D 대상은 거리별 축소 표시를 포함해 확인합니다. 근거: [Unity Texture Importer](https://docs.unity.cn/Manual/class-TextureImporter.html), [Unity 자산 설정·최적화](https://unity.com/how-to/project-configuration-and-assets).

UV 전개 방식과 패킹은 목적에 맞춰 선택합니다. 자동으로 면을 조각내 채우는 방식만으로 사람이 채색하기 좋은 UV가 되는 것은 아닙니다. 근거: [Blender UV 연산자](https://docs.blender.org/manual/en/5.0/modeling/meshes/editing/uv.html).

## 채택 기준

- 원래 디자인 디테일·실루엣·관절 상태 보존. UV만 바꾼 전사본에서 먼저 확인.
- 의도하지 않은 겹침·0면적 UV·경계 색 섞임 검사. 의도된 대칭·스트립 겹침과 구별.
- 얼굴, 손, 소매, 신발, 옆·뒤·안쪽을 실제 이미지로 검수하고 원본/전사/정리 후를 문서에 함께 수록.
- 새 UV의 면적·픽셀 배분을 원래와 비교해 v323 때의 디테일 축소를 반복하지 않음.
- 실패 방법과 미채택 이유도 새 버전 폴더에 기록. 사용자가 확인할 때까지 비교 후보와 최종 채택을 구분.
