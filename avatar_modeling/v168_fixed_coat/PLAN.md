# v168 — Blender 검토와 게임의 삼각 면 고정 방식 일치 실험

v166 국소 좌표 보정은 미사용436자세에서 새 면적4/새 교차69가 다시 나왔다. 아직 통합하지 않는다. 다음은 좌표/웨이트를 더 조정하기 전에 게임이 실제 사용하는 고정 삼각면과 Blender의 포즈별 사각면 삼각화를 구분하는 실험이다.

v146에서 원본면15414 대각선 하나를 고정한 이력이 있다. 이번은 v165 코트 전체에서 **현재 rest 삼각형과 정확히 같은 대각선**만 기존 사각면 안에 추가한다. 정점 수와 위치, UV, 모든 키 좌표, 웨이트는 바꾸지 않는다. 새 캐릭터 메시를 생성하지 않는다. 코너 노멀은 실제 벡터를 기존 코너ID로 대응하여 보존하고 오차를 확인한다.

기대 효과는 품질 개선을 가정하는 것이 아니라, 포즈마다 달라지는 대각선으로 생기는 표시 차이 제거다. Unity FBX는 기본 삼각면을 고정하고 스키닝한다. 고정 후에도 같은 홈이 보이면 면 방향 전환만이 원인이 아니라 실제 변형/정지 주름 문제다. 정지 원형과 음영을 먼저 비교하고 앞/뒤/옆/아래에서 평가한다. 바깥 형상 재생성이나 무조건적인 세분화는 수행하지 않는다.
