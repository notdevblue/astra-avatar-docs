# v030 무릎 국소 수정으로 방향 재정렬

2026-09-09. 사용자는 v030의 무릎만 잘 조절하는 것이 낫지 않은지, 다른 제작자는 어떻게 해결했는지 질문했다. 필요하다면 Blender MCP 설치도 허용했다. 이번에는 사례와 기존 코드를 다시 확인했으며 모델 파일은 변경하지 않았다.

## 결론

v030에서 무릎만 수정하는 접근을 버릴 근거는 없다. 기존 시도에서 무릎 문제가 해결되지 않았다는 사실이 그 접근의 불가능성을 뜻하지 않는다. 다음 편집의 출발점은 v030 사본으로 다시 잡는다. v035/v036을 이어 고치는 것이 기본 경로라는 이전 기록보다 이 방향을 우선한다. v030 자체의 두께 손실·국소 교차까지 합격 처리하거나 전체 아바타 최종 채택하는 것은 아니다.

## 지금까지 우리 작업과의 중요한 차이

`knee_structure_v033.py`의 컷은 기존 면을 여러 높이에서 bisect하는 방식이다. 원형 보존에는 유용하지만, 앞쪽 지지 구획과 뒤쪽 접힘의 연결을 다르게 다시 짜는 작업 전체를 대신하지 않는다. 컷 수가 늘어났다고 무릎의 면 흐름이 해결된 것은 아니다.

`knee_crease_corrective_v036.py`의 목표 변형은 접힌 공간에서 지수 함수로 이동장을 만들고 스키닝 행렬을 역산한 것이다. 키 좌표 저장과 재생이 정확해도, 그 입력 목표가 사람이 직접 다듬은 자연스러운 무릎이라는 보장은 없다. v036은 이 한계를 실제 주름·압축 경고로 보여 주었다.

검사에서 교차를 없애고 투영 폭을 늘리는 데 비중을 두면서, 사용자가 선호한 v030의 접촉 실루엣을 충분히 유지하지 못했다. v036 본 보정은 교차·면적 검사에 통과하고도 측정 홈 폭이 증가했다. 따라서 새 출발에서는 숫자 검사 전에 v030에서 유지할 접힘과 바꿀 형상을 명시해야 한다.

또한 실제 수정 대상은 바지 표면이다. 무릎뼈가 있는 인체의 두께 원리는 참고하되, 바지 안쪽의 자연스러운 접힘까지 균일하게 부풀리는 것을 목표로 삼지 않는다.

## v030 사본에서 진행할 순서

1. v030의 90/120/130도와 앉기 자세를 같은 시점으로 고정한다. 뒤쪽의 좁은 접힘과 전체 캐릭터 실루엣을 유지할 기준으로 삼고, 앞·옆에서 얇아지는 부분과 국소 교차를 따로 표시한다.
2. 우선120도에서 무릎 앞·옆의 목표 형상을 정점 단위로 다듬는다. 뒤쪽 공간을 통째로 벌리거나 무릎 전체를 부풀리는 일괄 이동장을 기본 해법으로 쓰지 않는다. 변경된 정점·면 목록을 기록하고 편집 경계를 부드럽게 연결한다.
3. 목표 형상을 따라가기 어려운 기존 연결만 정리한다. 앞쪽의 곡면 지지와 뒤쪽의 압축을 분리하고, 필요한 컷·모서리 정리·기존 정점 이동을 별도 사본에서 수행한다. 새 메시 생성·부분 대체·자동 리메시는 하지 않는다.
4. 기존 본의 축·피벗·웨이트로 가능한 범위부터 맞춘다. 추가 본이나 자세 키는 실제로 부족한 부위에만 사용한다. v035 보조 계층이나 v036 키/14줄 컷을 자동으로 가져오지 않는다.
5. 90/130도·중간 굽힘·비틀림에서 같은 형상을 유지하는지 확인한다. 대표 자세의 시각 검수를 먼저 통과시키고, 그 뒤 기존 전신/새 복합 자세·동작 재로드 검사를 한다. 접촉·압축·면 교차·원형을 각각 보고한다.
6. PC Unity/VRChat 구동 가능한 변형으로 마무리한다. Blender에서만 동작하는 드라이버 결과를 완성본으로 전달하지 않는다. Unity 작업 전 본/접힘 정리라는 사용자 순서를 유지하되, 사용할 구동 방식의 호환 여부는 미리 확인한다.

이 계획은 기존 승인 범위 안의 다음 편집 순서이며 이번 응답에서 새로 완성한 모델이라는 뜻이 아니다. 구체적인 정점 수·이동량은 목표 포즈와 편집 영역을 확인한 뒤 기록한다.

## Blender MCP 판단

현재 세션에 호출 가능한 Blender MCP 도구는 없다. 다만 로컬 Blender Python으로 파일 로드, 기존 정점·면·본·웨이트·키 편집, 평가 메시 읽기와 렌더는 이미 실행 가능하다. 따라서 이번 문제의 주된 원인을 MCP 부재로 볼 근거는 없다. MCP는 열린 Blender와 상호작용하는 경로를 늘릴 수 있지만 좋은 면 흐름이나 보정 형상을 자동으로 결정해 주지는 않는다.

설치는 이번에는 하지 않았다. 사용자의 조건부 설치 허가는 유지하며, 실제 편집에서 현재 접근으로 부족한 기능이 확인되면 설치·연결 검증을 진행한다. 설치만으로 문제가 해결된다는 약속을 하지 않는다.
