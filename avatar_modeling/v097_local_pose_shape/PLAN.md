# v097 — 기존 주름의 국소 포즈 보정

v094의 CGDive·Blender Studio 포즈 보정 자료를 적용한다. v095 단면 평균은 높은 팔에서 날카로운 끝을 줄였지만 다른 자세에 회귀가 있었다. 이를 전체 자세의 웨이트로 쓰는 대신, 옆 올림 120 명령 자세의 국소 목표로만 삼는다. 목표 9점의 변위를 기존 연결 2겹 이웃까지 완만하게 분산하고 3겹 경계는 고정한다. 새 메시/면/본 없이 기존 정점 Shape Key 사본을 만든다.

25/50/100% 목표를 비교한다. 중립값0, 목표값1의 왼쪽 상완·쇄골 quaternion 근방 드라이버로 제한한다. 기본 30자세와 추가 무작위 혼합 회전으로 검사하고 실제 색/와이어 형태를 확인한다. 이것은 Blender 저작 실험이며 VRChat 런타임 드라이버 구현은 아니다. 기본 웨이트·기하·UV는 v089를 유지한다. 전역 681점 ARAP 목표였던 v071과 달리 기존 주름 근방 40점만 대상으로 한다. 회귀가 남으면 통합하지 않는다.
