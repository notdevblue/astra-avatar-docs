# v101 — 반대쪽 소매 뿌리의 독립 곡면

왼쪽 보정값을 오른쪽에 그대로 복사하지 않는다. v089 기존 정점의 좌우 대응을 근접 검색으로 확인하고, 오른쪽의 실제 면 연결과 팔 올림 표면에서 별도 목표를 계산한다. 오른쪽 중립 형태·기존 웨이트·UV·본을 유지한 포즈 키 사본이다. 왼쪽과 별개의 문제 여부와 변화량을 먼저 확인한 뒤 복수 자세 검증을 적용한다. 새 메시 생성/리메시 없음.
