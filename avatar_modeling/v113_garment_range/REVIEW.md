# v113 — 중간 회전에서 생긴 오류를 다시 제한

v112의 넓은 포즈 보정에서 새 오류가 발생한 원래 면을 찾아, 기존 점의 보정 강도를 줄였다. 좌우 앞/옆 키의 기준 형태는 v112에서 매번 다시 읽고 누적 보호 구간만 적용한다. 새 메시나 정지 형태 변경은 없다.

| 반복 | 검증 표본 | 새/해소 면적 | 새/해소 접촉 |
|---|---:|---:|---:|
| 1 | 222 | 7/54 | 0/1 |
| 2 | 222 | 3/43 | 0/2 |
| 3 | 222 | 0/39 | 0/1 |
| 4 | 584 | 3/67 | 0/6 |
| 5 | 584 | 0/62 | 0/6 |

3번째 사본은 기존222에서 새0/0이었지만 **다른 난수320+기본42=362에서 새 면적1·접촉16**으로 실패했다. 이후 이362를 선별 자료에 포함했다. 마지막584는 난수500 + 반복 기본84이며, 독립584나 서로 다른584자세가 아니다. 범위를 계속 수정했으므로 마지막 새 검증은 [v115](../v115_garment_review/START_HERE.md)에서 별도로 수행한다.

5번째 사본 `bianca_GARMENT_GUARDED_05.blend`는 선별584에서 새 면적0/해소62, 새 접촉0/해소6이다. 기존 원형·웨이트·UV·텍스처·본·v108 기존 두 키를 유지했다. 4개 새 키로 기존 소매와 옆 몸판의 포즈 좌표만 보정한다. 단순히 오류를 다른 위치로 옮기지 않는지 절대 늘어남·눌림 분포와 렌더도 후속 검수한다.

늘어남이 모두 사라진 것은 아니다. 보호 구간이 늘어나면서 효과도 줄었으며, 이미 접히거나 겹친 구간은 남는다. `STATE.json`과 반복별 원시 JSON은 실제 수행 이력을 보관한다. `03_render.py`는 준비 파일이며 이 단계에서는 실행하지 않았다. 최종 사본 렌더는 v115에서 수행한다.
