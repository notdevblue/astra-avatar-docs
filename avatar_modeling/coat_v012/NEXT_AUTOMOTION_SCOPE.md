# 다음 구조 변경 제안 — 자동 추종 시험용 부모 제어 4개

> **후속 상태 (2026-09-09):** 사용자가 별도 파일의 부모4개 추가와 기존 비교를 승인하여 [v013 검수](../coat_runtime_v013/REVIEW.md)에서 실행했다. 부모 계층·수동 포즈 비교·FBX 계층/웨이트 왕복검사를 완료했다. 아래는 제안 당시 기록이며, PhysBone/Unity 자동 구동은 계속 미구현이다. 같은4개 추가 승인을 다시 요청하지 않는다.

**제안이며 아직 추가하지 않았다.** v012의 형상/웨이트와 수동 검사 동작은 만들었다. 실제 VRChat에서 몸을 움직일 때 같은 방식으로 자락이 따라가는 단계는 남았다. 기존 8본 시험 승인은 유지되며 이 문서는 그 승인을 다시 묻는 것이 아니다.

## 왜 추가 제어가 필요한가

현재 자락은 hips 바로 아래에 01→02 체인 네 개가 있다. 검사 동작에서는 앞 01의 회전뿐 아니라 깊은 다리 들기에서 뿌리가 바깥으로 최대 20mm 움직여야 했다. 고정된 뿌리의 흔들림만으로 그 경로를 항상 재현할 수 있다고 가정할 수 없다. 몸 추종과 물리를 같은 대상에 중복 적용하는 구성은 [VRChat 공식 주의사항](https://creators.vrchat.com/common-components/physbones/)에 따라 피한다.

## 사본에서 추가할 구체적인 범위

| 항목 | 범위 |
|---|---|
| 기준 | `bianca_COAT_8BONE_WAIST_COVERAGE_TRIAL.blend` |
| 저장 | 새 `coat_runtime_trial` 폴더의 별도 Blender/FBX/Unity 검수본 |
| 추가 제어 | `coat_anchor_front.L/R`, `coat_anchor_back.L/R`의 4개 부모 제어 |
| Blender 표현 | 직접 메시를 변형하지 않는 본 4개. 기존 총 28본→32본, 직접 변형 본은 기존대로 유지 |
| 부모 관계 | 기존 hips → 새 anchor → 기존 coat 01 → 기존 coat 02 |
| 배치 초안 | 앞 anchor는 각 앞 01 뿌리에서 Y +.060m, 뒤 anchor는 뒤 01 뿌리에서 Y -.050m. 기존 자락 뿌리의 중립 월드 위치는 보존 |
| 이유 | 짧은 부모 구간의 회전으로 자락 01의 뿌리에 옆 방향 이동 여유를 마련하는 시험 |

| 메시/텍스처 | 정점·면·중립 외형·UV·텍스처 변경 없음 |
| 추가 메시 | 없음. 표시용 뼈/충돌체는 렌더 자산을 새로 만드는 작업이 아님 |

배치는 현재 약 1m 스케일 기준의 **시험 시작점**이며 Unity 변환 후 같은 수치를 그대로 입력하지 않는다. 본 축·스케일·부모 변환을 FBX 재가져오기에서 먼저 확인한다. 4개를 추가하면 성공한다는 보장은 없으며, 기존 8본을 유지한 결과와 직접 비교한다.

## 물리/추종을 적용하는 순서

1. 새 부모의 작은 수동 회전으로 기존 254표본 검사 중 대표 자세의 뿌리 이동을 재현한다. 기존 수동 값의 큰 선형 이동을 그대로 강제하는 대신 짧은 호로 움직였을 때 형태가 유지되는지 본다.
2. 가능한 PC 환경에서 부모의 몸 추종과 자식 PhysBone의 적용 대상을 분리한다. 임의 C# 런타임 스크립트에 의존하지 않는다. 키프레임으로 정해진 동작과 자유로운 추적 동작을 구별한다.
3. 좌우 허벅지 캡슐과 팔의 접촉 부위에 충돌체를 배치한다. 시작 구성은 허벅지 2개, 상완/전완 4개로 총 6개이며 기본 반경·길이는 실제 모델로 맞춘다. 자락이 콜라이더 위로 과하게 뜨면 반경을 키워 관통을 가리는 식으로 완료 처리하지 않는다.
4. 느린 다리 들기/앉기, 좌우 반전, 숙임/비틀기, 정지 복귀를 먼저 확인한다. 이후 빠른 동작과 접촉을 확인한다. 실제 SDK 성능 수치를 읽기 전에는 PC 등급 합격을 주장하지 않는다.
5. 환경이 준비되지 않았거나 라이선스/공식 지원 버전이 맞지 않으면 실제 원인을 확인해 기록한다. 코드 작성·컴파일·Blender 렌더를 VRChat 실행 검증으로 대체하지 않는다.

## 별도 승인 없이 확대하지 않을 것

4개 이상의 추가 제어, 체인 길이의 계속 증가, 메시 분리·새 토폴로지·형상 재생성, 원래 몸 20본의 구조 변경을 이 제안에 포함하지 않는다. 기존 옆기울임의 팔/몸통 겹침과 무릎/겨드랑이 변형은 별도 원인 검토 대상으로 남긴다.

## 의견 확인 이유

사용자가 **“뭔가 만질 때 수정이 크면 내 의견 물어봐”**라고 명시했다. 이번 추가는 이미 승인된 8본의 위치·웨이트 보정에서 더 나아가 **새 부모 계층 4개와 실제 자동 구동 구조를 넣는 변경**이다. 따라서 실제 변경 범위를 먼저 제시한다. 이 문서 작성 시점에는 4개 제어 본과 Unity 물리 설정을 실행하지 않았다.
