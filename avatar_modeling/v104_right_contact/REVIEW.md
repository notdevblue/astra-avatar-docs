# v104 — 수정 범위 밖 고정 면까지 접촉 조건 확장

v103의 새 접촉은 오른쪽 원래면 8684와 8682/8648 사이였다. 8684는 수정점이 없는 면이라 기존 영역 내부 검사에서 빠졌다. 실제 전체 메시에서 활성 434자세의 이 두 쌍을 조사해 29,601개 분리 축 조건을 만들었다. 기준부터 교차한 삼각 쌍 183개는 새 교차 방지 조건에서 제외했다.

오른쪽 기존 54점 중 사각면 경계 16737의 보정은 0으로 고정했다. 세 번의 적합과 영역 내부 근접 검사로 조건은 31,527개가 됐다. 마지막 캐시에서 새 면적 경고 0, 해소 412, 최대 보정 7.570mm, 평균 1.568mm. 최대 선형 조건 위반은 0.000827mm였다. 각 적합은 1,200회 반복 상한에 도달했으므로 수렴 완료로 표현하지 않는다.

새 메시·정점·면·본을 만들지 않았다. 산출물 RIGHT.npz는 기존 점의 포즈 보정이다. 캐시 수치만으로 채택하지 않고 v105 별도 통합본에서 실제 Blender 면 분할·접촉과 새로운 회전을 검증한다.
