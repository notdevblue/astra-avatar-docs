# v169 — 정지 상태에 새겨진 깊은 홈을 국소적으로 완화하는 별도 실험

v166은 포즈 보정만으로 기존 주름을 유지하려다 회귀가 반복됐다. v168 고정 삼각면에서는 원래 홈 일부가 더 뚜렷했다. 따라서 기본 정장 어깨선은 유지하면서, 그 아래의 작은 오목한 골만 기존 정점으로 완화하는 다른 원인을 시험한다.

[Blender Fill 설명](https://docs.blender.org/manual/en/2.90/sculpt_paint/sculpting/tools/fill.html)은 기준면 아래의 정점만 위로 올리는 도구이며, [Blender4.4 Plane Brush 설명](https://developer.blender.org/docs/release_notes/4.4/sculpt/)은 Fill/Flatten/Scrape의 범위를 구분한다. 접근 가능한 검색 설명을 참고하며 전체 문서나 영상 정독을 주장하지 않는다. 실제 작업은 UI 브러시를 자동으로 썼다는 뜻이 아니라, 대응되는 국소 오목함 측정을 코드로 계산하는 실험이다.

v165 복사에서 코트 어깨/상완의 기존 정점만 선택한다. 이웃 평균으로 향하는 성분 중 표면 법선 방향의 양수 성분만 사용하여 오목한 부분을 채운다. 접선 이동과 볼록한 어깨선 낮추기는 하지 않는다. 경계는 연속적으로 감쇠하며 최대1.5mm와3mm 두 안을 비교한다. 모든 기존 모양키에도 같은 rest 이동을 더하여 상대 보정벡터를 유지한다. 새 정점/면/캐릭터 메시를 생성하지 않는다. 기본 위치가 바뀌므로 원형좌표 exact라고 보고하지 않는다.

중립/앞/뒤/옆 들기, 비틀기/몸통 복합, 새 면적 경고와 자기 교차, 실루엣과 음영을 검사한다. 기존봉제선이 사라지거나 불필요하게 부풀면 제외한다. 사용자가 허용한 별도 파일의 기존 메시 수정 범위로 진행하며, 채택 전 변경 크기와 그림을 문서화한다.
