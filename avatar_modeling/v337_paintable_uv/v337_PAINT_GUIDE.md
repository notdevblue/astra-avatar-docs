# v337 · 채색 파일 사용법

`bianca_v337_UV_DETAIL_REVIEW.blend`의 Paint 재질과 활성 `V337_UV`를 사용합니다. 기존 `V324_UV` 등은 원본 비교·되돌리기 용도로 남겼으며, 새 그림을 그리는 기준은 V337_UV입니다. Head는 원래 UV와 그림을 유지합니다.

![부위 지도](images/v337_PAINT_REGION_MAP.png)

`paint_guides`에 다음 파일이 있습니다. 모델과 함께 작업 저장소에 보관하며 공유 문서 저장소에는 그림 안내만 포함합니다.

| 파일 | 용도 |
|---|---|
| `v337_UV_WIRE_4096.png` | 4096² 투명 UV 선. 새 채색 레이어 위에 임시 표시 |
| `v337_UV_LAYERS.svg` | coat/pants/hands/shirt/shoes/details 그룹별 벡터 선 |
| `v337_MASK_coat.png` 등 여섯 MASK | 흰색 영역이 해당 부위. 다른 부위로 칠이 번지지 않게 선택 |
| `v337_PANEL_INDEX.json` | C001~C541의 부위·패널·픽셀 범위·원래 면 대응 |

추천 순서는 코트와 바지의 넓은 색 → 소매·주름 연결 → 셔츠·신발 세부 → 손과 장식입니다. 원래 전사 이미지를 잠근 바탕 레이어로 두고 별도 레이어에서 수정합니다. 여섯 마스크는 구역 선택용이며 픽셀 경계의 안티앨리어싱이나 색 확장을 대신하지 않습니다. 경계 작업 뒤에는 실제 3D 화면과 축소 화면을 확인합니다.

큰 패널은 연결돼 있지만 모든 부위가 한 조각은 아닙니다. 셔츠의 굴곡과 신발의 밑면 경계는 2D에서 선을 긋는 것보다 3D 투영으로 확인하며 그리는 것이 안전합니다. 얇은 장식은 의도적으로 최소 픽셀 폭을 확보했습니다. 전체 아틀라스를 블러 처리하면 보존한 단추·솔·머리 디테일을 다시 잃을 수 있으므로 국소적으로 작업합니다.

Blender 파일에는 텍스처를 패킹했고 Paint 이미지 노드와 UV를 선택해 두었습니다. UV 이미지 편집기가 있는 화면은 새 Paint 이미지를 표시합니다. 전사 원본을 보존하려면 채색을 시작할 때 새 버전의 이미지와 blend 사본으로 저장합니다.
