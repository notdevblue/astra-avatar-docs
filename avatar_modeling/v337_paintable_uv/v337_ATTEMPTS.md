큰 패널과 낮은 왜곡은 항상 동시에 좋아지지 않았습니다. 셔츠·신발 일부의 늘어짐은 원래보다 높고, 작은 조각도204개 남습니다. 이를 없애려고 모든 면을 다시 합치거나 잘라내면 기존의 심한 왜곡/파편화 문제로 돌아가므로 이번에는 큰 면의 채색 편의와 원래 디테일 보존을 우선했습니다.

Unity의 최종 12구도는 사진 전체가 원본과 비트 단위로 같지는 않습니다. 구도별 30/255 초과 차이는0~16픽셀, 최대 채널 차이는109/255입니다. 신발·옷 외곽의 드문 픽셀 차이가 남으며, 특정 뒤트임 영역의 개선을 전체 화면 오차0으로 확대하지 않습니다. 기본색 전사와 축소·셰이더·윤곽의 차이를 구분했습니다.

방법 조사에는 제작자가 공개한 [xatlas 옵션 정의](https://github.com/jpcy/xatlas/blob/master/source/xatlas/xatlas.h)와 [Python 바인딩 설명](https://github.com/mworchel/xatlas-python)을 확인했습니다. 분할 결과의 원래 정점 대응을 검증하고 원래 사각형 단위로 결합했으며, 최종 펼치기·패킹·전사는 Blender에서 수행했습니다. xatlas를 모델 재생성이나 리메시 도구로 쓰지 않았습니다.

원시 분할 후보와 검사 값은 작업 저장소의 `trials/` 및 JSON 파일에 기록합니다. 실패 후보를 최종 모델에 자동 합치지 않습니다. 진단 중 Vector2의 JSON 직렬화 순환 참조 오류는 스칼라 배열로 바꿔 해결했으며 모델 문제와 구분합니다.
