# v182 골반·사타구니의 국소 웨이트 실험

v181에서 BodyHair 면적 경고 269건 중 바지205건을 확인했다. 특히 중앙 사타구니 일부는 골반 영향이 거의 없고 양 허벅지의 서로 다른 움직임을 직접 혼합한다. 위쪽 고관절 접힘은 hips/thigh/hip_support 혼합 부위에 집중된다. 이것이 모두 오류라는 뜻은 아니며 실제 접촉과 외형으로 판별한다.

기존 정점·원형·키·UV·본을 보존한 채, 바지의 중앙 골반 지지 및 위쪽 고관절 보조 비중을 별도 후보로 실험한다. 무릎 이하와 다른 메시 웨이트는 보호한다. 최대4영향을 유지하고 변경 강도/반경을 작은 값부터 비교한다. 경고가 줄어도 신규 경고·관통·실루엣 악화가 있으면 채택하지 않는다.

참고: [Autodesk 하체 웨이트 튜토리얼](https://download.autodesk.com/us/3dsmax/2012tutorials/files/GUID-4F676CAA-1C0A-465F-BD0E-19AF4B1F0B14.htm). 골반 정점에 과도한 허벅지 영향이 있는지 확인하고, 중앙과 허벅지의 역할을 나누어 운동시키며 검사한다. 특정 예제의 정점별 값을 비앙카에 그대로 적용하지 않는다.

233자세는 개발용 회귀 검사이며 독립 검증이 아니다. 선별된 후보는 다른 seed/더 넓은 복합 움직임과 실제 Unity 재생·다각도에서 다시 검사한다.
