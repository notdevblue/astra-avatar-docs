# v184 손·바지 기존 사각면의 대각선 검토

v182 골반 국소 웨이트는 개발233자세에서 개선됐으나 별도433자세에서 새43/해소88사건으로 미채택. v183 어깨 제한 웨이트도 별도433자세에서 새189/해소187로 미채택한다.

이번에는 변형 입력과 정점 위치를 모두 보존하고, BodyHair의 기존 사각면 내부 두 삼각형의 대각선만 비교한다. 좁은 손가락 사이 면과 골반 접힘에서 원래 긴 대각선이 수치/외형 불안정을 키우는지 분리한다. 새 캐릭터 메시·정점 생성은 하지 않는다.

선별 기준: 기존233+433 자세 전체에서 해당 사각면의 신규 면적 경고가 없어야 한다. 정지 상태의 비평면 차이가0.2mm 이내이고 UV/법선/웨이트가 같은 원래 코너만 사용한다. 이어서 별도 자세, 교차, 실제 재질 사진을 확인한다. 삼각면 번호가 바뀌므로 공정 비교를 위해 같은 원래 사각면을 묶어 경고 여부를 비교한다. 모든 면의 균일 삼각화나 일반 리메시는 하지 않는다.

Blender Triangulate Modifier의 Fixed/Fixed Alternate 및 대각선 선택 방식은 구조적 참고다. 어떤 대각선이 이 모델의 움직임에 유리한지는 실제 포즈 데이터로 판단한다.
