숨은 면 전체 렌더만으로 부위의 의미까지 검증했다고 생각한 점이 부족했다. 넥타이는 사용자 지적 후에야 잘못된 셔츠 분류를 발견했다. 현재 목록을 수정했고, 이후에는 카라·넥타이·단추처럼 서로 접하는 재료 경계를 연결해서 검토한다.

모든 창작용 래스터 편집은 내장 image_gen을 사용했다. 기본 패널의 최종 프롬프트·출력 여부는 `GENERATIONS.json`, 장식 재실행은 `ACCESSORY_GENERATION.json`, 넥타이는 `TIE_GENERATION.json`과 `TIE_REFINE_GENERATION.json`에 기록했다. 채택 영역·강도는 `APPLIED_PATCHES.json`과 `TIE_FIX.json`에 있다. 입력·출력·마스크·전달 아틀라스는 작업 버전 폴더에 저장했다. API/CLI 생성 대체는 사용하지 않았다.

모델 검수 사진은 Unity/Blender 렌더이며 생성 도구로 수정하지 않았다. 텍스처 소스 생성 이미지와 실제 모델 비교 사진을 구분했다. 미채택 시험과 재배치만 한 비교용 아틀라스는 최종 전달 파일을 대체하지 않는다.
