# v183 실제 Unity 입력을 이용한 어깨 국소 웨이트 후보

v181에서 기존 보정키 ON/OFF를 분리했다. 앞팔 경고는 ON10 / OFF12이며, 233자세 전체에서 기존키가 11사건을 개선하고4사건을 추가한다. 보정 전체를 끄지 않는다.

기존 위치·키·UV·본은 보존하고 소매/몸통 경계의 상완 비중을 원래 값의 0.7–1.3배 이내에서 조절한다. 합을 다시 정규화해 최대4영향을 유지한다. 내보내기로 나뉜 중복 정점은 원래 Blender 정점 단위로 함께 처리한다.

이번 시도는 모든 어깨를 한 비율로 덮는 방식이 아니라, 실제233자세의 본 행렬과 기존키 변형에서 압축되는 면을 대상으로 제한된 수치 최적화를 수행한다. 작은 변경량과 이웃 간 매끄러움을 함께 요구한다. 이 개발용 자세에서 좋은 값이 나와도 독립433자세, 교차, 원형/다각도 실루엣 검사를 거쳐야 한다. 기존v180 또는 골반후보에 자동 채택하지 않는다.

근거는 v181의 Autodesk 어깨 영향본 개별 확인 튜토리얼과 v182 하체 튜토리얼의 국소 조정/움직임 확인 원칙이다. 수치 목적함수는 이 프로젝트의 실험 설계이며, 튜토리얼이 이 알고리즘의 성공을 보장하는 것은 아니다.
