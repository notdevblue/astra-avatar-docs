# v350 — 미채택 분리 실험

사용자 피드백: UV를 파편처럼 조각내지 말고 일반적인 캐릭터의 연결된 부위 전개로 만든다.

이 실험은 기존 조각을 부위별 파일로 재배치했다. 픽셀 왕복은 보존했지만 얼굴 161조각·헤어 1313조각 등 기존 파편화를 유지하여 요청한 작업성에 미달했다. 채택하지 않는다. 현재 사용 기준은 v348이다.

후속은 v351_conventional_uv에서 기존 물리 표면의 연결을 기준으로 의미 있는 이음선을 다시 설계한다. 모델 형상·웨이트·본·표정은 보존한다. 단순 차트 수 감소나 수치 통과를 작업성 합격으로 보지 않는다.
