# 기존 어깨 지지 본의 역할 재검토

v042 실제 웨이트에서 기존 shoulder_support.L/R 본의 최대 웨이트는0이었다. 본이 존재하는 것과 실제 부피를 지지하는 것은 다르다. v043에서 새 보조본을 추가한 시험만으로 어깨 구조를 확정하지 않고, 기존 보조본에 상완과 몸통의 공통 웨이트를 옮긴다. 기존 본 중심/15mm 아래/15mm 바깥/15mm 안쪽을 각각 사본에서 비교한다.

손에서 중간 마디 보조본의 중심을1.5mm 바깥으로 옮기자 같은300표본 경고가17→3으로 줄었다. 반대 방향은76으로 악화됐다. 이 원리를 어깨에 그대로 정답으로 복사하지 않고, 옷의 압축부/견봉/옷깃에 맞게 별도 검증한다. 옷깃은 범위에서 보호하며 최대4영향을 유지한다. 새 메시·새 본·정점 이동 없는 시험이다.
