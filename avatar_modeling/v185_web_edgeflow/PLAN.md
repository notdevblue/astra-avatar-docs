# v185 손가락 사이의 인접 삼각면 흐름 검토

v184의 기존 사각면 대각선 수정과 독립적으로, 남은 손가락 사이의 좁은 면을 확인한다. 특히 v181에서 반복26번 경고된 오른손 삼각면4913은 기존 사각면만 바꾸는 방법으로 다루지 못했다.

기존 두 인접 삼각면의 공유 edge를 반대 대각선으로 옮기는 후보를 비교한다. 새 정점·새 캐릭터 메시 생성 없이 연결만 수정한다. 기존 코너의 UV/법선/웨이트가 일치하고, 반대 대각선이 이미 존재하지 않으며, 뒤집힌 면/겹친 경계가 되지 않는 경우만 허용한다. v184 채택 후보와 같은 면은 제외한다.

233+433+533 실제 Unity 자세 자료에서 같은 원래 두 면 영역을 묶어 경고를 비교한다. 교차/정지 표면 오차/확대 사진이 통과하기 전에는 채택하지 않는다. 이 자료는 선별용이며 별도 검증에서 발견되는 회귀는 다시 기록한다.
