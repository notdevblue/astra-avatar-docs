# Bianca — 국소 색 보정·몸 웨이트 수정 v002

2026-09-09. 사용자가 승인한 작은 수정 범위의 **1차 적용본**이다. 최종 디자인/최종 아바타 채택을 뜻하지 않는다.

## 적용 결과

- 원본 모델을 재생성하지 않았다. **정점 이동 0, 추가/삭제 정점 0, 추가/삭제 면 0, 컷 추가 0.** 기존 정점·에지·면·UV가 최초 가져오기 검수본과 동일하다.
- 헤어에 묻은 피부색, 이마·볼에 칠해진 검은 헤어 무늬를 기존 재질의 국소 마스크와 색 기준으로 줄였다. 원래 JPG는 그대로 보존했다.
- 보정은 생성형 이미지나 3D 재생성 없이 Blender의 기존 재질 노드에서 수행했다. 피부/헤어 분리 마스크와 밝기 조건으로 적용 범위를 제한했고 기존 UV에 4096×4096 PNG로 베이크했다. 귀와 눈의 원래 채색을 보호하는 영역을 두었다.
- 팔을 올릴 때 안쪽 소매가 몸통에 붙잡히던 웨이트를 수정했다. 겨드랑이 아래의 메시 연결 관계로 소매와 재킷 몸통을 구분해 팔 웨이트를 다시 할당했다. 어깨와 무릎에 국한해 웨이트를 부드럽게 조정했다.
- 기존 20개 본의 위치와 기본 형상은 유지했다. 이번 개선은 웨이트로 얻었으며, 큰 형태 변경이나 추가 컷의 필요성을 먼저 가정하지 않았다.

## 같은 자세의 정량 비교

아래 수치는 면적이 1e-10보다 큰 원본 면을 대상으로 한 변형 시험 지표다. '3배 초과'는 굽힌 면의 면적 / 기본 자세 면적 > 3, '20% 미만'은 < 0.2를 뜻한다. 조명이나 텍스처의 영향을 받지 않지만, 실제 게임 품질과 관통을 모두 평가하는 지표는 아니다.

| 자세 | 면적 3배 초과: 전 → 후 | 면적 20% 미만: 전 → 후 |
|---|---:|---:|
| 양팔 올리기 | 76 → **2** | 4 → 4 |
| 팔꿈치 90도 | 0 → 0 | 2 → **0** |
| 한쪽 무릎 90도 | 0 → 0 | 1 → **0** |
| 고관절 + 무릎 | 0 → 0 | 9 → **6** |
| 머리 회전 | 0 → 0 | 0 → 0 |

양팔 올리기의 최대 면적 배율은 약 5.873 → 3.015로 줄었다. 전후 렌더에서도 소매의 늘어진 삼각형 형태가 크게 줄어든 것을 확인했다. 무릎의 각짐과 앉는 자세의 재킷 자락 겹침은 아직 남는다. 지금의 본/웨이트는 몸 검토용이며 손가락·표정·물리까지 완성한 리그가 아니다.

## 검증과 제외한 시험

1. 원본 ZIP의 SHA-256 보존을 다시 확인했다.
2. 최초 검수본, 이전 임시 리그, 재질 노드 보정본, 베이크 적용본의 네 파일을 재로드해 정점 좌표·에지·면 연결·UV 해시가 동일함을 확인했다.
3. 사각형 13,710개 + 삼각형 3,845개, 총 17,555 faces / 31,265 triangles 유지. 크기 약 0.9995m 유지.
4. 전 정점 웨이트 할당, 최대 4본, 합 오차 1e-6 미만, 동일 위치 분할 정점의 웨이트 일치를 확인했다.
5. 타임라인 1~121 **모든 프레임**의 좌표 유효성, 메시 정점 수 유지, 면적 비율을 검사했다. 주요 여섯 자세는 렌더로 비교했다. 좌표 유효성 통과는 관통/미관 문제까지 해결됐다는 뜻이 아니다.
6. 동일 카메라의 재질 노드 결과와 베이크 결과를 비교했다. RGB 평균 차이 0.132/255, 채널 차이 99백분위 2/255, 어느 채널이든 10/255를 초과한 픽셀은 0.0165%다. 최대 62/255의 일부 경계 차이는 남으므로 텍스처가 픽셀 단위로 완전히 동일하다는 주장은 하지 않는다.
7. 단순한 넓은 웨이트 스무딩은 팔꿈치/앉는 자세를 악화시켜 제외했다. 개선된 소매 구분 방식에서 12/36/72회 범위의 국소 스무딩을 비교해 결과가 나은 72회를 선택했다. 무릎은 12회로 제한했다. 상세 `weight_verification.json`.
8. 눈의 흰 부분을 홍채색으로 채우는 시험은 실제 홍채 조각을 더 크고 둥글게 보이게 해 **제외했다**. 최종 적용본에 홍채색 채우기는 포함하지 않았다. 귀를 어둡게 만들던 초기 헤어 마스크도 범위를 좁혀 수정했다.

## 남은 문제와 사용자 의견이 필요한 범위

- **눈:** 홍채 조각과 그려진 눈의 위치/범위가 맞지 않는 부분, 눈 아래 흰 원형 선, 가려진 눈의 채색 차이가 남는다. 색만 바꾸는 시험이 눈 인상을 바꿨으므로 눈 주변은 유지했다. 홍채 조각의 위치·크기와 해당 UV를 함께 다루는 수정은 얼굴 인상에 영향을 줄 수 있어 사용자 의견을 받은 뒤 별도 비교본으로 진행해야 한다.
- **헤어:** 피부색 번짐은 줄었으나 일부 회색/갈색 얼룩과 두꺼운 말림, 면 경계가 남는다. 덩어리 실루엣의 재설계는 하지 않았다.
- **얼굴:** 헤어를 숨기면 투영 얼룩과 색 경계가 일부 남는다. 눈썹·눈선을 보호한 국소 보정이므로 전체 얼굴을 새로 칠한 결과가 아니다.
- **몸:** 무릎의 각진 접힘과 겨드랑이 일부 압축, 앉을 때 자락/허벅지 겹침은 남는다. 남은 문제 때문에 자동 리메시나 전체 재생성을 수행하지 않는다. 추가 컷/정점 수정은 실제 필요한 부위를 제한한 후 비교해야 한다.
- 손가락 본, 눈 감기·입 벌림, 립싱크, 헤어·넥타이 물리, Unity/VRChat 실행 검증은 이번 범위에 포함하지 않았다.
