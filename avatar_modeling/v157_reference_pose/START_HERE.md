# v157 — Lapwing·SiuSiu 관절을 실제로 움직여 비교

2026-09-11. **두 구매 모델을 Unity Play Mode에서 실제로 굽히고 돌렸다.** 이전 v153/v156의 정적 구조 조사에서 확인하지 못했던 보조 본의 작동과 변형 결과를 이번에 검사했다. 비앙카는 v152 그대로이며 이번 결과는 참고 모델 동작 조사다.

핵심은 **SiuSiu의 정장 어깨 형태, Lapwing의 관절 부분 회전, 두 모델의 전완 비틀기 분산과 제작자 손 제스처를 나눠 참고하는 것**이다. 다른 모델도 깊은 굽힘에서 주름·접촉·각진 부분이 생긴다. 모든 관절이 무조건 매끈한 정답 모델로 취급하지 않는다.

## 실제 시험 조건

Unity **2022.3.22f1**, VRChat SDK **3.10.5**를 별도 프로젝트 `.venv/reference_pose_unity`에 준비했다. 원래 Unity 프로젝트와 구매 ZIP은 수정하지 않았다. FBX에 임의의 Blender 제약을 붙여 흉내 낸 결과가 아니다.

| 구성 | 시험 상태 |
|---|---|
| SiuSuit | SiuSiu Standard 프리팹. 동봉 BlazerOnly 클립의 의상 표시·축소 값 적용 |
| SiuBody | 같은 프리팹에서 Body_Base만 표시하고 shrink 키를 0으로 설정. 옷 안으로 숨기기 전 몸체 확인 |
| LapSuit | Lapwing 기본 의상 프리팹 |
| LapBody | Lapwing T-body 프리팹의 Body2 표시. 의상용 생략 몸체와 구분 |
| SiuKisekae | SiuSiu Kisekae 프리팹. Standard와 다른 제약 구성을 그대로 유지 |

각 구성에 38개 자세 (공유본 미포함: `POSE_PLAN.json`), 총 **190개 구성×자세 기록**을 남겼다. 정지 자세별로 15프레임 평가한 뒤 실제 본 회전과 Unity BakeMesh 정점 좌표를 수집했다. 연속 애니메이션 190개를 재생했다는 뜻은 아니다.

- 어깨 앞30/45/60/90/120°, 뒤35/60°, 옆90/120°, 앞90°+비틀기±60°, 쇄골 병행2조건.
- 팔꿈치45/90/135°, 전완 비틀기±80°, 손목 굽힘±60°, 손 펴기·일반 주먹·동봉 주먹.
- 무릎60/90/135°, 고관절80°+무릎30°, 고관절70°+무릎110°.
- 목 좌우60°/앞뒤30°, 척추 회전40°/굽힘35°, 발목±35°, 원래 자세와 팔 내린 기준.

Animator는 꺼서 시험 자세를 덮어쓰지 않게 했고 **원래 Unity/VRC Constraints는 켰다. PhysBone은 껐다.** 따라서 바람·옷자락·헤어 물리, VRChat IK, Animator/FX 전체 조합, VRChat 빌드 후 제약 변환과 실제 클라이언트는 이번 통과 범위가 아니다. 고각도 상완 단독 시험은 스트레스 검사이며 실제 사람이 쇄골을 고정하고 그 범위까지 움직인다는 해부학적 주장도 아니다.

Unity/VRC 제약의 로컬·월드 공간 차이를 확인하고 원래 설정을 유지했다. [VRChat 공식 Constraints API](https://creators.vrchat.com/common-components/constraints/constraints-api/) 참고. Lapwing은 이 실행에서 원래 Unity Constraint 솔버로 평가했으며 VRChat 빌드의 변환 결과까지 동일하다고 주장하지 않는다.

## 본이 실제 작동하는지도 확인했나

같은 입력 자세에서 제약 ON/OFF 대조군을 따로 실행했다. 아래는 본의 **로컬 회전 차이**이며 표면 부피 복원율이나 지정 회전 가중치 자체가 아니다. 원래 회전 offset과 나머지 제약 영향이 포함된다.

| SiuSiu LowerArm_Twist_L | 손 비틀기80° | 40.0004° |
| Lapwing LowerArmTwist_L | 손 비틀기80° | 48.3326° |
| Lapwing LowerElbow_L | 팔꿈치90° | 43.0470° |
| Lapwing LowerLegKnee_L | 무릎135° | 64.7268° |

대조군 결과 (공유본 미포함: `CONSTRAINT_PROOF.json`). 본이 존재한다는 사실만 보고 작동한다고 판단하지 않았다.

SiuSiu Standard/Kisekae도 별도로 확인했다. N→손 비틀기80°에서 해당 전완 Twist의 로컬 회전 변화는 **Standard 40.0004°, Kisekae 0°**였다. v156에서 찾은 4개 Twist 제약 부재가 실제 실행 차이로 이어진다. Kisekae 소매가 같은 자세에서 다르게 접히는 사진도 있으나 이 한 동작만으로 전체 구성의 우열을 매기지 않는다.

## 어깨 수치 — 해석 범위를 제한한다

팔 내린 N 자세에서 왼쪽 상완 길이로 정규화한 고정 구역을 잡았다. 앞90° 결과를 강체 정렬한 뒤 전후 폭 비율과 삼각형 면적 비율을 구했다. 상세 선택식은 분석 코드 (공유본 미포함: `analyze.py`), 전체 수치는 POSE_METRICS.json (공유본 미포함: `POSE_METRICS.json`)에 있다.

| 앞90° 구역 | N 대비 전후 폭 | 삼각형 면적 비율 95백분위 |
|---|---:|---:|
| SiuSiu 블레이저 | 99.1% | 1.19배 |
| Lapwing 볼레로 | 96.7% | 1.74배 |
| SiuSiu 축소 해제 몸체 | 91.9% | 2.21배 |
| Lapwing T-body | 102.4% | 2.87배 |

**실제 밀폐 부피가 아니며, 비앙카 v152의 다른 소매산 구역에서 측정한 89.8%와 직접 순위를 매기면 안 된다.** 체형·면 밀도·기본 자세·의상 구조가 다르다. 아웃라인용 형상과 겹친 면도 수치에 포함될 수 있다. 몸체 축소 상태의 수치는 해부학적 두께 판단에 쓰지 않는다. 이번 표는 같은 모델에서 의상과 몸체가 서로 다르게 변형된다는 참고 자료다.

## 다음 비앙카 수정에 적용할 순서

1. v152의 몸판·소매산·겨드랑이·카라를 고정 구역으로 나누고, 앞/뒤 동작의 본별 기여와 실제 표면 이동을 함께 표시한다. 원래 정장 어깨선과 외형을 기준으로 삼는다.
2. 쇄골 고정/병행 조건을 나눠 원인을 먼저 분리한다. 이후 별도 파일에서 몸판 지지와 소매 회전의 분배를 한 요인씩 바꾼다. 이미 실패한 v047/v058/v154/v155 보조 본·웨이트 실험을 같은 설정으로 반복하지 않는다.
3. 전완 Twist는 비틀기 문제를 대상으로 별도 실험한다. 주먹은 실제 쓸 손 제스처와 엄지 접촉까지 함께 검증한다.
4. 기본·앞45/60/90/120·뒤35/60·옆90/120·비틀기 조합에서 두께, 봉제선 길이, 국소 면 늘어남, 접촉과 다각도 실루엣을 동시에 비교한다. 특정 각도 한 장만 좋아진 결과는 채택하지 않는다.
5. 형태가 안정되면 Unity/VRChat 구동 변환·실제 IK·PhysBone·원래 재질까지 검증한다. 이번 참고 조사만으로 비앙카가 Unity 작업 준비를 끝냈다고 하지 않는다.
