# v181 미해결 경고의 부위 분류

v180과 같은 실제 Unity 233자세를 재생하고, SDK 보정 결과·본 행렬·기존 웨이트를 추출했다. 이 버전은 진단 자료이며 모델 변경본이 아니다.

| 부위 | 면적 경고 사건 |
|---|---:|
| 바지 | 205 |
| 양손 | 61 |
| 셔츠 | 3 |
| 코트 | 104 |

BodyHair라는 객체 이름 때문에 큰 복합 자세 경고를 머리카락 문제로 묶으면 안 된다. 이번 경고는 머리카락이 아닌 위 세 부위다. 서로 다른 자세에서 같은 면이 반복 경고된 수도 포함한다.

큰 바지 경고는 골반/허벅지 접힘에 집중된다. 중앙 사타구니에는 골반 지지가 거의 없이 양 허벅지 움직임을 혼합하는 점이 있다. 손은 손가락 사이와 손바닥 쪽의 좁은 면을 추가로 구분해야 한다. 코트 앞팔 경고는 몸통과 소매의 혼합 웨이트 구역에 남아 있다.

실제 Unity 본 행렬과 웨이트로 BakeMesh 결과를 재구성한 최대 오차는 BodyHair **0.000382mm**, Coat **0.000272mm**다. Blender 원래 정점 대응 오차는 두 객체 모두 **0.000089mm 미만**이다. 이후 국소 후보를 동일한 본 입력으로 비교하는 기반으로 사용할 수 있다.

- 면별 원인 자료 (공유본 미포함: `LOCALIZATION.json`): 자세, 삼각면, Blender 정점, 부위, 원래 면적, 변형 면적비, 영향 본별 평균 웨이트.
- [조사와 계획](PLAN.md).
- 실제 다각도 사진은 로컬 `.venv/bianca_joint_localization`에 있다. `179_ArmsForward`, `221_Combined_39`, `225_Combined_43`의 FRONT/REAR/SIDE.
- 후속 변경 후보는 [v182 골반 실험](../v182_pelvis_weights/PLAN.md). v180은 계속 보호한다.

자료 접근 범위: Autodesk 어깨·하체 웨이트 튜토리얼 본문은 읽었다. Blender Armature 본문은 이번 요청에서402로 열리지 않아 검색 요약만 확인했다. Autodesk Pose Space Deformation 페이지는 본문 추출이 되지 않아 기존 설명/검색 요약 수준이다. 영상 전체 시청으로 보고하지 않는다.
