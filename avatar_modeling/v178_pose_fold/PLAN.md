# 동작 중 깊은 옷 홈의 별도 국소 보정

v166은 선 길이 목적함수로 당김을 줄였으나 새 교차가 생겼다. v169는 정지 원형의 홈을 채웠다가 다른 자세에서 회귀했다. 이번에는 **정지 원형은 고정**하고, 기존60/90/120도 앞들기 보정키에서만 국소 오목한 부분을 바깥으로 완화한다.

[Blender Smooth 설명](https://docs.blender.org/UATEST/manual/en/dev/sculpt_paint/sculpting/brushes/smooth.html)은 일반 smoothing이 부피를 줄일 수 있음을 설명한다. 그래서 이 실험은 평균 위치로 당기는 전체 smoothing 대신, 완만하게 평균낸 법선의 바깥쪽으로 향하는 변위만 사용한다. Fill 문서 본문은402로 읽지 못했다. 공식 기능을 그대로 재현했다고 주장하지 않으며, 기존 메시에 적용하는 수치 실험이다.

어깨/소매 기존 정점에만 적용하고 경계를 부드럽게 감쇠한다. 작은1mm/중간3mm/최대6mm 변위 한도 후보를 별도 저장한다. 정지·텍스처·웨이트·본·면 연결은 유지. 먼저 실제 앞90 뒤/아래 사진과 면적/교차를 비교한다. 개선이 확인된 범위만 복합 자세 홀드아웃 검증 후 통합한다.
