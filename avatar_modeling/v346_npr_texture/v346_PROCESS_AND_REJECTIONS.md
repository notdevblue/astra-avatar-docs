# v346 텍스처 재작업 — 원인과 시도 기록

실제 제작·수정·미채택 기록이다. 최종 비교·판정은 [v346 보고](v346_WORK_REVIEW.md)에 연결한다. v345 계획 이후 실제 제작을 재개했으며, 원본 v343과 실험 사본을 분리했다.

## 목표

고품질 애니메이션·일러스트의 NPR 표현을 목표로 한다. 단추 구멍·실·봉제선·옷의 큰 접힘·헤어 가닥을 남기고 흐린 반사와 불규칙한 얼룩을 정리한다. 추가 일러스트는 색면과 선 설계 참고이며 머리 길이·얼굴 인상·체형을 이식하지 않는다.

## 시도와 판단

| 시도 | 확인한 문제 | 대응·미채택 이유 |
|---|---|---|
| 원본 모델을 부위별 6방향으로 분리하여 렌더 | 정면에서 가려지는 소매·코트·바지·헤어 안쪽 누락 | 기존 면의 목록을 기준으로 내부 면을 별도 렌더. 임시 격리 화면이며 모델에 구멍을 저장한 것이 아님 |
| 생성 채색을 기존 UV로 전사 | 생성 그림과 실제 실루엣의 미세한 불일치 | 그림 자체를 완료 모델 사진으로 제시하지 않고, 실제 모델에 적용한 뒤 재렌더 |
| 첫 얼굴 채색 | 눈꺼풀 중복·강한 턱 윤곽선 | 미채택 보존. 원래 눈 위치·외형을 지키는 얼굴 채색으로 교체 |
| 첫 오른 신발 채색 | 앞코·뒤꿈치의 넓고 흐린 반사 | 미채택 보존. 스트랩·봉제선·굽 구조를 남기는 더 명확한 색면으로 재작성 |
| 유색 전경 판정 | 회색·검은 NPR 선이 배경으로 배제됨 | 색상 차이에 의존하는 조건을 제거. 실제 표면과 배경 차이를 기준으로 판정 |
| 숨은 면 추가 채색 | 옆/뒤/안쪽에서 기존 번짐 잔존 | 헤어·코트·양 신발·얼굴을 격리해 추가 전사. 이후 헤어·얼굴·셔츠 잔여도 별도 검사 |
| 가까운 픽셀의 triangle ID/깊이로 가림 판정 | 삼각형 경계의 미전사 픽셀에 v343 색이 남음 | 바지 24,276픽셀에서 확인. 동일 UV 차트 안에서 최대 4픽셀의 전사 경계를 보완. 기존 채색 픽셀은 수정하지 않음 |

## 지워서는 안 되는 디테일

소매 안쪽의 큰 검은 대각선은 v343에도 있는 깊은 주름과 이어진다. 독립 시각 검토에서 필수 오염 판정을 보류로 낮췄다. 코트 뒤 허리의 V자 접힘, 바지 엉덩이 아래·무릎 뒤의 큰 접힘, 신발 스트랩 외곽과 밑창 경계도 구조 디테일로 유지한다. 소매 단추 주변 사각 명암은 원래 겹침·절개와 대조하며, 단추 구멍·실·테두리를 지우는 근거로 쓰지 않는다.

## 검토 분리

시각 검토자는 실제 적용 렌더의 선·번짐·인상·숨은 면을 보고, 기술 검토자는 원형·UV·웨이트와 투영 산술·Unity 설정을 대조한다. 첫 판단은 작업 담당의 선호를 전달하기 전에 각각 받았다. 수치 통과와 시각 통과, 사용자 최종 채택은 구분한다.
