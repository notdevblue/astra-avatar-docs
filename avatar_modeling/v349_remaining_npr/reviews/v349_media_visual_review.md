# v349 실제 SDK GIF 독립 시각 검토

## 결과

**비교 GIF 6개는 검토한 구간에서 움직임과 외형이 유지된다. WorldContact GIF는 캐릭터가 전혀 나오지 않아 전달용 동작 증거로 미통과다.**

0.3mm 패딩 전후는 매우 비슷하다. 크게 흔들림이 개선됐다거나 부드러워졌다고 표현할 근거가 없다. 헤어–코트 기존 국소 교차를 이번 정면 GIF에서 잘 안 보인다는 이유로 해결 처리하지 않는다. 해당 잔여의 확대 검토는 `/tmp/v349_exposed_visual_review.md`와 구분한다.

## 파일·입력 확인

`make_review_media.py`와 `MEDIA_CHECK.json`을 직접 읽고 7개 GIF를 PIL로 프레임 끝까지 디코딩했다. 실제 디코딩 결과도 비교 4개 각 60프레임/10초, Wind 2개와 WorldContact 각 120프레임/20초다. 각 프레임의 표시 시간은 160/170ms 배분이며 총 시간과 일치한다. 시간 보간 없이 실제 기록 매 10프레임을 취한 6Hz 자료다.

비교 순서는 왼쪽 `physics/repeat/frames/OriginalRepeat_*`, 오른쪽 `FinalRepeat_*`이며 GIF 표시 `Original` / `0.3mm padding`과 코드가 일치한다. 좌우 반전 편집은 없다. 단, 여기서 Original은 **v348 Final을 기준으로 한 추가 패딩 0mm 사본**이지 초기 뻣뻣한 원본 모델이 아니다. 보고서에 이를 명시해야 한다.

읽기 전용 SDK 기록 `physics/repeat/RUN.json`의 error는 null이며 Final/FinalRepeat/OriginalRepeat 완료다. `MacRemainingSecondaryAudit.cs`에서 일반 입력은 0~4초, Wind는 0~10초이고 이후 자연 복귀다. 카메라가 루트를 추적하므로 Translation 정면에서 전신의 큰 화면 이동을 기대하면 안 된다.

검토 당시 파일 해시는 `/tmp/v349_media_review/REVIEW_HASHES.json`, 디코딩 확인은 `DECODE_CHECK.json`에 남겼다. 이후 파일이 교체되면 별도 재검토가 필요하다.

## 직접 본 시간 범위

- HeadYaw/Translation Head/Translation Tie/Bend FullSide: 시작 0,0.5,1,1.5초와 2~6초 매 1/6초 연속 프레임, 8초, 마지막 9.833초.
- Wind Head/Tie: 0,2,4,6,8,9.833,10,11,15,19.833초와 2~3.333초 및 10~11초 매 1/6초 연속 프레임.
- WorldContact: 시작/1.833/2/4/6/8/9/10/19.833초 화면 직접 확인, 원본 PNG 120장 전수 단색 여부 검사.
- 선택 시점 시트와 연속 구간은 `/tmp/v349_media_review/v349_*_{overview,active,stop,relax}.jpg`다. 생성만 한 WorldContact active/relax 시트는 시각 검토 근거로 추가 계산하지 않았다.

전체 GIF 디코딩과 **전체 프레임을 하나씩 사람이 시각 검수한 것**은 다르다. 위 시간 밖의 세부 프레임은 시각 미검증이다. 6Hz 사이의 짧은 관통·떨림도 판정 범위 밖이다.

## MED-V349-01 — WorldContact 영상 공백: 수정 필요

GIF 20초 전체 구간에서 캐릭터 없이 배경과 라벨만 보인다. 대표 원본 `world_wind/world_usage/frames/WorldWind_0240.png`를 직접 열었고, **원본 PNG 120장 모두 각각 RGB 고유색 수 1**이다. 따라서 팔레트/GIF 변환 때문에 캐릭터가 사라진 문제가 아니라 원본 촬영 단계부터 빈 화면이다.

검토 당시 공백 원본 — 임시 보존 (공유본 미포함: `WorldContact_BLANK_SOURCE_0240.png`)

시작·중간·끝 공백 (공유본 미포함: `v349_WorldContact_overview.jpg`)

원인 확정 범위는 “촬영 단계 공백”까지다. 카메라 높이/모델 위치·가시성·렌더 조건 중 어느 것이 직접 원인인지는 이번 읽기 전용 검수에서 확정하지 않았다. Unity 장면/브리지는 조작하지 않았다.

`world_usage/RUN.json`의 scenario 1 자료를 따로 확인했다. manual은 .35이며 frame120/240/360/480에서 receiver와 animator_world가 1, frame0/110/540/600/720/1190에서 0이다. 실제 SDK World Usage Sender → Avatar Receiver 수신과 Editor 어댑터 파라미터 전달 기록은 존재한다. **데이터 정상 수신과 시각 동작 검증은 별개다.**

`MacWorldWindAudit.cs`상 첫 Sender 2~8초, 두 번째 6~9초, 다른 태그 10~12초다. 이 GIF는 manual .35가 계속 켜져 있으므로 9초 이후의 기대 상태는 완전 무풍이 아니라 manual .35로 복귀다. 새 영상은 2초 진입, 6초 중복, 8~9초 이탈, 10~12초 다른 태그, 19.833초 상태를 실제 캐릭터와 함께 보여줘야 한다.

## 라벨·클리핑·공유 범위

- 비교 GIF 라벨은 읽을 수 있고 좌우 시간·부위가 일치한다. 세로가 늘어나거나 눌린 비율 왜곡은 보이지 않는다.
- Head는 머리 위와 컬 끝이 화면 안에 있다. Tie는 의도된 몸통 구도로 머리 상단/팔 끝은 잘리지만 매듭과 넥타이 끝은 보인다. 이를 전신 관통 검수로 확대하지 않는다.
- Bend FullSide는 머리부터 신발까지 들어온다. 대상 크기가 작아서 관절 국소 결함 검수에는 원본 확대가 필요하다.
- 6Hz GIF는 빠른 움직임이 계단처럼 보일 수 있다. 연속 프레임의 형태 보존과 복귀는 확인했지만 재생의 부드러움은 30/60fps 실제 영상으로 별도 확인해야 한다.
- WorldContact는 Editor 어댑터 실제 수신 실험이며 PC VRChat 클라이언트 동작/네트워크/월드 호환 합격이 아니다. 공백을 수정하기 전 동작 성공 GIF로 게시하지 말 것.
- 프로젝트 파일/자산/문서/Unity 수정은 0이다. 본 보고와 검수 시트만 `/tmp`에 작성했다.

## 재검토 추가 — WorldContact 빈 화면 수정 후

현재 `images/v349_WorldContact.gif`는 `world_wind/pose_camera_fix/frames/WorldWind_*.png`로 교체됐다. `make_review_media.py`의 실제 입력 경로와 WORLD_MEDIA_CHECK.json을 확인했다. 새 GIF SHA256은 `9d8800b70bdf57ce3fc5945686d1458a792cc7480beb3b1dba8fca9f74e6c123`이다. **초기 MED-V349-01 빈 화면 문제는 이 교체본에서 해소됐다.** 초기 실패 기록은 당시 증거로 남기며, 현재 파일도 여전히 비었다고 인용하면 안 된다.

- 새 GIF 120프레임/20.0초/450×650 직접 디코딩. 소스 PNG120장 모두 색이 존재하며, 최소 고유 RGB 9970, 빈 소스0.
- 처음/바람 진입/작동 중/해제/끝 36개 overview·연속 구간 프레임과 native 0/2/4/9/19.833초를 직접 확인했다. 추가로 헤어와 타이를 따로 잘라 **120개 모든 6Hz 프레임을 순서대로 직접 펼쳐 확인**했다. 파생 검토 이미지 `/tmp/v349_world_fixed_review/sequence_000~096.jpg`, `tie_000~080.jpg`, `overview.jpg`, `enter.jpg`, `exit.jpg`, `late.jpg`.
- 아바타가 실제로 보이고, 머리·매듭·넥타이 끝이 화면에 들어온다. 허벅지 아래와 일부 손 끝은 원래 상반신 카메라 밖이다. 전신/발 검사용으로 소개하지 않는다. 좌우 비교본이 아닌 단일 후보 영상이며 좌우 라벨 오류는 없다.
- 넥타이는 2.333–3.167초 및 4.0–4.667초에 좌우 기울기가 눈에 읽히고, 8–9.333초에도 매듭을 유지한 채 하단이 이동한다. 갑자기 다른 위치로 끊겨 보이는 매듭 이탈·큰 의상 관통은 이 정면 프레임에서 식별되지 않았다.
- 헤어는 전후 프레임의 컬 끝 변화가 작다. 이 구도에서 강한 헤어 흔들림이 뚜렷하다고 표현하면 과장이다. 큰 가닥 폭 변형/얼굴 노출 변경/뿌리 들림은 식별되지 않았다. 뒤목–코트 접촉은 정면에 가려져 있으므로 이 GIF로 해결 여부 판정할 수 없다.

- 6Hz 프레임 사이 순간 관통/30fps 부드러움, 측면·뒤면, PC VRChat 클라이언트는 이 재검토에 포함되지 않는다. 기존6개 움직임 비교의 판정은 앞 절을 유지한다.
