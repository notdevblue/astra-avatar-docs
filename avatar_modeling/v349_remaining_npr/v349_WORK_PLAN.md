## 추가 사용자 정정 — UV 연결성

v350의 기존 조각 재배치는 미채택. v351에서 일반적인 캐릭터처럼 연결된 부위 UV를 제작한다. 기존 UV seam의 무조건 보존·왜곡시 원래 파편화로 자동 복귀는 사용하지 않는다. 의미 있는 부위/자연스러운 이음선/편집 가능한 전개 형태와 실제 모델 디테일을 함께 검수한다.

## 추가 사용자 방향 — iPhone 얼굴 트래킹

현재 실제 파일에는 얼굴 표정 키가 없고 기존 키는 관절 보정용이다. 이번 UV 작업은 기존 정점·loop·셰이프키 좌표 대응을 보존하고 눈·입 주변의 연속 전개와 디테일 공간을 확보한다. 눈 감기·입 벌리기·웃음의 UV 늘어짐·선 끊김 검수는 후속 얼굴 표정 제작 후 필수 단계로 등록한다. 현재 중립 얼굴 검수나 관절 키 보존을 표정 검수 완료로 계산하지 않는다. 세부 상태와 ARKit 채널 대응·iPhone 실기 계획은 [v351 준비 문서](../v351_conventional_uv/v351_IPHONE_FACE_TRACKING_PREPARATION.md)를 따른다.
