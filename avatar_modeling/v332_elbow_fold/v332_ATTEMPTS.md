## 검사·구현 중 바로잡은 문제

초기 교차 필터가 정면2키의 영향만 포함해 모으기2키의 일부 영향 면을 빠뜨렸습니다. 해당 결과는 최종 근거로 사용하지 않았습니다. 네 키의 합집합으로 검사 범위를 고쳐 초기 실험3종과 최종 후보를 다시 검사했습니다. 최종 보고서의422→374쌍과 새 교차0은 수정한 전체 영향 범위 기준입니다. 범위가 다른 이전 총수끼리 개선율을 계산하지 않습니다.

최적화에서 나온 아주 작은 수치 잔여 때문에 Unity 키 저장 시 미세 델타가 생략되어 정확 비교가 실패했습니다. 무시할 수 있는 잔여를 정리하고 비영점 데이터를 정확히 저장한 뒤 모든 새 키를 다시 비교했습니다. 실패한 생성 직후 잘못 시작한 프로브는 prefab이 없어 종료됐고, 이후 정상 생성본의205기록으로 다시 검증했습니다. 초기 오류 기록은 작업용 trials에 남겼으며 최종 실행에는 해당 오류가 없습니다.

모으기 키의 노멀을 만들 때는 이미 켜진 기존26키의 노멀과 정면 키의 노멀을 빼고 추가분만 저장하도록 고쳤습니다. 기존 명암을 이중으로 더하지 않도록 최종 prefab을 다시 생성하고 실제 SDK 스냅숏을 다시 촬영했습니다.

부피 검사 스크립트의 누락 import도 수정 후 다시 실행했습니다. 최종 단면 결과는 `FINAL_CHECK.json`에 있습니다.
