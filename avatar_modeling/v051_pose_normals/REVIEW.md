# v051 — 노멀과 연결 상태의 분리 진단

Weighted Normal과 Weld 임시 모디파이어를 비교해 겨드랑이의 검은 선이 형상·분리 정점·노멀 중 어디에서 오는지 확인했다. Weld 진단은 선을 줄였지만, 당시 입력 `CONNECTED_SIDE`의 이름과 달리 실제 입력은 연결 전 34597정점이었다. 따라서 Weld가 아무 작업도 하지 않은 상태에서 노멀만 바꿨다는 해석은 잘못이다.

이 오류와 영향 범위는 [v045 입력 정정](../v045_coat_connections/SOURCE_CORRECTION.md)에 기록했다. 연결된 올바른 입력으로 `TRUE_SIDE`와 `TRUE_FRONT`를 다시 만들었다. 실제 `CONNECTED_COAT`의 읽기 전용 별도 Blender 검사에서는 코트 3659변 중 sharp 102개, 코트 1923면의 flat 0개, custom normals 존재를 확인했다. 첫 잘못된 입력 검사 실패도 로그에 보존했다.

결론은 기존 겹친 정점을 올바르게 연결한 뒤, 옷깃의 의도적인 각과 소매의 부드러운 음영을 구분해야 한다는 것이다. Weighted Normal이나 DQS를 전체에 적용하는 방식은 채택하지 않았다. 이 단계는 진단이며 새 최종 모델은 없다.
