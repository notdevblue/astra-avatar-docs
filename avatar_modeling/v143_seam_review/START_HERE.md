# v143 — 텍스처 UV 여백 보완 비교안

**현재 최종 채택 대상이 아니다.** 사용자는 정장 어깨선 자체를 유지하고, 팔에 과하게 끌려가는 변형을 먼저 해결하라고 기준을 구체화했다. 이에 따라 원래 텍스처를 보존하는 [v144](../v144_seam_transport/START_HERE.md)에서 형상·웨이트 실험을 계속한다.

v141의 3,452픽셀 국소 수정은 렌더에서 검은 띠를 줄였지만 UV 섬 가장자리 색 차이를 키웠다. v143은 실제 면이 덮는 texel을 그대로 두고, 주변 빈 UV 여백에 수정량만 8texel까지 연장했다. 새로 영향을 받은 여백은 3,786픽셀이다. 다른 면이 덮는 영역을 덮어쓰지 않는다. 구현·보존 검사 (공유본 미포함: `PADDING.json`).

같은 604개 UV 분리 모서리에서 각 네 표본을 비교했다. 원본 대비 색 차이의 최대 증가량은 다음과 같다. 단위는 0–1 RGB 벡터 거리이며 화질 점수가 아니다.
