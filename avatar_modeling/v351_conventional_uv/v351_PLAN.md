# v351 — 연결된 캐릭터 UV 제작 중

v350의 기존 조각 재배치를 미채택하고, 원형 모델 사본의 UV 이음선을 재설계한다. 얼굴 외피, 의상 몸판/소매, 손바닥/손등과 연결된 손가락, 신발 부품, 헤어 가닥의 연속 채색을 목표로 한다.

## 보존과 표정

- 기존 정점 좌표/순서, polygon/loop, 노멀, 본/웨이트, 모든 shape key 좌표를 보존한다.
- iPhone 얼굴 트래킹을 계획하고 있으므로 눈꺼풀과 입술을 가로지르는 불필요한 UV 이음선을 피한다.
- 구강·눈 부속의 비다양체 가상 접촉을 피부와 강제 접착하지 않는다. 원래 모델의 실물 구조는 변경하지 않는다.
- 새 UV와 기존 UV를 동일한 눈 감기/입 벌리기/웃음 표정에서 비교한다. 표정에서 드러나는 숨은 면도 포함한다.
- ARKit 의미 대응/현재 미지원 목록을 별도로 기록한다. 현재 작업을 iPhone 실기 지원 완료로 표현하지 않는다.

## 현재 실행

큰 의미 패널 설계 → 유효 edge/fan 기반 UV solver → 원래 실제 삼각형으로 전개 → 손 경계의 UV 한정 겹침 완화 → 부위별 기존 채색 전사. 헤어 가닥 전개 및 실제 3D·표정 전후 검수는 진행 중이다. 실제 검수 전 최종 채택하지 않는다.
