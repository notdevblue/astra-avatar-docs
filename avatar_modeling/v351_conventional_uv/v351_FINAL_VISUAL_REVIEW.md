## 수치의 사용 범위

최대 색차 주변을 놓치지 않도록 이미지 차이를 보조로 사용했다. `DIFF.json`의 격리 이미지 최대 채널 차이는 face40/pants30/shirt35/shoe_L22/shoe_R21/255이며, 큰 값은 소수 경계 픽셀에 집중했다. 직접 본 native crop에서 새 큰 오염이나 주요 선 소실은 확인하지 못했다. 이 수치를 미관 점수나 무손실률로 해석하지 않는다. 전후 픽셀이 완전히 동일하다는 주장도 아니다.

## 남은 범위와 권고

1. 최종 UV 전사 비교로서는 현재 렌더 범위의 디테일 보존 근거가 충분하다. 기존 NPR 명암을 추가로 평탄화하거나 전체 재채색할 이유는 이 비교에서 발견되지 않았다.
2. 얼굴 셸 내부 미세 경계, 무릎 뒤 고정된 짙은 명암, 커프 끝 작은 점상 경계는 **기존 잔여와 이번 회귀를 분리해** 보고할 것. 원인별 별도 작업을 하지 않았으면 해결했다고 쓰지 않는다.
3. Unity 사진은 같은 v348 SDK 캐시 자세에 신 UV/텍스처를 적용한 비교다. 새 연속 관절·물리·교차 전수 시험이 아니다. 헤어–코트 접촉 해결도 이 정적 사진만으로 확정하지 않는다.
4. 눈·입 디테일이 정적 렌더에서 유지된 것과 iPhone 얼굴 추적 지원은 별개다. 이번 검토에는 눈 깜빡임/입 벌림/ARKit 입력 실행이 없다.
5. 검사한 6방향에서 가려진 미세 면, 압축/밉/거리 변화와 PC VRChat 클라이언트는 별도 검증 범위다. 전체 최종 채택은 아직 아니다.

프로젝트 파일/자산/Unity 변경 없이 독립 검토했다.
