# v351 — 헤어 UV 전사 및 v349 국소 명암 독립 시각 검토

2026-09-13. 실제 렌더 직접 검토, 제작 자산/Unity 수정 0. 일반 6방향 사진에 가려진 두 부위는 별도 Blender background 프로세스에서 기존 면만 격리해 `/tmp/v351_visual_local/`에 추가 렌더했다. 프로젝트 `.blend` 저장은 하지 않았다.

## 현재 결론

- 헤어 기존본/4K/8K의 외부 6방향에서 넓은 색 번짐·덩어리 붕괴·주요 디테일 손실은 식별되지 않는다. 8K는 확대 시 원본에 더 가깝다.
- 그러나 **가려진 C11/C34의 국소 면에는 원본에 없던 반복 띠가 4K/8K 모두 생긴다.** 8K는 패턴을 더 촘촘하게 만들고 차이를 줄이지만 없애지는 못한다. 숨은 면도 사용자 요청 범위이므로 이 두 후보를 전사 무회귀/완료로 판정할 수 없다.
- v349 바지/소매 명암 수정은 넓은 낮은 주파수의 톤을 약하게 바꾸며 세로 봉제선·짧은 깊은 주름·V자 접힘과 외곽은 유지한다. 이번 격리 사진에서 의미 있는 디테일을 죽인 큰 회귀는 식별하지 못했다.

## 자료

기준 폴더 `avatar_modeling/v351_conventional_uv/`:

- `images/v351_ISOLATED_BEFORE_hair.png`: 원본 v348의 색/UV.
- `trials/hair4k/v351_ISOLATED_AFTER_hair.png`: 4K 베이크.
- `images/v351_ISOLATED_AFTER_hair.png`: 당시 현재 8K 베이크.
- 세 장 모두2400×1600, 앞/옆/뒤/반대옆/위/아래를 직접 열었다.
- `trials/hair4k/hair_TRIANGLES.json`의 원래 packed loop UV와 `Bianca_v351_hair.png`를 **함께** 적용해 4K 국소 렌더를 만들었다. 8K UV에 4K 이미지만 대입하지 않았다.

외부 확대 ROI(원본 이미지 좌상단 기준): (140,175)–(300,330), (1330,60)–(1480,180), (1715,895)–(1870,1040), (425,1310)–(550,1435), (640,1160)–(770,1300). 가닥의 긴 선·쐐기형 하이라이트·끝말림은 세 후보에서 유지된다. 4K가 일부 가는 가장자리를 조금 더 부드럽게 만들지만 일반 구도에서 큰 디테일 손실로 식별되지는 않는다.

## 왜 별도 국소 렌더가 필요했는가

`render_isolated.py`의 회전/맞춤/직교 카메라 수식과 기존 삼각형으로 지정 world 점을 투영했다. C11 poly3044 및 C34 poly1606의 투영 위치는 6방향 모두 다른 헤어 삼각형 뒤에 있었다. 따라서 일반 사진의 해당 화면 좌표를 보는 것만으로 지정 면을 검사했다고 할 수 없다.

국소 렌더는 각 면 중심에서 원래 면 법선 방향으로 카메라를 두고, 같은 헤어 차트 안에서 중심 거리0.017 이내인 기존 면만 남겼다. C11은50면, C34는34면. 직교 폭0.026,900×900,Emission,Standard,16samples. 양쪽 후보에서 선택 면·형상·카메라는 같다. 인위적으로 격리한 바깥 절단 모서리/빈 공간은 실제 모델 구멍이 아니다. 반복 패턴은 절단선 안쪽의 기존 표면에 나타난다.

재현 스크립트: `/tmp/v351_visual_local.py`.

대조: `avatar_modeling/v349_remaining_npr/images/v349_ISOLATED_AFTER_{pants,sleeves}.png` 대 `v351_conventional_uv/images/v351_ISOLATED_BEFORE_{pants,sleeves}.png`(각2400×1600). 네 장 전체와 아래 구역을 동일 크기로 직접 확대했다.

- 바지 뒤 종아리/단 ROI(1840,330)–(2130,710): 긴 선과 바짓단 어두운 V자 접힘이 유지된다. 넓은 면 톤 조절 때문에 바지가 평평한 단색으로 변한 것으로 보이지 않는다.

판정: 이 두 격리 사진 범위에서는 명암 완화가 의미 있는 선·주름을 뭉갠 회귀는 관찰되지 않는다. 단추는 이 sleeves 격리 분류에 충분히 노출되지 않으므로 단추 디테일 전체 검증으로 확대하지 않는다. 실제 굽힘/Unity 광원별 결과는 별도 검수해야 한다.

## 권고

C11/C34의 반복 패턴을 해결한 후보를 같은 국소 카메라에서 다시 비교하고, 그 뒤 일반6방향과 실제 동작 노출을 확인한다. 현재8K도 채택 보류가 맞다. 원형 헤어 명암·긴 가닥 선을 보존하면서 전사/좁은 UV 삼각형의 분배/경계를 다루며, 전체 헤어를 새로 칠하거나 흐리게 만들어 패턴을 감추지 않는다.

DIRECT의 일반6방향 전체는 이 추가 검토에서 새로 렌더하지 않았으므로, 국소 개선을 전체 헤어 합격으로 확대하지 않는다.
