# v329 · SiuSiu 기준 팔꿈치 차이 조사

[사진·비례·웨이트·부피 비교](v329_SIUSIU_COMPARISON.md)

사용자가 선호한 SiuSiu Kisekae 블레이저와 비앙카 v324를12자세에서 읽기 전용 비교했습니다. 전완/위팔 비례0.69대1.08, 실제 보조본 역할, 지역 면 밀도와 구간 부피를 확인했습니다. SiuSiu의 전용 팔꿈치 키나 더 많은 본이 외형의 비결이라고 단정하지 않습니다. 모델 수정 없이 후속 적용 방향만 정리했습니다.

v327의 둥근 측면은 채택 보류하고 수정 전 측면을 보호합니다. 원시 구매 모델 배열은 로컬 캐시에만 보존합니다.
