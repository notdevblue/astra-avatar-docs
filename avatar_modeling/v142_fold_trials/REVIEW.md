# v142 — 겨드랑이 압축 면 국소 복원 실험

**최종 통합하지 않은 형상 실험이다.** 기존 코트 52정점만 대상으로 했고, 메시 재생성·리메시·원래 rest 좌표 변경은 없다. 이 결과를 v143 또는 v145에 포함했다고 해석하지 않는다.

원래 면 3288/8702/15402/15403/15406/16515 주변을 대상으로, 앞90 평가 삼각형의 최소 늘어남을 SVD로 복원하는 15회 국소 반복 계산을 했다. 기존 점의 최대 이동량은 1/2/4mm로 제한했다. 5가지 목표, 12가지 강도 축소, 24가지 문제 면 제한을 실제 Blender에서 시험했다.

강한 목표는 압축을 줄였지만 주변에 새 교차가 발생했다. 단순히 문제 면 정점을 멈추는 방식도 전체 통과하지 못했다. 이후 **기준 자세에서 떨어져 있던 삼각형의 분리 평면을 유지하는 212개 선형 제약**을 넣어 두 목표를 다시 투영했다. 강한 투영안은 앞90에서 새 면적 경고 0, 새 접촉 0, 기존 면15406의 면적 경고 1건과 접촉 1쌍을 해소했다. 최대 이동은 약1mm다.

이 검사는 저작 자세 하나뿐이다. 다른 자세와 키 활성화 경계는 검사하지 않았으므로 일반화된 관절 해결로 채택하지 않았다. 전체 코트의 늘어남/압축 수치도 서로 상충한다. 작은 면 개선을 큰 겨드랑이 홈 해결로 보고하지 않는다.

- 5가지 원본 목표 검사 (공유본 미포함: `TRIALS.json`)

- 분리 제약 (공유본 미포함: `PROJECTION_STRONG.json`)
- 강한 투영안 앞90 검사 (공유본 미포함: `PROJECTED_STRONG_TRIAL.json`)

- 재현 가능한 국소 정점 변화량 (공유본 미포함: `PROJECTED_STRONG.npz`)

참고한 [Blender Studio Pose Shape Keys](https://studio.blender.org/tools/addons/pose_shape_keys)는 변형된 자세에서 보정 모양을 저작하는 흐름을 설명한다. [Bridson 등의 의복 접촉 논문](https://www-graphics.stanford.edu/papers/cloth-sig02/)은 옷의 자연스러운 접촉과 실제 교차를 구분해 처리한다. 이번 작은 정적 분리 제약은 논문의 완전한 동적 충돌 솔버를 구현한 것이 아니다.
