# v122 — 수정한 앞뒤 경로의 소매 곡면

v121의 앞뒤 회전 경로를 유지하며 같은 자세에서 표면을 수정한다. 원본 레퍼런스의 정장 어깨/소매 형태를 다시 실제 확인했다. 앞90의 기존 원래면 접촉361과2배 늘어남6.103%를 기준으로 삼고, 이전 v119의 다른 팔 방향과 비교해 통과라고 하지 않는다.

기존 v048의 전신 DQS/Corrective Smooth는 옆들기의 돌출을 늘려 제외했다. 이번에는 새 앞들기 경로에서 코트 영역만 진단하고, 결과가 나쁘면 그대로 제외한다. 정지 상태를 스무딩하거나 전체 메시를 대체하지 않는다. v109/v114에서 드러난 단순 변형률 제한의 접촉 증가도 그대로 반복하지 않도록, 목표를 계산할 때 안쪽/바깥쪽 접촉과 고정 경계를 함께 검토한다.

1. 앞0~120의 실제 삼각분할·본 행렬·코트 좌표와 DQS 진단 좌표를 수집한다.
2. 기존 면 접촉과 늘어남이 어디에 집중되는지 앞30/60/90에서 확인한다. 변형 방식 교체, 기존 웨이트의 제한된 분담, 접촉을 포함한 기존 곡면 보정을 비교한다.
3. 개선 후보는 별도 파일에 적용하고 같은 수정 전방 자세, 새 혼합/비틀림, 옆들기, 저장 동작을 비교한다. 중립·UV·텍스처·v038 SMALL 무릎은 보존한다.
4. 최댓값뿐 아니라 늘어난 면적과 눌린 면적, 새 접촉, 실제 전후 렌더를 함께 보고 판단한다. 새 자세에 들어간 기존 문제와 수정으로 새로 생긴 문제를 분리한다.

## 후속 원문 확인

[Kavan의 DQS 설명/원문 연결](https://users.cs.utah.edu/~ladislav/dq/index.html)은 LBS 수축과 DQS의 회전 보간을 설명한다. DQS가 이 캐릭터의 옷 접힘/접촉까지 해결한다는 보장은 아니다. 실제 v122의12개 혼합목표에서는 중간각도 눌림이 줄었지만 높은각도 새 면적경고가 증가했다.

[Autodesk의 post-skin corrective 설명](https://help.autodesk.com/cloudhelp/2024/ENU/Maya-CharacterAnimation/files/GUID-B8755F24-7C24-4066-B6F8-2DE6954DC2BF.htm)은 변형된 상태에서 보정을 만드는 작업 순서를 참고했다. Maya를 설치/실행하거나 해당 기능을 직접 사용한 것은 아니다.

v123에서는 [Blender Cloth Shape](https://docs.blender.org/manual/en/latest/physics/cloth/settings/shape.html)의 pin group과 dynamic mesh, [자기 충돌 설정](https://docs.blender.org/manual/en/3.6/physics/cloth/settings/collisions.html)을 확인하고 기존 한 메시에서 코트 밖을 고정한다. 검색으로 공식 설명을 확인했으나 해당 페이지의 직접 열기는402로 실패했다. 실제 설정명과 실행은 Blender5.2 MCP에서 확인한다. 자기 충돌 제외 그룹은 지정된 면을 제외하는 기능이라서, 코트 밖을 그 그룹에 넣는다. 모델을 분리/리메시하지 않고 원래 정점의 목표만 얻는다. 엔진 실시간 cloth 적용과는 다른 저작 실험이다.
