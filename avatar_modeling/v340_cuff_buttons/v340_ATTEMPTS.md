# v340 · 문제·시도·미채택 이유

| 시도 | 확인한 결과 | 판정 |
|---|---|---|
| 기존 작은 UV 안에서 원만 정렬 | 위치는 맞지만 테두리가 작은 점처럼 끊김 | 제외, 타일 해상도 확보 |
| 테두리만 있는 단순한 단추 | 중앙 홈·봉제 디테일이 사라짐. 사용자도 디테일 보존 요청 | 제외, 테두리와 안쪽 표현 복원 |
| 큰 소매 두 패널만 잔상 제거 | 손목 아래에 어두운 띠가 남음 | 불충분, 실제 화면 UV를 추적해 작은 네 조각 추가 |
| 추가 조각 첫 정리 | 한 조각의 짧은 검은 획이 남음 | 해당 조각만 다시 정리 |
| 기존 메시 에셋에 직렬화 복사 | 반복 갱신에서 메시 보존 검사 실패 | 원래 메시의 새 사본으로 갱신 |
| 새 메시 에셋으로 교체 직후 렌더 | 프리팹의 캐시된 참조 때문에 빈 화면 | 프리팹 강제 재임포트 후 실제 렌더·기하 검사를 다시 통과 |

![디테일이 부족했던 시험과 복원 결과](images/v340_BUTTON_DETAIL_R.png)

최종적으로 기존 단추 8개를 그대로 사용하고 UV만 전용 타일로 이동했다. 생성 도구는 내장 image_gen을 사용했으며, 원래 천 패널의 잔상 제거와 단추 면 디테일에만 적용했다. 프롬프트·입력·생성 결과·마스크는 작업 저장소의 `v340_PROMPTS.json`, `DETAIL_RESTORE_GENERATION.json`, `LOWER_CUFF_GENERATIONS.json` 및 inputs에 보존했다. API/CLI 대체 생성은 사용하지 않았다.

Unity 에셋 덮어쓰기 동작은 [공식 CreateAsset 문서](https://docs.unity.cn/ScriptReference/AssetDatabase.CreateAsset.html)를 참고했으나, 이번 캐시 문제의 해결 판정은 실제 재임포트와 모델 렌더 결과로 확인했다.
