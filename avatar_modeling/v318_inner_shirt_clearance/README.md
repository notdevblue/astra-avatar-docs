# v318 — 코트 부피를 고정한 안쪽 셔츠 분리 조건, 미적용

코트 v316의 좌표를 정확히 고정하고 기존 셔츠 component12의524위치만 움직이는 선형 제약 문제를 구성했다. 실제 새 교차에서 원래 분리 방향을 찾고, 정점 이동과 이웃 간 변위 차이를 줄이도록 했다. 버튼·머리·얼굴·손 등 다른 표면은 변수에 넣지 않았다.

좌표축별±6mm 상한과 선택된 반평면 조건에서는 OSQP가 primal infeasible을 반환했다. 따라서 후보 좌표나 모델 파일을 저장·적용하지 않았다. 모든 기하학적 수정이 불가능하다는 뜻은 아니다. 선택한 분리 방향을 모두 동시에 고정한 선형 문제의 실패다.

다음에는 겹친 셔츠 경계와 코트 면을 함께 다루고, 이미 있던 셔츠·코트 접촉 곡선의 이동과 새 외부 관통을 구분해야 한다. 코트만 밀기나 몸 쪽만 밀기를 각각 강제하는 방식은 이번 조건에서 마무리 해법이 아니었다. 부피·원형·실제 시각 검수·자동 구동 검증은 여전히 모두 필요하다.

원본 v212/v224와 이전 후보는 유지했다. 새/대체 메시·리메시·본·웨이트 변경·Unity 최종본 채택 없음.
