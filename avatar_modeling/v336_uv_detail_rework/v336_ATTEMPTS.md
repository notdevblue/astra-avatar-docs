# v336 · 겪은 문제, 시도와 선택 이유

v334 사본에서 기존 기하·본·웨이트·보정키를 보존하고 UV/기본색 전사만 시험했습니다. 채색 원본은 디테일을 복원했던 v324입니다. 원래 레퍼런스의 소매 주름, 옷깃, 단추, 바지 접힘, 신발 띠·밑창과 머리 웨이브를 보호 기준으로 다시 확인했습니다. SiuSiu/Lapwing의 문양을 비앙카에 옮기지는 않았습니다.

| 시도 | 발생한 문제 / 결과 | 판단 |
|---|---|---|
| 패널 전체를 한 번에 펼치고 최소 픽셀 밀도에 맞춰 확대 | 일부 극단적인 모서리 때문에 패널 전체 면적이 크게 증가, 4K 한 장 안에 보존 밀도로 수용 곤란 | 패널 전체를 가장 나쁜 한 면에 맞춰 확대하는 방식 제외 |
| 밀도 변화가 큰 경계에서 분리한 첫 배치 | UV가 접혀 들어가 309쌍의 양의 면적 겹침 발생, 관련 109개 면 확인 | 그대로 베이크한 결과 미채택 |
| 겹친 면을 기존 UV 모양으로 분리 | 양의 면적 겹침 0. 그러나 아주 얇은 작은 면은 폭이 1픽셀 미만이라 베이크에서 색이 빠짐. 표면 표본 최대 오차 약 221/255 | UV 겹침 0만으로 합격하지 않음 |
| 작은 차트의 최소 높이 확보, 손의 남은 문제 면 별도 분리 | 누락·검은 점을 줄이고 기본색 전사 오차 감소. 더 많은 작은 조각과 Unity UV 분리 정점이 필요 | 디테일 보호를 우선한 비교 후보로 선택 |

| 밉맵 끄기·이방성 16·Clamp 진단 | 밉맵 OFF에서는 뒤트임 점선이 사라짐. 이방성/Clamp만으로는 남음 | 밉맵 OFF는 원인 분리용. 전달본은 밉맵을 유지 |
| 전체 UV 간격 0.0015→0.003 | 최소 방향 픽셀 밀도 0.9267배로 감소. 분리 기준을 더 좁혀도 0.9581배이며 조각 1,753개로 증가 | 원래보다 낮은 밀도와 과분할 때문에 제외 |
| 뒤트임의 얇은 UV 2개, 이어 바깥 면까지 4개를 빈 공간으로 이동 | 크기를 그대로 둔 채 각각 64픽셀 주변 빈 공간 확보. 베이크 확장도 64픽셀로 재실행 | 보존된 마지막 시험 파일. 밝은 점선이 남아 개선책으로 미채택 |

밉 진단에서 겪은 실행 오류도 기록합니다. Editor bridge가 진단 클래스 이름 규칙에 맞지 않는 첫 호출을 거부해 `Views` 이름으로 수정했습니다. 화면 픽셀과 면을 대응하는 진단은 임시 카메라 종횡비 및 BakeMesh가 포함한 스케일을 바로잡은 뒤 사용했습니다. 잘못된 진단 좌표의 결과를 모델 결함으로 해석하지 않았습니다.

Blender 재로드 보존 검사에서 처음 본 행렬 차이가 보고된 것은 파일 전환 후에도 Blender 내부 벡터 참조를 보관한 검사 코드의 문제였습니다. 파일 전환 전에 순수 숫자로 복사해 재검사한 실제 본 행렬 차이는 0입니다. Unity의 작은 보정키 델타를 일반 추가 API로 복사할 때 생기는 생략도 원래 직렬화된 항목을 정확히 복사하는 방식으로 방지했습니다.

이동 후에도 밝은 점선은 남았습니다. 뒤트임 고정 영역(원본 이미지 x=480–519, y=730–829)에서 원본 대비 최대 채널 차이는 16픽셀 여백 시험 100/255, 마지막 64픽셀·4차트 이동 시험 167/255였습니다. 차이 30 초과 픽셀도 19→22개입니다. **국소 여백 이동은 이 구도에서 오히려 악화해 해결책으로 채택하지 않았습니다.** 마지막 파일은 이를 포함한 재현·비교용 시험본이며, 현재 사용 기준은 v334입니다.

밉맵 OFF에서 현상이 줄어든 것으로 필터링의 관여는 확인했지만, 정확한 GPU 샘플링 원인을 끝까지 분리하지 못했습니다. 더 늦은 이방성 강제 활성화 진단은 공유 Unity에 다른 작업 명령이 들어와 결과를 얻지 못했으며 성공한 시험에 포함하지 않습니다. 모델 기하 문제라고 단정하거나 관절을 수정하지 않았습니다.

## 남은 개선과 미채택 접근

- 전체 Paint UV 조각은 줄었지만, 4삼각형 이하 작은 조각은 증가했습니다. 큰 패널은 편집하기 쉬워졌고 작은 결함 면은 분리한 절충입니다. 손으로 최적화한 참고 모델 수준으로 UV 정리가 끝난 것은 아닙니다.
- 새 UV의 면적 가중 늘어짐 상위 5% 구간은 원래보다 나쁩니다. 최소 픽셀 밀도를 보전해 전사 디테일은 보호했지만, 앞으로 직접 패턴을 그릴 때의 왜곡까지 해결한 배치는 아닙니다. 특히 신발·장식 패널을 더 개선할 여지가 있습니다.
- 기존 신발 윗면의 부드러운 명암과 셔츠의 강한 밝은 주름을 그대로 전사했습니다. UV 재배치가 원본 채색의 흐림까지 새로 만들어주지는 않습니다. 의미 없는 얼룩과 원래 디자인의 접힘을 구분하는 국소 채색은 후속입니다.
- 머리·얼굴을 같은 방식으로 통째로 다시 펼치거나 전체 평활화하지 않았습니다. v323에서 있었던 디테일 손실을 반복할 가능성이 있어 기존 Head를 보호했습니다.
- 셰이더 v003, 관절 수정, 메시 재생성, 새로운 표정·물리 작업은 합치지 않았습니다.

## 재현 자료

작업 폴더에 원본 표면 목록, UV 차트와 폴리곤 대응, 미채택 수치, 새 UV 이동량, 전사 오차와 파일 보존 검사를 남겼습니다. 원본에서 펼치기 → 겹침/밀도 보정 → 배치 → 뒤트임 차트 여백 확보 → 기본색 EMIT 베이크 → Unity 원래 삼각형 대응/UV 분리 → 원래 속성/보정키 정확 복사 → 재로드·전후 사진 비교 순서입니다.

UV를 푸는 계산용 임시 면은 원래 면의 좌표와 대응으로만 구성했습니다. 전달 모델에 새 메시를 생성하거나 기존 메시를 교체하지 않았습니다. Unity에서 늘어난 정점은 새 UV 이음매를 표현하기 위한 같은 위치·같은 웨이트의 복제 정점입니다.
