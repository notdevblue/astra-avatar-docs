# v158 — 카라·헤어·의상 물리 조사와 적용 계획

2026-09-11. 사용자 추가 승인: 카라가 팔을 따라 늘어나는 문제 포함, 본 추가/수정 허용, 기존 메시만 수정, 별도 파일에서 실험·다관절 검사 지속. 품질이 나쁜 후보는 제외하고 대안 시험. 비앙카 기준은 v152이며 원본 ref_char.png를 실제 열람했다.

## 참고 모델에서 실제 확인한 것

v157은 물리를 끈 관절 검사였다. 이번에는 별도 Unity2022.3.22f1/SDK3.10.5에서 원래 PhysBone·Collider 설정과 연결 대상을 읽고, 원래 제약을 유지한 채 물리 ON/OFF 실행을 추가했다. 구매 원본은 .venv 사본에서만 사용한다.

| 대상 | 실제 구성 | 적용할 점 |
|---|---|---|
| SiuSiu | 앞/뒤/좌우 헤어4그룹, 별도 Dummy 계층의 물리 결과를 실제 헤어 본에 제약으로 전달. 앞/옆25°, 뒤40° Polar 제한. 해당4헤어 PB의 명시적 Collider 목록은 비어 있음 | 짧은 머리는 뿌리 고정과 회전 제한을 먼저 맞춘다. 모든 헤어에 큰 Collider를 넣는다고 좋아지는 것은 아님 |
| Lapwing | 앞머리와 긴 포니테일 설정 분리. 긴 머리는 Head/Chest Collider를 명시적으로 연결. 몸통·골반·다리·전완 등에 실제 Collider가 있음 | 길이·몸과의 근접도에 따라 설정과 충돌 대상을 분리 |
| SiuSiu 의상 | 앞 스커트 체인은 골반/다리 Collider, 블레이저 뒤쪽은 제한된 물리 회전과 연결 제약 | 고정 몸판과 움직일 자락을 분리. 카라 늘어남을 물리로 덮지 않음 |
| Lapwing 의상 | 긴 소매의 안/밖 체인과 전완 Capsule/Plane 연결. 일부 목록에 null도 있음 | 명칭·목록 개수만으로 충돌 완료 판정 금지. 실제 참조를 확인 |

동일한 머리 yaw/pitch/roll과 몸 위치 진동→정지 입력을 60Hz 시뮬레이션 시간으로 720프레임씩4구성 실행했다. 헤어 계열 추적 본의 최대 로컬 회전 변화는 SiuSiu15.30°, Lapwing42.48°, PB OFF는 양쪽0°. 서로 다른 체형/머리 길이이므로 품질 점수나 비앙카 목표 각도가 아니다. 전체 아바타 Animator/게임 IK는 재현하지 않았다. 실측 집계 (공유본 미포함: `REFERENCE_DYNAMICS.json`).

## 자료와 이번 적용 판단

- [VRChat 공식 PhysBones](https://creators.vrchat.com/common-components/physbones/): 뿌리/끝점, 복원·감쇠·회전 제한, 지정 Collider, Is Animated 및 제약과 물리의 계층 분리 확인. 뼈를 넣는 것만으로 메시 충돌이 해결되지 않는다. 원형이 이미 완성된 헤어는 정지 상태를 바꾸지 않도록 설정하고 움직임 후 복원을 검사한다.
- [Blender Armature 설명](https://docs.blender.org/manual/en/latest/modeling/modifiers/deform/armature.html): 웨이트에 따른 변형과 Preserve Volume의 의미 확인. 과거 v154/v155 실패에 따라 전체 DQ나 같은 반회전 어깨 본 적용을 반복하지 않는다.
- [Sipp's Avatar Box PhysBones 튜토리얼](https://www.youtube.com/watch?v=PTTnWUkswkU): 제작자 설명과 챕터 확인. 1:03 뿌리/끝점, 1:50 힘, 4:15 제한, 5:40 충돌. 영상 전체 시청·화면 단계 재현 주장 아님.
- [ABDE in VR 헤어 설정 영상](https://www.youtube.com/watch?v=WaJ3ImmAurg): 제작자 설명과 1:02 Collider, 6:12 헤어 챕터 확인. VRoid 전용 변환 절차는 비앙카에 적용하지 않는다.
- [VRChat Animator Parameters](https://creators.vrchat.com/avatars/animator-parameters/): 아바타 파라미터 구동 구조 확인. 현재 SDK PhysBone 필드/API도 실제 반사 검사했다. 임의의 월드 바람 방향을 자동 입력받는 전용 wind 필드는 찾지 못했다. 따라서 이번 바람은 아바타의 선택 가능한 약한 흔들림 연출로 분리하고, 머리·몸 이동에 따른 관성은 실제 PhysBone으로 처리한다. 모든 월드의 WindZone에 자동 반응한다고 설명하지 않는다.

## 비앙카 실제 상태와 계획

헤어 고정 부모6개 + 가중치 있는 본12개가 이미 있다. 지금까지는 실제 물리·충돌 검증이 빠져 있었다. 단순히 본을 중복 생성하지 않고 가중 구역/피벗/길이를 먼저 확인한다. 필요한 끝점과 바람용 부모를 추가하되 기존 기본 정점·UV·텍스처·표정 키를 보존한다. 머리 및 목/가슴 충돌은 모델 크기에 맞춰 실제 Unity에서 설정·시험한다.

카라는 코트 상단과 앞 라펠을 따로 잡아 팔·쇄골 영향과 흉곽 지지를 분리한다. 초기 측정에서 코트 상단156정점에는 흉곽66.3%, 목19.5%, 좌우 쇄골 합12.2%, 상완 합2.0%의 평균 영향이 있다. 앞 라펠90정점은 쇄골 합31.1%, 상완 합6.0%다. 평균값을 그대로 목표값으로 쓰지 않는다. 셔츠 카라와 겉 코트 라펠도 구분해 본다.

먼저 웨이트 대조를 여러 강도로 실행한다. 앞만 좋아지고 옆/목 동작에서 나빠지면 실패 위치를 확인해 범위·기여를 바꾸고, 부족하면 국소 보정이나 별도 본 구조를 시험한다. 기본 외형 보존, 수정 밖 정점 보호, 여러 관절 동작과 렌더 비교를 함께 수행한다. 진행 결과는 후속 버전 문서에 기록한다.
