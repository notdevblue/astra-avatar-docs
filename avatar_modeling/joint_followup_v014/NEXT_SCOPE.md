# 남은 큰 굽힘 보정 — 추가 본 4개 사본 제안

2026-09-09. **아직 추가하지 않은 제안**이다. v014의 국소 무릎 웨이트는 원래 형상을 유지하며 압축을 줄였지만 큰 각짐과 겨드랑이의 납작한 접힘까지 해결하지 못했다.

현재 두 본으로 섞이는 관절 중심에서는 회전 중 부피가 줄 수 있다. [Blender Armature 설명](https://docs.blender.org/manual/en/latest/modeling/modifiers/deform/armature.html)의 Preserve Volume은 다른 변형 계산법을 쓰므로, 이를 켠 Blender 화면만으로 Unity 해결을 주장할 수 없다. 이번에는 그대로 보존했다.

다음 사본에서는 **무릎 2개 + 겨드랑이 2개, 총4개 보조 변형 본**을 시험하는 범위를 제안한다. 모델 메시·원래 몸20본·자락12본은 그대로 두며 총32→36본이 된다. 기존 골격 전체를 바꾸는 작업이나 새 메시 생성은 아니다. 추가 구조이므로 사용자의 “수정이 크면 내 의견 물어봐” 조건에 따라 실행 전에 범위를 확인한다.

| 항목 | 구체적인 시작 범위 |
|---|---|
| 기준 | v014 무릎 웨이트 후보3. 별도 폴더/파일로 분기 |
| 무릎 보조 | `knee_support.L/R`, 각각 기존 shin head 위치. thigh의 자식. 원래 shin의 부모/위치 유지 |
| 어깨 보조 | `shoulder_support.L/R`, 각각 기존 upper_arm head 위치. clavicle의 자식. 원래 upper_arm의 부모/위치 유지 |
| 본 길이 | 표시/편집용으로 기존 shin 또는 upper_arm 방향의 약20mm. 원래 모델 약1m 스케일 기준 |
| 제어 시작 | 부모/굽힘 본의 회전을 50:50으로 따르는 중간 방향. 무릎은 thigh+shin, 어깨는 clavicle+upper_arm |
| 웨이트 변경 한도 | 무릎은 이번383 raw 정점 안에서만, 겨드랑이는 좌우 head 반경35mm 부근의 재킷 표면에서 최대400 raw 정점까지만. 범위를 넘기면 먼저 재검토 |
| 보조 영향 시작 | 기존 두 본의 혼합 구간 일부를 보조 본에 분배. 최고50%부터 시험, 정규화·최대4본 영향 유지 |
| 원형 | 중립 정점·면·UV·노멀·텍스처 변경 없음. 원래 몸 본 이동 없음 |
| 런타임 | 지원 Unity에서 VRCRotationConstraint 소스 가중치로 시험. 임의 C#을 아바타에 넣지 않음 |

[VRChat Rotation Constraint](https://creators.vrchat.com/common-components/constraints/vrc-rotation-constraint/)는 소스들의 회전을 따라 대상의 회전을 정한다. 유지할 중립 offset과 본 축은 실제 사본에서 확인해야 한다. [공식 API](https://creators.vrchat.com/common-components/constraints/constraints-api/)의 구성/활성화 방법을 사용한다. 이 기능의 존재가 현재 모델의 부피 복원이나 IK 안전성을 보장하지는 않는다.

추가 후에도 움직임이 좋아진다는 보장은 없다. 원형 불변, 양쪽15~120도 무릎·팔 올리기/앞뒤 뻗기, 기존32자세와254동작의 악화 여부를 검사하고 실제 렌더로 비교한다. 단순히 본을 추가했다는 이유로 채택하지 않는다. 고관절·몸통·목·손가락 보조 본을 함께 늘리는 범위는 포함하지 않는다.

소매/자락 접촉은 이4개만으로 해결된다고 가정하지 않는다. 기존32본 자락과 허벅지/팔 충돌체 시험은 별도로 진행해야 한다. v014의 자락 전체 몸통 추종은 소매 접촉을 줄이는 대신 바지 관통을 만들었으므로 제외했다.
