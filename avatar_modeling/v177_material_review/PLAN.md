# 원본 이미지 기준 Unity 셰이더 비교

원본 `avator_references/ref_char.png`를 다시 열어 정장 색과 음영의 강도를 확인했다. 구매 모델들은 lilToon을 사용한다. 비앙카도 현재 Standard 검수 재질과 lilToon의 약한 그림자/그림자 없는 두 설정을 같은 자세·조명에서 비교한다.

[lilToon 공식 조명 설명](https://lilxyzw.github.io/lilToon/ja_JP/base/lighting.html)은 밝기 하한/상한과 환경광 처리 방식을 설명한다. 설치한 공식2.3.4 `lts.shader`에서 실제 속성 기본값을 확인했다. `_LightMinLimit`은 어두운 환경에서의 최소 밝기이며 emissive 대체가 아니다. 새로 텍스처를 생성하거나 그림자 설정으로 관절의 기하 문제를 해결했다고 주장하지 않는다.

원래 텍스처와 메시·UV·키·본·웨이트를 유지한 별도 재질/프리팹을 만든다. 대기/앞/뒤/위팔 자세를 밝은 조명과 약한 조명에서 비교하고 실제 사진을 검토한 뒤 채택한다. 정장 어깨선 자체는 남긴다.
