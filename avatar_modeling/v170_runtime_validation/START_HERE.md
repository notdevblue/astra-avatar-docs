## 후속 통합 결과

4 FX 상태 ON은 실제 저장 확인. `HUMANOID_REPAIRED_CHECK.json`20자세에서는 자동키 최대오차0.001273%, Unity IK·물리·바람 동시 실행 완료, 이전 teardown 예외 없음. 앞/뒤/위 대표 사진을 실제 검토했으며 어깨 옷 접힘과 면 찌그러짐은 여전히 남는다.

루트 이동은 별도 문제다. `ROOT_SPACE_PROBE.json`에서 원점은 정확하지만 이동 시 Contact가 일부0. `RADIUS_PROBE.json`1e-8/1e-6/1e-4/0.001m Sender 확대는 모두 해결 실패. `NATIVE_CONTACT_PROBE.json`에서 SDK 내부 구 중심과 반경도 정상이고 직접 CalculateProximity는 약1이지만 실제 collisionValue는0인 사례를 확인했다. 따라서 단순 본 위치나 작은 반경 문제로 확정하지 않는다.

설치 SDK의 로컬 DLL을 읽어 충돌 사전 검사에서 공간 셀별 쌍 저장 한도1024를 확인했다. 태그 필터 전에94Contact의 다수 겹침 쌍이 생기고 원점을 벗어나 하나의 셀에 모이는 것이 원인일 가능성이 높다. 원본 DLL/복원 소스는 Git에 포함하지 않는다. 본의 로컬 회전만 복제한6개의 분리된 측정 구역으로 센서를 옮기는 대체안을 실제 검사 중이다. 보정 수학·키·메시는 유지하면서 무관한 구체 간 겹침을 줄인다. 성능 등급 문제와 이 기능 실패는 구분한다.

현재 통합 완료가 아니다. 실제 VRChat 클라이언트는 실행하지 않았다. 계획과 공식 출처는 `PLAN.md`.

## 찾은 회귀와 수정

바람 레이어 추가 전 v167 자동24키는32+174자세에서 정확했다. 추가 후 스케일/루트192자세 검사에서 최대오차1.0, 많은 키가1에 고정되었다. 실패자료 `SCALE_FX_CHECK.json`. 물리/IK를 켠 첫20자세도 같은 실패가 있으므로 `HUMANOID_CHECK.json`과 해당 사진은 완성 결과가 아니다.

`WindFXProbe`로4자세×5구성을 분리했다:

| 구성 | 최대 키 오차 |
|---|---:|
| 현재 wind WD OFF |1.0|
| wind 레이어 가중치0 |0.00000261|
| 첫 레이어 mask 제거, wind WD OFF |1.0|
| wind WD ON |0.00000261|
| wind WD ON + mask 제거 |0.00000261|

따라서 이 구성에서는 wind 상태의 Write Defaults OFF 혼합이 회귀 원인으로 확인되었다. 마스크만 제거해서는 해결되지 않았다. 공식 문서의 Direct Tree ON 예외를 확인했지만, 그 지침만으로 이 복잡한 컨트롤러의 혼합 설정이 정상이라고 가정하지 않는다. **4개 FX 상태 모두 ON으로 통일**, 정적 스케일/루트와 통합 검사를 재실행한다. 검사용 Humanoid Base 상태도 ON으로 한다. 다른 사용자 정의 컨트롤러와 임의로 섞어도 안전하다는 보장은 아니다.

초기 여러 프리팹을 순차 Destroy할 때 SDK Contact가 이미 삭제된 Animator에 값을 쓰는 MissingReference와 물리 Job 의존성 예외가 발생했다. 테스트 종료 순서를 수정해 인스턴스를 비활성화하고 Animator 객체는 실행 종료까지 유지한다. 이 오류가 있는 실행을 깨끗한 물리 통과로 취급하지 않는다.
