# PC 성능 비교와 작업 판단

사용자 결정: 참고 모델들과 비교해 실제 부담이 허용할 만하면 비앙카도 등급 자체보다 품질을 우선한다. **현재는 등급 때문에 보정이나 헤어·옷 물리를 제거하지 않고 유지**한다. 기능이 끊기는 버그는 별도로 해결한다.

같은 Unity2022.3.22f1/SDK3.10.5의 실제 PC 성능 집계로 비교했다. 원본 구매 ZIP에서 텍스처·재질을 로컬에 복원하고 공식 lilToon2.3.4를 설치했다. 이전 진단 프로젝트의 texture0 집계는 누락 자료이며 실제 메모리0이 아니다.

## FX 계산만 분리한 CPU 측정

각 모델 실제 custom FX를 사용해200회 예열 후24배치×250회 `Animator.Update(1/60)`를 측정했다. 렌더링·Contacts·PhysBone·제약은 이 측정에서 제외했다. Unity Editor의 해당 컴퓨터 측정이며, 전체 아바타 프레임 시간이나 GPU·VRChat 실제 성능이 아니다. 제스처 입력과 비앙카 바람 입력을 바꾸고 GC0세대 추가수집0 확인.

| 모델 | 중앙값 |95백분위 배치|
|---|---:|---:|
| 비앙카 |0.176ms|0.193ms|
| SiuSiu 기본 |0.139ms|0.145ms|
| SiuSiu Kisekae |0.081ms|0.082ms|
| Lapwing 기본 |0.048ms|0.051ms|

비앙카는 기준 모델보다 FX 계산이 많지만 SiuSiu 기본 대비 차이는 약0.037ms다. 이 결과만으로 현재 자동 보정을 제거할 필요는 낮다고 판단한다. 반대로 Contacts/물리까지 ‘무시 가능한 비용’이라고 확정하는 근거도 아니다. 그 부분은 실제 SDK 실행에서 추가 측정한다.

## 등급과 기능 버그의 구분

[공식 PC 기준](https://creators.vrchat.com/avatars/avatar-performance-ranking-system/)에서 Contacts Poor 상한32를 넘으면 해당 항목 Very Poor가 된다. 단일 항목이 전체 등급에 영향을 주며, 정적 등급은 Animator의 실제 비용을 모두 설명하지 않는다. 다른 사람의 표시 설정에 따른 제한은 남는다. 단순히 등급을 숨기려고 Local Only로 바꾸어 원격 보정을 없애지는 않는다.

이번 원점 이동 시 보정값 소실은 등급 경고가 아니라 실제 기능 결함이었다. 측정 센서를6개 분리 구역으로 옮기자16개의 원점/이동/회전/축소 검사에서 최대 키 오차0.000689%로 회복했다. 이는 보정과 원형을 유지하는 수정이다. 이후 이동/회전/크기0.5·1·2를 포함한192자세에서 최대 키 오차0.00088215%로 통과했다.


## 실제 SDK 물리·Contacts·제약 측정

`DYNAMICS_COST_FRAME.json`은 각 모델150프레임 예열 후600게임 프레임을 기록했다. 실제 SDK 구동, 머리 회전 입력, 렌더링 비활성화, Unity Editor Profiler ON이다. 매 게임 프레임 기록 버퍼를 비워 Editor의 많은 빈 샘플이 유효 구간을 덮어쓰지 않도록 했다. 세 모델 모두 주요 마커600개 유효 샘플, 버퍼 넘침0을 확인했다. 앞선 DYNAMICS_COST 및 DYNAMICS_COST_VERIFIED는 일부 구간만 남아 비교 근거에서 제외한다.

| SDK 마커, 게임 프레임당 기록 합계 | 비앙카 | SiuSiu 기본 | Lapwing 기본 |
|---|---:|---:|---:|
| PhysBoneJob |0.696ms|0.445ms|1.210ms|
| VRCConstraintJob |0.175ms|0.320ms|0.080ms|
| Contact CollisionScene |0.0229ms|0.0329ms|0.0132ms|
| Contact UpdateReceivers |0.0375ms|해당 실행 없음|해당 실행 없음|

Job 값은 작업자 스레드의 실행 시간 합계이며 서로 겹쳐 실행될 수 있다. 표를 모두 더해 화면 한 프레임의 지연이라고 해석하면 안 된다. Editor Profiler의 계측 비용도 포함되어 실제 VRChat 클라이언트 수치가 아니다. 비앙카는 빠른 v173 FX와 T-pose 교정 프리팹을 사용했지만 위 FX 단독 표는 이전4레이어 측정이다.

현재 비앙카의 물리 작업량은 두 참고 모델 사이이고, 보정용 Contact 처리도 이 검사에서는 큰 병목으로 나타나지 않았다. **사용자 요청에 따라 Very Poor 등급은 허용하고 관절 보정·헤어·옷 물리를 유지한다.** 실제 프레임 비용이 과도해지는 구성이 확인될 때만 원인을 줄인다. 실제 클라이언트 성능을 검증했다는 의미는 아니다.
