# v338 · 겪은 문제, 시도한 방법과 판정

2026-09-13. v337 UV와 원래 세부 묘사를 유지하면서 외래 흔적을 먼저 제거했다. 로컬 레퍼런스의 전신·정면·측면 이미지를 실제로 열어 비교했다. 이미지 편집 도구의 결과는 후보 채색으로 사용했고, 검수 사진은 Blender/Unity가 실제 모델을 렌더한 것이다.

| 문제와 시도 | 결과 | 판정과 이유 |
|---|---|---|
| 허벅지 잘라낸 영역을 이미지 편집 도구로 정리 | 손 윤곽은 줄지만 범위 전체를 쓰면 원래 주름 위치까지 바뀔 수 있음 | 전체 패치 교체 제외. 대상 UV 조각 안의 국소 마스크만 합성 |
| 첫 합성의 UV 밖 여백 검사 | 대상 조각 밖 1,703픽셀 변화 발견 | UV 삼각형으로 제한하는 마스크로 보완. 최종 지정 부위 밖 변경 0 |
| 앞쪽 두 허벅지 UV 조각 정리 | 2D와 일부 구도는 깨끗하지만 반대 사선에는 손 윤곽 잔존 | 이 단계의 완료 판단 철회. 최종 후보로 사용하지 않음 |
| 재질·UV 경로와 실제 화면 UV 좌표 추적 | Paint 재질과 V337_UV 연결은 정상. 뒤쪽 연결 조각 C391에도 흔적 존재 | 앞쪽 C381/C401에 더해 C391 국소 수정. Unity 양쪽 사선 재검수 후 반영 |
| 셔츠 새 채색 100% 반영 | 접힘이 각지고 종이 같은 인상으로 변함 | 미채택. 원래 부드러운 천 표현 보존 실패 |
| 셔츠 25% 혼합 | 원래 인상에 가깝지만 정리 효과도 미세 | 비교용 보존, 전달 모델에 미반영. 피드백 대상 |
| 신발 반점의 화면→UV 위치 추적 | C469의 작은 부분으로 특정 | 반점만 국소 완화. 신발 옆면 전체 재채색은 후속 |

반대쪽 확인이 빠지면 같은 흔적을 여러 조각 중 일부에서만 지우게 된다. 후속 작업도 2D 편집 뒤 해당 부위의 반대 방향·가려진 면을 실제 3D에서 확인한다. 현재 결과가 모든 얼룩과 이음선을 해결했다는 의미는 아니다.
