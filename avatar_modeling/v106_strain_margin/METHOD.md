# 늘어남 경계의 실패에서 바꾼 조건

[수정 전 조사](../v094_shoulder_research/RESEARCH.md)의 자세별 옷 보정 방법을 현재 기존 메시에서 시험했다. 목표 표면을 직접 만든 뒤 여러 실제 자세의 면적·면 방향·분리된 면의 간격 조건으로 제한한다. 목표 표면 제작은 Blender Studio의 포즈 보정 워크플로와 관련이 있지만, 아래 수치와 제약 설계는 이 모델에서 수행한 자체 실험이다. 외부 튜토리얼이 이 수치의 정답을 보장하지 않는다.

1. v098의 기존 54점 표면 목표는 주름 아래쪽뿐 아니라 위쪽 소매 뿌리를 포함한다. 고정 이웃과 위치 유지 조건으로 과한 변위를 제한한다. 새 메시 생성 없이 기존 정점의 보정 위치를 계산한다.
2. v099–100의 면적 제한만으로는 Blender가 변형 후 고르는 사각면 대각선이 달라지는 문제를 막지 못했다. 원래면15415의 실제 두 분할과 면적비를 비교한 뒤 경계 정점28805와 반대쪽16737의 보정을 0으로 고정했다.
3. v102의 수정 영역 내부 접촉 검사에는 바깥 고정 면8684가 빠져 있었다. v104에서 전체 메시의 해당 고정 면까지 분리 축 조건에 포함했다. 이미 원본부터 접촉한 면과 새로 겹친 면을 구분한다.
4. v105 새 회전은 경계에 가까운 면이 조금씩 더 늘어나는 문제를 드러냈다. v106은 면적비2.5 초과인 면은 원래보다 더 늘리지 않고, 0.35 미만인 면은 더 줄이지 않도록 벌점을 준다. 원래부터 경고인 면에도 이 조건을 사용한다. 최종 검사 경계0.2/3은 바꾸지 않았다.
5. 포즈 키는 본의 정규화한 쿼터니언 방향으로 활성화한다. 속성 길이가 바뀌는 애니메이션 보간에서도 같은 회전 방향이면 같은 키 값을 내도록 한다. 양쪽 키는 각각 자기 팔과 쇄골을 참조한다.

선별 캐시는 이전200+530+v105의530+전신1377, 총2637명령이다. 왼쪽732/오른쪽717명령에서 보정이 활성됐다. 면마다 가능한 삼각 조합을 계산하지만 실제 Blender의 최종 삼각분할 검사도 별도로 수행한다. 선별 표본과 새 난수 검사, 저장 동작 검사를 구분한다.

최적화는 [SciPy L-BFGS-B](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-lbfgsb.html)를 사용했다. 도함수는 v099에서 유한차분으로 대조했다. v106의 각 적합은1200회 상한으로 끝났으며 수렴한 최적해로 표현하지 않는다. 분리 축 잔차는 실제 관통 깊이와 다르다. 표본에서 새 경고0이라도 모든 연속 자세의 무결함 증명은 아니다.

이 파일은 Blender 저작용 포즈 키 두 개를 추가한다. 기존102본과 제약·웨이트·원래 기하·UV·이미지를 유지한다. 키를 FBX로 전달하는 것과 임의 팔 회전에서 자동 활성화하는 것은 별도 문제이며, Blender 드라이버가 Unity/VRChat에서 그대로 동작한다고 가정하지 않는다. 실제 엔진 내 활성화·본 제약 이식·PhysBone 검증은 남는다.
