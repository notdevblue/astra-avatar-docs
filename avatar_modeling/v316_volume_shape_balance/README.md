# v316 — 부피와 면의 길이를 함께 제한, 미채택

기존 겨드랑이 접힘을 풀면서 주변 면이 과하게 늘어나는 v314의 부작용을 줄였다. 같은 기존 삼각형의 두 방향 길이비를 추가로 제한했고, 단면적·최소 폭·정점 띠의 축 방향 조건은 유지했다. 새 메시·본·웨이트·원본 변경은 없다.

복합571에서 면1659의 큰 방향 길이비1.396→1.051, 면1204는1.336→1.152로 줄었다. 반대 방향 압축까지 모두 해결된 것은 아니다. 중앙55–85% 실제 폐단면25개씩 적분한 외곽 부피는 중립 대비 왼96.75/오른96.83%다. 독립 폐곡선이 없는 어깨뿌리 전체나 옷감 체적을 뜻하지 않는다.

미분 대조9조건 통과, 자기교차·새 큰면적/접힘 경고0,14개 검사용 폐단면 유효. 그러나 몸과의 새 교차가79→90으로 늘어 채택하지 않았다. 기존 교차 해소775개(몸217·코트 자체558)가 새 교차를 상쇄해 합격한 것은 아니다. 정면·측면 재질 렌더를 직접 열었고 넓은 어깨 각짐도 남아 있다.
