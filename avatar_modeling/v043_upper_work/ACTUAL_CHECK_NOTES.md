# 실제 평가 면과 독립 손가락 검사

07/08 MCP 시험은 자세마다 평가 메시를 다시 삼각화한다. 중립 교차도 그 자세의 연결로 재계산하여 뺀다. 기존 동시 굽힘100표본과 새로운 개별 마디·손목·전완 복합200표본, 총300표본이다. 각 손가락의 MCP/PIP/DIP는 독립각도로 시험했다. 숫자는 자세·면쌍 누적이며 고유 결함 수나 관통 깊이가 아니다.

| 사본 | 면적 경고 | 교차 면쌍 누적 |
|---|---:|---:|
| 기존 v041 |127|7051|
| 엄지축+WEB40 |126|3131|
| 타 손가락 웨이트50% 정리 |72|3133|
| 타 손가락 웨이트100% 정리 |111|3156|

첫500표본의 면적0은 개별 손가락 독립 움직임을 검증한 결과가 아니었다. 확대 검사에서는 새 실패가 드러났다. WEB40만으로 손 전체가 해결됐다고 하지 않는다. 새 실패는 새끼/약지 사이의 당김과 중지 두 번째 관절 주변에 집중된다. ISOLATE50을 후속 작업의 사본 출발로 삼되 아직 최종 통합 합격으로 확정하지 않는다.

ISOLATE50은666raw 손 정점 웨이트를 바꾸며 다른 부위의 웨이트·Basis좌표·UV·면·노멀은 그대로다. 엄지6본의 roll 변경은 유지한다. 최대4영향, 정규화오차1.04e-7, 중립 평가의 원본 대비 최대차8.89e-8m이다. 원본 rest좌표 대비3.47e-6m라는 초기 수치는 원본 자체의 평가 오차까지 포함했으므로 원본/후보 차이로 대체했다.

보조본 시험의 잘못된 changed_raw 초기값도 이름 대응으로 다시 검사했다. 손 보조본은1708raw, 팔 보조본은1691raw이다. PRESERVATION JSON이 초기 BUILD의 열 순서 오류를 정정한다. 보조본 시험은 통합하지 않는다.
