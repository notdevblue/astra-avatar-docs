# 코트의 기존 정점 연결과 음영

v044에서 pose shape만 바꾸거나 기존 노멀을0으로 초기화해도 판 같은 음영이 남았다. 별도 진단에서 코트의 일치 위치를Weld modifier로 연결한 뒤 노멀을 재계산하자 면 경계가 상당히 줄었다. 분리된 raw정점 때문에 자동 노멀이 이웃면을 평균할 수 없었던 부분이 있었다. 큰 실루엣 접힘은 여전히 따로 고쳐야 한다.

v045는 기존 메시의 코트 정점 중 위치·웨이트가 같은 것만 연결한다. 새 메시/새 면/리메시 없이 기존 면을 유지한다. UV는 면 코너별로 원본과 대조한다. 원래 정점/면/루프 번호와 component를 속성에 남겨 인덱스 재배치 뒤에도 검사 부위가 틀어지지 않게 한다. 기존 로더는 component속성이 있는 새 사본에서만 이를 읽고, 이전 파일은 기존 방식 그대로다.

전신 코트의 노멀을 전부 부드럽게 하면 옷깃·옷자락 인상이 바뀌므로 어깨/소매 영역만 재계산하는 사본을 시험한다. 아직 최종 합격 기록이 아니다. v043 손 사본 위에 연결하되 v038 무릎 좌표와 웨이트는 보호한다.
