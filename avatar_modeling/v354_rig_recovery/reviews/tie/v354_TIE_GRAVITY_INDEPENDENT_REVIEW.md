# v354 넥타이 중력 독립 검토

새 실제 기준/후보 각1,800프레임(좌·우·앞 굽힘 각각600)을 검토했다. **PAD1은 아래 구간이 더 수직으로 드리워지며, 검사 표본에서 새 넥타이 접촉이나 비대상 표면 변화를 만들지 않았다.** 이동·바람 검증이 남았으므로 아직 전체 최종 채택 판정은 아니다.

두 실행 DONE 성공·SOURCE/SCENE 보존 true, 별도 Play 순서0이다. 실제 v352 원래 메시/본/웨이트와 실행기·자세입력 SHA가 같다. 원래 v353 눈 정리로 달라진 삼각형 인덱스를 섞지 않았다.

각66개 실제 스킨 표본에서 넥타이–셔츠·넥타이–코트·넥타이 자기교차는 양쪽0이다. 넥타이 삼각형의 수치상 거의0 면적도 양쪽0이다. 넥타이 밖 BodyHair 및 Coat의 같은 표본 좌표는 **차이 정확히0**이다. 코트–바지 접촉은 양쪽20/66, 최대63쌍·교차선26.385096mm로 기존과 같으며, 이 넥타이 후보가 코트 문제를 수정했다고 해석하지 않는다.

새 실제299프레임 좌/우/앞 측면 전후6장을 직접 열었다. 앞 굽힘의 후보는 아래 넥타이가 몸에서 조금 떨어지며 더 수직으로 내려온다. 좌우 기울임에서는 변화가 작고, 코트의 V자 꺾임·옷 여유 문제는 그대로 보인다. 사진 속 원래 코트 명암과 접힘을 넥타이 회귀라고 부르지 않는다.
