# v354 넥타이 물리 복구와 참고 모델 조사

v353 텍스처 재작업은 폐기한 상태로 유지하며, **v352 원래 외형에 넥타이 물리 개선만 분리해 통합 후보로 선택했다.** 어깨·자켓·눈·헤어와 최종 통합 검수는 계속 진행 중이다. 전체 아바타 완성 또는 PC VRChat 실기 합격을 뜻하지 않는다.

## 실제로 바뀐 것

기존 넥타이 PhysBone의 중력·복귀·길이별 제한을 조정하고, 셔츠의 움직임을 따라가는 작은 콜라이더 두 개를 추가했다. 매듭은 고정하고 아래 구간에 더 큰 가동 범위를 준다. 표면을 다시 칠하거나 새 UV·재질·셰이더를 가져오지 않았다. 메시와 웨이트, 기존 본·키·컨트롤러는 그대로다.

검수 사본은 작업 저장소의 `Assets/BiancaV354RigRecovery/Bianca_v354_V352_TIE_PAD1_REVIEW.prefab`이다. 원래 기준과 물리 전용 도너를 비교하여, 선언한 물리 필드 10개와 지원 Transform 6개 이외 차이가 없음을 확인했다. 재로드 후 기본 자세의 정점 오차는 0이다.

## 참고 모델 방식을 적용하는 방법

[SiuSiu·Lapwing 실제 구성 조사](reviews/physics_reference/v354_REFERENCE_PHYSICS_REVIEW.md)에서 두 모델 모두 Unity에 설정한 VRChat PhysBone을 사용하는 것을 확인했다. 모델마다 제어 본을 분리하거나 의상 부위의 체인에 직접 물리를 붙이는 차이가 있다. 넥타이는 이미 같은 SDK 계열의 방식이다. 동등한 참고 넥타이가 없어 계수까지 복사했다고 주장하지 않는다.

평상시에는 이동·머리 회전에 대한 PhysBone 반응을 기준으로 맞춘다. 우리 기존 `BiancaWind`는 풍속이 아니라 앵커 회전 애니메이션의 혼합 입력이므로 별도 옵션으로 구분한다. 참고 모델처럼 의상 지지와 부착 장식의 움직임을 연결하는 자켓 후보를 다음으로 확인한다.
