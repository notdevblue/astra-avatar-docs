# 관절별 검증 자세와 합격 기준

**PC Unity / VRChat · 계획 버전 v008 · 아래 시험은 모두 미실행**

이번에 수행한 것은 기존 모델의 읽기 전용 데이터 검사와 중립 렌더다. 이 문서의 포즈·엔진 테스트는 **후속 수정본에 적용할 계획**이며 통과 목록이 아니다. 과거 v006/v007 시험 기록과 혼동하지 않는다.

## 공통 촬영과 판정 규칙

전후 후보는 같은 카메라·렌즈·조명·포즈·렌더 해상도로 비교한다. 정면/측면/45도를 기본으로 하고 겨드랑이·엉덩이는 후면, 손은 손바닥/손등을 추가한다. 컬러·회색·와이어가 각각 디자인·형상·면 흐름을 설명하도록 만든다. 모든 회전은 본 이름, 부모 공간, 로컬 축, 각도/쿼터니언을 함께 기록한다.

아래 각도는 **제작용 시험 샘플**이다. 해부학 정상 범위를 뜻하지 않으며 실제 모델과 입력 장치의 동작을 보고 조정한다. 왼쪽과 오른쪽을 따로 시험하고 순방향·역방향·중립 복귀를 포함한다. 0→최대 두 프레임 사이 보간만으로 모든 중간 자세를 확인했다고 기록하지 않는다.

시각 실패는 원래 없던 뾰족한 윤곽, 관절 부피의 급격한 손실, 접힘 면 뒤집힘, 의도하지 않은 관통/틈, 주변 부품 끌림, 중립 복귀 후 형태 변화다. 의도된 접촉과 기존부터 있던 결함은 새 결함과 구분한다. 수치 개선이 시각 실패를 상쇄하지 않는다.

## 결과 기록 서식

각 ID에 `예정 / 실행-통과 / 실행-실패 / 장비·환경 미검증` 중 하나를 기록한다. 실행 결과에는 파일 SHA, 본 회전·입력, 카메라, 전후 이미지, 관찰한 실패, 수치, 결정과 남은 한계를 붙인다. 단순히 “총 N프레임 정상”으로 대체하지 않는다.

이 계획의 모든 ID는 아직 예정 상태다. 현재 문서 작성으로 Unity/VRChat 동작 합격이나 관절 개선 완료를 주장하지 않는다.
