## 우리 작업안 — 아래는 조사에 근거한 제안이며 아직 구현하지 않음

### 1. 얼굴을 먼저 검증

캐릭터 디자인을 정하고 정면·측면·후면이 일관된 얼굴/머리카락/몸 참조를 준비한다. 눈높이, 턱선, 목 둘레, 머리 크기를 기준으로 정렬 가능하게 만든다. 첫 얼굴에서 정면·45도·측면 렌더를 확인하고 눈·입을 점검한다. 실패한 얼굴 위에 전체 리깅을 쌓지 않는다.

### 2. 파트별 형상 생성 후 텍스처 확정

얼굴·머리카락·몸에 생성 예산을 따로 배정한다. 원본과 후보를 보관하고 형상 선택 후 텍스처를 생성한다. 현재 서비스에서 가능한 사각면 설정과 FBX 내보내기를 확인한다. 첫 실험은 표정 수를 작게 제한한다. 정확한 크레딧 예산은 실제 생성 화면 확인 후 정한다.

### 3. 검사·조립을 스크립트로 반복 가능하게 만들기

원본 복사본에서 오브젝트/재질/정점/면/UV/본/셰이프 키 목록을 뽑는다. 스케일·축·중복 정점·비정상 면·연결 성분을 확인한다. 정점 병합 임계값은 모델 크기에 맞추고 눈꺼풀·입술·옷 층이 잘못 붙지 않는지 비교한다. 얼굴·머리카락·몸을 정렬하고, 필요할 때만 목 경계를 연결한다. 루프 정점 수와 UV가 맞지 않으면 단순 브릿지만으로 완료 처리하지 않는다.

### 4. 최종 리깅 전 얼굴 구조 결정

Blender 영상 시제품이면 기본/미소/입 벌림 정도의 얼굴 교체부터 검증할 수 있다. 사용하지 않는 메시가 그림자나 렌더에 남지 않고 모든 각도에서 전환이 자연스러운지 확인한다. VRM이 목적이면 눈·입을 독립 변형하는 얼굴 구조를 확보하고, 별도 생성된 얼굴을 그대로 보간할 수 있다고 가정하지 않는다. 눈 깜빡임과 입 벌림을 함께 테스트한 뒤 확장한다.

### 5. 기본 몸 리깅과 의상 웨이트

뼈 위치를 전후좌우에서 확인하고 기본 웨이트를 만든다. 소체가 온전하면 의상으로 전송하되, 없거나 불완전하면 해당 부위를 보완하거나 의상 웨이트를 별도로 처리한다. 어깨 올림, 팔꿈치 굽힘, 앉기, 무릎 굽힘으로 찢어짐·눌림·관통을 확인한다. 긴 머리·치마·리본은 그 다음에 추가한다.

### 6. 흔들림과 납품 형식 검증

머리카락 체인과 의상 움직임을 작은 범위에서 설정하고, 몸·목·얼굴과 충돌하는지 확인한다. Blender 렌더와 VRM 실행 환경은 각각 검증한다. 10~20초의 간단한 동작 영상과 얼굴 클로즈업, 360도 턴테이블로 검토한다. 완성 전 사용자에게 결과를 보여줄 수 있는 .blend와 미리보기를 남긴다.

### 우리가 만들 보조 기능의 범위

작성자의 앱 복제라고 부르지 않는다. 우리 구현에는 다음 기능이 유용하다: 장면 검사 보고서, 다각도 렌더, 파트 정렬 기준점, 본 위치 표시, 웨이트 전송과 정규화, 관절 테스트 포즈, 표정 전환 컨트롤, 단계별 저장. 비용이 큰 시각적 시행착오를 줄이는 것이 목적이며, 모든 기능을 선제적으로 만들기보다 실제 모델에서 필요한 것부터 구현한다.
