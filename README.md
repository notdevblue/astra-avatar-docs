# 비앙카: 원래 모습을 지키며 움직이는 아바타로

레퍼런스를 바탕으로 만들어진 비앙카의 3D 시제품에서 출발해, **기존 모델의 인상을 유지하면서 PC용 Unity / VRChat 아바타로 다듬는 과정**을 기록한 저장소입니다. 처음에는 얼굴과 머리카락의 채색을 정리했고, 이후 몸의 뼈대와 관절, 정장 코트의 변형, 머리카락·옷 물리, Unity에서의 실제 구동까지 작업을 넓혔습니다.

가장 오래 다룬 문제는 “가만히 있을 때 괜찮은 모델이 움직일 때도 자연스러운가?”였습니다. 한 자세에서 좋아진 수정이 다른 자세를 망가뜨리는 일이 반복됐고, 그때마다 원인을 나눠 검사하고 반영할 부분을 다시 골랐습니다. 이 문서는 그 흐름과 주요 판단을 설명합니다.

**공유 기준: 2026-09-11, v186까지.** Blender와 Unity Editor에서 검토한 단계이며, 어깨·골반·손에는 남은 문제가 있습니다. 실제 VRChat 클라이언트 테스트와 업로드는 아직 하지 않았습니다. 진행 중인 v187 이후 작업은 이 공유본에 포함하지 않았습니다.

[현재 검토 결과](avatar_modeling/v186_review_bundle/START_HERE.md) · [전체 단계 색인](STAGES.md) · [상태·결정 이력](STATUS.md)

## 작업은 이렇게 진행했습니다

기본 흐름은 **문제 확인 → 원인 분리 → 사본에서 수정 → 같은 자세로 비교 → 다른 동작에서 재검사 → 통합 여부 결정**입니다. Blender에서 본과 표면을 검사하고, 반복 측정과 비교 렌더에는 스크립트와 MCP를 사용했습니다. Unity 단계에서는 실제 SDK를 켜서 가져오기 결과와 자동 보정·물리를 확인했습니다.

본은 움직임의 축, 웨이트는 각 정점이 어느 본을 얼마나 따라갈지 정하는 비율입니다. 여기에 자세에 따라 표면을 보완하는 셰이프 키와 면의 연결 방향을 함께 조절했습니다. 새 캐릭터나 대체 메시를 만드는 대신 기존 메시를 수정했고, 원본과 실험 사본을 따로 보존했습니다.

버전 번호는 이 실험의 순서입니다. 번호가 높다고 모든 이전 수정을 누적한 완성본은 아닙니다. 결과가 나빠 제외한 실험도 이후 같은 실패를 반복하지 않도록 남겼습니다.

## 1. 먼저, 색의 문제와 모양의 문제를 나눴습니다

초기 모델에는 뼈대가 없었고, 얼굴에 머리카락 무늬가 묻거나 머리카락에 피부색이 섞여 있었습니다. 눈 주변에는 그려진 눈선과 실제 입체 표면이 어긋난 부분도 있었습니다. 조명을 뺀 색상 렌더와 회색 표면을 비교해, 채색 오류와 실제 형상 차이를 구분했습니다.

눈은 두 방법을 비교했습니다. **기존 눈 모양에 텍스처를 맞추는 A안**과 눈 정점을 기존 그림에 맞춰 옮기는 B안입니다. 정점을 옮겨도 잘못 그려진 색과 중복 눈선은 남았습니다. 사용자가 A 방향을 선택한 뒤, 얼굴·헤어·의상으로 채색 작업을 넓히고 기존 UV에 다시 입혔습니다. 이 텍스처 단계에서는 정점 위치와 면 연결을 유지했습니다.

| 텍스처 보정 전 | 텍스처 보정 후 |
|---|---|
| ![기존 얼굴 채색](avatar_modeling/v005_texture/before_face_front.png) | ![기존 형상에 맞춘 얼굴 채색](avatar_modeling/v005_texture/after_face_front.png) |

큰 얼룩과 색 번짐은 줄었지만, 기존 눈 조각의 돌출이나 머리카락의 두꺼운 실루엣까지 채색으로 해결한 것은 아닙니다. [초기 진단](avatar_modeling/v001_inspection/REVIEW.md), [눈 A/B 비교](avatar_modeling/v004_eyes_ab/REVIEW.md), [전신 텍스처 갤러리](avatar_modeling/v005_texture/GALLERY.md)에 과정과 남은 차이를 담았습니다.

## 2. 뼈대를 만들고, 무릎에서 수정 기준을 다시 잡았습니다

임시 리그로 팔 올리기·무릎 굽히기·앉기를 시험하자 겨드랑이, 무릎, 목, 옷자락의 문제가 드러났습니다. 목과 턱의 추종 범위를 나누고, 손가락과 관절 보조 본을 추가하고, 코트 자락이 다리와 별도로 움직일 구조를 비교했습니다. 본을 추가하는 것만으로 자연스러운 변형이 생기지는 않아 웨이트와 회전 중심을 함께 검토했습니다. [전신 본 작업](avatar_modeling/v023_rig_review/REVIEW.md), [자락 제어 비교](avatar_modeling/v013_coat_runtime/REVIEW.md).

무릎에서는 중요한 방향 전환이 있었습니다. 컷과 보조 구조를 늘려 면끼리 겹치는 현상을 줄여도, 접히는 틈이 넓어지거나 형태가 부자연스러워졌습니다. 사용자가 더 낫다고 본 v030으로 돌아가 **뒤쪽의 좁은 접힘을 보존하고 앞면 웨이트만 작게 조정**했습니다. 이 v038 SMALL이 사용자 채택 기준이 됐습니다.

이 선택은 “교차를 전부 없앴다”는 뜻이 아닙니다. 기존 안쪽 교차와 주름은 남았고, 원래에 없던 문제가 추가되는지와 보호한 뒤쪽 모양이 같은지를 확인했습니다. 이후에도 수치와 실제 외형을 함께 보는 기준으로 이어졌습니다. [무릎 전후 비교와 채택 이유](avatar_modeling/v038_knee_front/REVIEW.md).

## 3. 정장 어깨는 움직임·면 연결·두께를 따로 다뤘습니다

팔을 올리거나 앞으로 뻗으면 코트 몸판과 소매가 함께 끌려가고, 겨드랑이는 접히며 소매산이 납작해졌습니다. 웨이트 조정, 보조 본, 국소 컷, 표면 완화, 자세 보정 등을 비교했지만 한 방향의 개선이 다른 회전의 찌그러짐이나 교차를 만드는 경우가 많았습니다.

그래서 문제를 더 잘게 나눴습니다.

| 관찰한 문제 | 처리한 방법 | 얻은 결과와 한계 |
|---|---|---|
| 팔을 앞으로 돌려도 바깥으로 벌어지고 코트 중앙이 따라감 | 벌어진 기본 팔 자세에 맞게 조작 축과 쇄골 분담을 분리 | 앞뒤 동작 경로와 중앙 끌림 개선. 소매 겹침은 별도 문제로 남음. [v121](avatar_modeling/v121_arm_controls/START_HERE.md) |
| 어깨선이 끊기거나 검게 패인 것처럼 보임 | 색상·음영·실제 면을 분리해 비교 | 날카로운 음영 경계를 정리. 정장 선을 지우는 텍스처안은 제외하고 원래 선을 보존. [v139](avatar_modeling/v139_seam_diagnosis/START_HERE.md), [v146](avatar_modeling/v146_seam_topology/START_HERE.md) |
| 국소 면 수정 뒤 텍스처에 줄무늬·검은 누락 발생 | UV 경계와 색 전달 방식을 따로 검사 | 색 전달 오류는 해결 경로를 확인했지만 형상 회귀가 있어 해당 사본은 미채택. [v093](avatar_modeling/v093_bake_projection/START_HERE.md) |
| 앞으로 뻗을 때 소매산 앞뒤 두께 감소 | 기존 정점의 자세 보정에 두께·어깨선 길이·접촉 조건을 함께 적용 | 앞90 검사에서 기본 대비 두께 66.6% → 89.8%. 깊은 접힘과 일부 새 경고는 남음. [v152](avatar_modeling/v152_volume_review/START_HERE.md) |

![같은 자세에서 어깨 두께 보정 전후](avatar_modeling/v152_volume_review/COMPARE_F90_DETAIL.jpg)

위 비교는 두께 복원의 효과와 남은 주름을 함께 보여 줍니다. 두께 수치는 같은 정점 구역의 회전을 정렬한 뒤 측정한 앞뒤 범위이며, 닫힌 의상의 부피를 뜻하지 않습니다. **큰 어깨·겨드랑이 접힘은 v186에서도 미해결**입니다.

## 4. 참고 모델을 실제로 움직여 보고, 부위별 역할을 나눴습니다

어깨 실험의 회귀가 반복된 뒤에는 Lapwing과 SiuSiu 구매 아바타의 본·웨이트·의상 구조를 조사하고, Unity에서 관절을 실제로 굽히고 돌려 봤습니다. 이름이 같은 보조 본도 구성에 따라 다르게 움직였고, 옷 아래 몸체를 생략하거나 축소한 부분도 있었습니다. 겉으로 보이는 결과만 보고 웨이트나 본의 수를 그대로 따라가지는 않았습니다. [세 모델 구조 비교](avatar_modeling/v156_three_avatar_comparison/START_HERE.md), [실제 관절 동작 비교](avatar_modeling/v157_reference_pose/START_HERE.md).

이후에는 몸판·소매·카라·헤어의 역할을 더 분명하게 나눴습니다.

- **카라:** 팔에 끌려가는 기존 코트 정점의 웨이트 전이를 조절했습니다. 팔 들기에서 늘어남을 줄였지만 모든 접촉을 없애지는 못했습니다. [v159](avatar_modeling/v159_collar_support/START_HERE.md)
- **헤어:** 큰 움직임에서 면이 찌그러지는 후보를 제외하고, 기존 모양과 웨이트 전환을 보존한 완만한 후보를 골랐습니다. Unity PhysBone의 물리 ON/OFF와 정지 복귀를 검사했습니다. [v160](avatar_modeling/v160_hair_dynamics/START_HERE.md)
- **코트 분리:** 기존 코트와 몸을 두 객체로 나눠 부위별 조작을 쉽게 했습니다. 위치가 같아도 음영이 달라지는 문제는 원래 면 모서리의 음영 정보를 복원해 해결했습니다. [v161](avatar_modeling/v161_separate_coat/START_HERE.md)
- **소매 끝:** 손을 전부 따라 꺾으면 소매가 찌그러지고, 전완에 고정하면 손이 소매를 통과했습니다. 손목 축에 맞춘 보조 본과 회전 분담을 조절해 490자세 및 추가144복합 자세로 검토했습니다. [v165](avatar_modeling/v165_cuff_roles/START_HERE.md)

전완 비틀기 분산 등 회귀가 남은 안은 통합하지 않았습니다. 카라·헤어·코트 분리까지의 그림은 [v163 종합 검토](avatar_modeling/v163_review_bundle/START_HERE.md)에서 볼 수 있습니다.

## 5. Unity에서는 실제 구동을 다시 확인했습니다

Blender에서 잘 움직여도 그 본 제약과 자세 보정이 Unity로 그대로 옮겨지는 것은 아니었습니다. Humanoid 연결, 작은 웨이트의 가져오기, 자동 보정, 물리, 재질을 각각 확인하면서 다음 문제를 수정했습니다.

| 실행 중 발견한 문제 | 적용한 처리 |
|---|---|
| 가져올 때 작은 웨이트가 빠져 변형이 달라짐 | 원래 본별 웨이트를 복원하고 실제 표면 위치를 비교 |
| 바람 애니메이션과 자세 보정을 함께 켜면 값이 누적됨 | Animator의 값 유지 설정인 Write Defaults 조합을 대조해 수정 |
| 아바타를 이동하거나 크기를 바꾸면 보정이 사라짐 | 관절 측정용 Contact 센서를 공간별로 분리하고 이동·회전·스케일 재검사 |
| 대기 자세에서 팔이 등 뒤로 모임 | Humanoid 기준을 원래 팔 내린 자세에서 올바른 T-pose로 교정 |
| 정의 목록에는 손가락이 있지만 실제로 연결되지 않음 | Unity가 요구하는 이름 형식에 맞추고 실제 연결된 51개 본 확인 |
| 움직임보다 보정이 늦게 따라옴 | 중간 계산 단계를 줄여 연속 시험의 지연을 3프레임에서 2프레임으로 감소 |

자세 보정은 SDK의 Contacts와 Animator로 구동했습니다. 검사 코드가 표면 보정값을 직접 넣은 결과와 자동 구동 결과를 구분했고, 물리도 켜고 끈 상태를 비교했습니다. [초기 Unity 이식](avatar_modeling/v167_unity_integration/START_HERE.md), [실행 오류와 후속 수정](avatar_modeling/v170_runtime_validation/START_HERE.md), [Humanoid·손가락·연속 동작 검증](avatar_modeling/v175_humanoid_reference/START_HERE.md).

성능은 등급과 실제 측정 비용을 함께 봤습니다. 비앙카는 보정용 Contacts 때문에 PC **Very Poor** 등급이지만, 같은 환경에서 참고 모델들과 비교한 뒤 기존 보정과 물리를 유지하기로 했습니다. 이 측정은 Unity Editor의 CPU 작업 비용이며 실제 VRChat 화면의 프레임 속도는 아닙니다. [성능 비교와 판단 근거](avatar_modeling/v170_runtime_validation/PERFORMANCE_COMPARISON.md).

## 6. 현재는 작은 개선을 선별해 통합한 검토본입니다

공유본의 최신 기준인 **v186**은 앞선 통합본에 손6곳·셔츠2곳·바지2곳의 기존 면 대각선 수정만 더했습니다. 정점 위치·본·웨이트·보정키·UV·텍스처를 유지하면서 작은 면이 접히는 방식을 조정한 결과입니다. 골반·어깨 웨이트 변경안은 더 넓은 자세 검사에서 악화돼 제외했습니다.

최종 후보를 실제 Unity/SDK에서 533자세로 재생하고, 별도 검수 프로젝트에 패키지를 다시 가져와 참조와 구동 상태를 확인했습니다. 국소 수정의 새 경고가 없었다는 결과를 전체 아바타의 무결함으로 확대하지 않았습니다. [반영한 10곳의 전후 비교](avatar_modeling/v184_body_diagonals/START_HERE.md), [v186 결과와 남은 문제](avatar_modeling/v186_review_bundle/START_HERE.md).

| 구분 | v186까지의 상태 |
|---|---|
| 반영한 개선 | 텍스처 정리, 무릎 기준, 카라·소매 회전, 헤어·코트·넥타이 물리, Unity 자동 보정과 Humanoid 수정, 국소 면 연결 |
| 계속 다듬어야 할 외형 | 큰 어깨·겨드랑이 접힘, 깊은 골반 굽힘의 바지 압축, 손가락 사이 일부 면과 복합 손 자세 |
